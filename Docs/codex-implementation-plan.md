# 테이블 도감 구현 계획

1. DX-00: 도감 전용 콘텐츠 SO와 AI 생성 책·책갈피 Sprite를 추가한다.
2. DX-01: 순수 Presenter, 적/악마 페이지 모델, 카테고리별 navigation을 구현하고 테스트한다.
3. DX-02: uGUI 도감 프리팹과 테이블 책 프리팹을 만들고 GameScene에 직렬화 연결한다.
4. DX-03: GameManager·GameFlowController 입력/가용성 생명주기를 연결한다.
5. 대상 테스트, 전체 EditMode, GameScene validate, 720p/1080p 수동 순회를 검증한다.

현재 수정 중인 카드 콘텐츠·악마 카드 프리팹·HUD 변경은 보존하며 도감 전용 카탈로그로 충돌을 피한다.
