> **현행 콘텐츠 변경 안내 (2026-07-30)**
> 새 런은 사탄·벨페고르·바알제붑·마몬 풀에서 서로 다른 2장을 무작위로 모두 지급한다. 선택 화면은 사용하지 않는다. 프로토타입 전체 출현 풀은 사탄·벨페고르·바알제붑·아스모데우스·마몬·바포메트·아자젤 7종이다. 나머지 악마의 구현·테스트 기록은 과거 사실로 보존하되 시작·상점·플레이어·적·계약 후보에서는 비활성화해야 한다.

> **기획 변경 기록 (2026-07-31):** 문서만 변경했다. 현행 코드는 아직 2장 제안·1장 선택·선택 체크포인트를 사용한다. 기존 DC-R01·DC-R05 테스트와 화면 검증은 과거 증거이며 새 규칙 구현 완료를 뜻하지 않는다.

> **바알제붑 단측 선택 변경 기록(2026-08-02):** 양쪽 중 한쪽에만 선택 가능한 공개 카드가 있어도 바알제붑은 발동하며 그쪽 카드 1장만 선택·폐기한다. 양쪽 모두 있으면 각 1장, 모두 없으면 발동하지 않는다. 문서만 변경했으며 현행 양쪽 공개 카드 필수 구현은 후속 이관 대상이다.

> **광신도 정책 이관 완료 (2026-07-31):** 광신도 덱에서 벨리알을 제거해 벨페고르·바알제붑 2종만 보유하게 했다. 영혼 수와 `CanUse`를 무시하고 상대 공개 카드 수가 2장 이상이면 바알제붑, 아니면 벨페고르를 강제 선택한다. 대상 21/21(job `014c7db74c2e494bab1f1c9e3ea7587e`)과 전체 EditMode 793/793(job `da347340b6a449b0a19a9e14fe1a5ce8`)을 통과했다.

> **DC-R07 상대 악마 정합성 완료 (2026-07-31):** 집행자의 과거 파이몬 계약을 제거하고, 보스 고정 쌍을 `바포메트/마몬 → 아스모데우스/바알제붑 → 아자젤/사탄`으로 교체했다. 기본 적 프로필의 악마 키 합집합이 프로토타입 7종과 정확히 일치하며 제외 악마가 없음을 고정했다. 바알제붑 AI는 양측 모두 가장 높은 숫자의 공개 카드를 버리고, 보스 정책은 아스모데우스 강제 히트 선택을 실제 적 턴 안에서 처리한다. 대상 64/64(job `055fefa7b42d4b99a6c75f4791184642`)·전체 EditMode 821/821(job `594eb19949154bdfaed3f367b3073a62`)을 통과했다.

> **사탄 선택 행동 기획 변경 (2026-08-01, DC-R09 코드 반영):** 소유자는 정상 차례에 허용된 일반 행동 또는 현재 면 능력 중 하나를 선택한다. 일반 행동은 면을 유지하고, 능력이 유효하게 완료된 경우에만 차례를 소비하며 반대 면으로 전환한다. 실패·취소 입력은 상태를 보존한다. 적도 능력을 강제 사용하지 않고 일반 행동과 비교한다. 기존 DC-R02의 차례 종료 자동 전환·강제 능력 사용 검증은 당시 구현 증거다.

> **레비아탄 현행 정정 (2026-07-29)**

> **현행 적 계약 (2026-07-30)**
> 광신도는 첫 정상 차례부터 성공까지 계약을 재시도하고, 집행자는 악마를 보유하지 않으며, 보스는 전투 시작·영혼 5·2에서 바포메트→아스모데우스→아자젤 단계로 전환한다. 과거 집행자 파이몬 구현은 아래 완료 기록으로만 보존한다.

> **DC-V01 GameScene 월드 후보 (2026-07-30)**
> 일반 계약 1~2장은 화면 하단 반노출 월드 카드로 표시한다. `CONTRACT`는 확인창 없이 즉시 시작하고, 후보 호버 시 전진·상승·확대와 SO 기반 제목·앞면·`ACTIVE`·`COST` 상세를 표시한다. 후보 선택 중 월드 후보 호버·클릭, 카메라 `W`·`S`, 일시정지 외 입력은 잠근다. 루시퍼 다중 후보는 기존 옵션 UI를 유지한다.

## 1. 기록 원칙

- 계획과 실제 구현을 분리한다.
- 코드가 없는 문서 단계는 구현 완료로 기록하지 않는다.
- 단계마다 작업자, 변경 파일, 직접 결정한 문제, 대상·전체 테스트와 실제 화면 결과를 남긴다.
- AI 대화 원문은 복사하지 않고 목적, 주요 지시, 결과와 사람의 결정을 기술적으로 정리한다.
- 기획·코드·검증의 최종 승인 책임자는 이천서로 기록한다.
- 팀원의 예정 업무는 실제 변경과 검증이 확인되기 전까지 완료 기여로 기록하지 않는다.
- 사용자의 명시적 요청 전에는 스테이징·커밋하지 않는다.

## 21. DC-R09 사탄 선택형 능력 이관

### 21.1 구현

- `SatanRuntimeState`의 소유자 정상 차례 종료 자동 전환을 제거했다.
- 유효한 윗면 두 숫자 선언 또는 아랫면 강제 히트 후속 처리가 완료된 경우에만 현재 면을 전환한다.

- 광신도·보스는 활성 사탄 능력과 일반 행동을 함께 평가한다. 안전한 일반 히트를 우선하고 공개 합이 높아 히트가 위험할 때 사탄 능력을 선택한다.

- 런타임 카탈로그와 `satan.asset` 설명을 선택형 규칙으로 갱신했다.
