# 테이블 도감 설계

## DX-M02: 적 정보 페이지 레이아웃 개편

- 책 배경, 탭, 닫기, `Q/E`, 악마 카드 페이지는 유지하고 적 정보 페이지만 참고 이미지 구성으로 재배치한다.
- 왼쪽은 이름, 프레임 초상화, 영혼/골드 정보, 설명, 계약 가능 악마 순서다.
- 오른쪽 시작 덱은 116×164 카드, 4열, 세로 전용 스크롤로 표시한다.
- `CodexFrame_0`, `CodexFrame_2`, `CodexOutline_0`, 별도 `SoulIcon`/`GoldIcon`을 사용한다.
- 긴 덱은 페이지 안에서 스크롤하며 페이지 렌더 때 항상 최상단으로 돌아간다.

## 목적

GameScene의 테이블 책을 눌러 전투·상점 위에 펼친 책 형태의 도감을 표시한다. 규칙값과 저장 데이터는 바꾸지 않고 적·카드 SO가 생성한 런타임 카탈로그를 읽기 전용으로 보여 준다.

## 결정

- 적 6종과 악마 카드 12종은 처음부터 모두 공개한다.
- 우측 책갈피는 `적 정보`, `악마 카드` 두 카테고리를 즉시 전환한다.
- `Q/E`는 현재 카테고리 안에서 한 페이지만 이동하며 경계에서 멈춘다.
- 카테고리별 마지막 페이지는 같은 GameScene 세션 동안 유지한다.
- 도감은 전투와 상점에서만 활성화한다. 시작 악마 공개, 상대 선택, 결과 화면에서는 테이블 책을 숨긴다.
- 도감이 열리면 전투·상점·HUD·카메라 전환 입력을 막되 `Time.timeScale`은 바꾸지 않는다.
- 도감과 덱 미리보기는 동시에 열리지 않는다. `Escape`는 Pause 메뉴보다 먼저 도감을 닫는다.
- 열기·닫기·페이지 전환 애니메이션과 효과음은 사용하지 않는다.
- 도감 전용 콘텐츠 카탈로그는 두지 않는다. 적 정보는 적 프로필 SO, 악마 서사는 해당 악마 카드 SO가 소유한다.

## 표시 구성

- 적 페이지 왼쪽: 이름, 초상화, 최대 영혼, 처치 골드, 설명, 계약 가능 악마.
- 적 페이지 오른쪽: 실제 시작 덱 장수만큼 카드 표시. 긴 덱은 ScrollRect로 스크롤한다.
- 악마 페이지 왼쪽: 이름, 큰 카드 이미지, 구매 골드, 기본 영혼 가격, 서사 설명.
- 악마 페이지 오른쪽: 액티브 스킬과 대가.
- 중복 숫자 덱 카드는 실제 전투 덱 생성 규칙과 같이 스페이드/클로버를 번갈아 표시한다.

## 아트

AI 생성한 투명 PNG 3종을 사용한다: 펼친 양피지 책, 닫힌 가죽 책, 붉은 책갈피. 이미지에는 글자·아이콘·로고를 넣지 않고 모든 문자는 TMP로 렌더링한다.

## 범위 밖

해금, 미발견 실루엣, 영구 저장, 저장 스키마 변경은 포함하지 않는다.
