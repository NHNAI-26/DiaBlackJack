## 1. 문서 목적

지도 없이 `전투 → 이벤트 → 전투 → 이벤트 → 보스`로 진행하는 정식 런을 구현할 기획 기준과 분업 경계를 확정한다. 최신 `rule.md`에 따라 이 문서에서 말하는 이벤트는 첫 개발에서는 **상점으로 고정**한다. 무작위 사건은 첫 정식 런이 안정된 뒤 확장한다.

> **시작 악마 지급 구현(2026-07-31):** 새 런 생성 시 사탄·벨페고르·바알제붑·마몬 기본 풀에서 서로 다른 2장을 한 번만 추첨해 모두 지급한다. UI는 입력 없이 두 장을 배치·동시 공개하고, 지급 결과 저장 성공과 공개 연출 종료 뒤 첫 상대 선택으로 자동 이동한다. 재접속은 예약된 같은 두 장을 복구하며 재추첨하지 않는다.

기획 결정과 최종 통합 승인은 이천서가 담당한다. 최초 HONG 인계 범위였던 런 골드, 전투 후 상점, 정식 순서 연결과 진행 화면은 이천서가 구현·검증을 인수했다. 계획 역할과 실제 구현 기여는 진행 기록에서 구분한다.

> **GSV-09 공용 기본 버튼 결정 (2026-08-04)**
> 현재 상점 나가기의 `Brush_UI_9` 외형을 시각 전용 `DefaultButton.prefab`으로 분리한다. 표준 Unity `Button`·`Image`·TMP 라벨만 사용하고 별도 래퍼나 로컬라이제이션 의존성을 만들지 않는다. 첫 사용처는 상점 나가기 하나이며, 클릭·활성·숨김 흐름은 기존 `GameHudView`와 `GameManager` 계약을 그대로 유지한다.

## 3. 정식 플레이 순서

사용자가 말한 `전투 → 이벤트 → 전투 → 이벤트 → 보스`를 실제 화면 단위로 풀면 다음과 같다.

```text
런 시작 전 사탄·벨페고르·바알제붑·마몬 풀에서 서로 다른 악마 카드 2장을 한 번 추첨해 모두 지급
→ 런 시작(영혼 12, 골드 0, 악마 덱 최소 1장)
→ 상대 후보 2명 중 1명 선택
→ 첫 번째 전투
→ 선택한 적에 따른 골드 지급
→ 첫 번째 상점
→ 상대 후보 2명 중 1명 선택
→ 두 번째 전투
→ 선택한 적에 따른 골드 지급
→ 두 번째 상점
→ 고정 최종 보스 전투
→ 보스 골드 지급과 최종 결과 기록
→ 런 승리
```

- 일반 전투 후보는 `일반+일반` 또는 `일반+엘리트`다.
- 보스는 후보 선택 없이 고정 진입한다.
- 일반전 뒤 별도의 무료 카드 보상 화면은 열지 않는다. 카드 획득은 상점 구매로 통합한다.
- 전투 사이에 자동 영혼 회복은 없다. 상점에서 골드를 지불한 휴식만 회복한다.
- 플레이어 영혼이 전투 중 0이 되면 골드와 상점 없이 런 패배다.
- 보스 승리 뒤에는 카드 보상과 상점이 없다.
- 분기 지도는 만들지 않는다.

## 4. 포함·제외 범위

### 4.1 포함

- 런 골드 보유·지급·소비·재시작 초기화
- 적 프로필별 승리 골드
- 전투 승리 확정 뒤 골드 1회 지급
- 두 일반 전투 뒤 상점 1회씩, 총 2회
- 상점의 카드 구매, 카드 제거, 유료 휴식과 무료 나가기
- 상점 완료 뒤 다음 상대 선택 또는 고정 보스 진입
- 기존 `StageTest` 진행 화면과 월드 공간 `GameScene` 전투 화면 재사용
- 잘못된 ID·중복 구매·중복 지급·오래된 입력의 무변경 거부
- 런 승리·패배·재시작과 반복 검증

### 4.2 제외

- 무작위 사건과 상점/사건 가중치
- 독립 휴식 노드
- 카드 강화와 유물 구매
- 상점 재입고·새로고침과 플레이어 카드 판매
- 분기 지도와 경로 선택
- 저장 데이터의 파일 형식·버전 마이그레이션과 메타 성장 구현
- 전투 규칙·적 AI·카드 효과·보상 풀 변경
- 새 이벤트 전용 씬과 최종 아트·사운드·연출

카드 강화는 숫자가 아니라 효과 강화가 필요해 현재 카드 정의·효과 계약의 별도 작업이므로 RF에서 가짜 단계나 플래그를 만들지 않는다.

## 4.3 체크포인트 저장

저장은 선택·전투·거래 도중의 임시 상태가 아니라 다음의 완료 상태에서만 갱신한다.

1. 시작 악마 2장 무작위 지급과 시작 덱 반영 완료
2. 전투 승리 뒤 골드 정산 완료
3. 상점 거래를 마치고 `상점 나가기` 완료
4. 무작위 사건의 선택과 결과 처리 완료
5. 보스 승리 또는 런 패배 결과 확정

상점 이용 중 종료하면 직전 골드 정산 체크포인트로 돌아오되 같은 상품과 서비스 상태를 재현한다. 사건 선택 중 종료해도 같은 사건이 다시 나타나야 한다. 이를 위해 상점·사건 후보의 안정 ID 또는 결정적 런 시드를 체크포인트에 포함한다. 전투 손패, 덱 순서, 계약·사건 선택 대기와 연출 상태는 저장하지 않는다.

## 5. 골드 규칙

### 5.1 공통

- 런 시작 골드는 0이다.
- 골드는 현재 런 동안 유지하고 상점에서만 사용한다.
- 승리한 실제 `BattleProfileKey` 하나로 지급량을 조회한다.
- 골드는 끝난 전투의 플레이어 승리를 정식 런 세션이 처음 동기화한 순간 정확히 한 번 지급한다.
- 패배, 끝나지 않은 전투, 이미 정산한 전투와 잘못된 입력에는 지급하지 않는다.
- 보스 골드는 최종 런 결과에는 포함하지만 사용할 상점은 열지 않는다.
- 재시작하면 골드 0과 최초 상점 상태로 돌아간다.

## 6. 상점 규칙

### 6.1 상점 생성과 유지

- 상점은 첫째·둘째 일반 전투의 골드 정산 완료 뒤 정확히 한 번 연다.
- 한 번 만든 상품과 가격은 화면 재진입으로 바뀌지 않는다.
- 상점은 안정적인 `ShopOfferId`와 방문 번호 0 또는 1을 가진다.
- 판매 카드는 서로 다른 상품 슬롯 5개로 생성한다. 왼쪽 3칸은 자동 발동 카드를 포함할 수 있는 일반 카드, 오른쪽 2칸은 악마 카드로 비율과 위치를 고정하며 각 슬롯의 재고는 1개다.
- 플레이어는 가능한 서비스를 원하는 순서로 이용한 뒤 `상점 나가기`를 선택한다.
- 카드를 구매하면 해당 카드만 각각 일반 카드 덱 또는 악마 카드 덱에 추가한다. 해당 카드는 같은 슬롯에 어둡게 남기고 중앙에 `SOLD OUT`을 겹쳐 표시하며, 아래 가격은 같은 위치에 회색으로 유지한다. 구매하지 않은 카드와 서비스 상태는 유지된다. 방문 전체 카드 구매 상한은 없으므로 골드가 충분하면 재고가 남은 카드 슬롯을 모두 살 수 있다.
- 상품 새로고침과 재입고는 제공하지 않는다.
- 나가기는 무료이며 항상 가능하다.
- 나간 상점에는 다시 들어갈 수 없다.
- 두 번째 상점에서 나가면 상대 선택 없이 보스 전투로 간다.

### 6.2 프로토타입 상품·서비스

| 항목 | 가격 | 효과 | 방문당 제한 |
| --- | --- | --- | --- |
| 일반 카드 | 미정 | 기본·수동·자동 발동 카드 통합 풀에서 서로 다른 3장을 제시하고 구매한 카드를 일반 카드 덱에 추가 | 상품당 재고 1개 |
| 악마 카드 | 미정 | 프로토타입 악마 7종 중 현재 판매 가능한 서로 다른 2장을 제시하고 구매한 카드를 악마 카드 덱에 추가 | 상품당 재고 1개 |
| 라이터 | 기본값·상승폭 조정 가능 | 현재 일반 카드 덱에서 선택한 카드 1장을 태워 제거 | 1회 |
| 위스키 | 기본값·상승폭 조정 가능 | 조정 가능한 수치만큼 영혼 회복, 최대 영혼 초과 불가 | 1회 |
| 상점 나가기 | 0골드 | 상점을 끝내고 다음 진행으로 이동 | 항상 |

- 판매 카드 5장은 상점 입장 시 일반 3장·악마 2장으로 한 번 생성하고 재추첨하지 않는다.
- 일반 카드 풀에는 독극물·부활초·거짓말 탐지기·화염 방사기·회중시계를 포함한다. 같은 방문에서 정의 키를 중복 제시하지 않는다.
- 엘리트 승리 뒤 상점은 높은 등급 일반 카드의 출현 가중치를 일반전보다 높인다. 정확한 가중치는 플레이 테스트로 확정한다.
- 구매한 카드 슬롯은 카드·가격·위치를 유지한 `SOLD OUT` 상태가 되며 다시 채우거나 재정렬하지 않는다.
- 골드와 조건이 허용하면 같은 방문에서 라이터와 위스키를 각각 한 번 모두 이용할 수 있다.
- 둘 중 하나 이상 이용한 방문은 다음 상점부터 두 서비스의 가격 단계를 함께 1 올린다. 하나만 이용한 방문과 둘 다 이용한 방문의 상승폭은 같고, 둘 다 이용해도 2단계 오르지 않는다.
- 어느 서비스도 이용하지 않은 방문은 가격 단계를 올리지 않는다. 누적 단계는 런 동안 유지하고 새 런에서 0으로 초기화한다.
- GameScene MVP는 두 서비스 기본 가격 2골드와 이용 방문당 공통 +1골드를 사용한다. 이 수치는 조정 가능한 프로토타입 값이며, 콘셉트 이미지의 10·11·20·30·50 등은 밸런스 값으로 사용하지 않는다.
- 카드 제거 뒤에도 런 덱은 최소 1장을 유지한다.
- 제거한 카드 ID는 같은 런에서 다시 사용하지 않는다.
- 회복할 영혼이 0이어도 휴식은 비활성화해 골드를 낭비하지 않는다.
- 각 서비스는 골드·대상·방문당 제한을 모두 검증한 뒤 비용과 효과를 한 번에 적용한다.
- 골드가 부족하거나 대상이 잘못되면 아무것도 바뀌지 않는다.

| 전투 | `GameScene` | 기존 전투 행동 | 실제 게임은 일반전 골드 결과 뒤 같은 `GameScene`의 진행·상점 화면, 보스는 런 승리, 패배는 런 패배. `StageTest` 직접 실행 경로만 기존 StageTest 복귀 유지 |
| 상점 | `StageTest` | 구매·제거·휴식·나가기 | 다음 상대 선택 또는 보스 |
| 런 종료 | `StageTest` | 재시작 | 첫 상대 선택 |

![상점 플레이 화면 콘셉트](./images/shop-screen-concept-v2.png)

상점마다 새 공간으로 이동하지 않는다. 정식 화면에서는 전투와 상점이 고정 카메라의 같은 서부 시대 술집 테이블을 공유한다. 전투가 끝나면 적과 전투 오브젝트를 정리하고, 적이 있던 자리에 어두운 상인을 작게 배치해 테이블이 화면의 주체로 남게 한다.

- 좌측 상단 화면 UI에는 현재 골드와 영혼을 표시한다.
- 테이블 상단 상품열은 왼쪽부터 일반 카드 3칸, 악마 카드 2칸으로 고정한다.
- 모든 카드 아래에 `돈 : {실제 가격}`을 표시한다. 구매한 상품 칸은 카드를 치우지 않고 어둡게 유지하며 중앙에 `SOLD OUT`을 겹쳐 표시하고, 가격표는 같은 위치에 회색으로 남긴다.
- 현재 골드로 살 수 없는 가격만 빨간색으로 표시한다.
- 테이블 좌측 하단의 플레이어 덱을 선택하면 일반 카드 목록을 열고, 라이터로 카드 제거 대상을 고른다.
- 테이블 우측 하단의 위스키는 영혼 회복 서비스다. 실제 회복량은 확정 전까지 표시하지 않는다.
- 라이터와 위스키를 사용하면 해당 방문에서 다시 사용할 수 없도록 사용 완료 상태를 표시한다.
- 라이터와 위스키에는 같은 현재 가격 단계를 반영하고, 다음 상점에서 두 가격이 함께 오른 결과를 표시한다.
- `나가기` 버튼은 일반 상점 상태와 라이터 카드 선택 상태 모두에서 노출한다.
- 라이터는 기존 덱 미리보기 카드 UI를 사용한다. 카드 클릭은 선택 강조만 바꾸고 `확인`에서만 비용 차감과 카드 제거를 수행한다. 닫기·배경·ESC는 재화와 덱을 바꾸지 않는다.
- 하단 문구는 `상점 나가기`로 고정하고 `Brush_UI_9`를 배경으로 사용한다. 라이터 선택 오버레이보다 높은 정렬 순서에서 계속 입력 가능해야 한다.
- 상점 중에는 상대·보상·`NEXT STAGE`·재시작 입력을 숨기거나 비활성화하며 가격, 이용 가능 여부와 최근 거래 결과를 표시한다.

정식 런은 `StageTest` 진행 화면과 `GameScene` 월드 공간 전투 화면을 왕복한다. `CoreLoopTest`는 독립 규칙·IMGUI 검증 씬으로 보존하며 정식 런의 기본 전투 목적지로 사용하지 않는다.

## 9. 완료 조건

- 실제 순서가 `전투→골드→상점→전투→골드→상점→보스→골드→RunVictory`이며 `RewardSelection`을 거치지 않는다.
- 각 승리에는 골드가 한 번만 지급되고 보스 뒤에는 카드 보상과 상점을 만들지 않는다.
- 두 상점에서 자동 발동 카드를 포함할 수 있는 일반 카드 3장·악마 카드 2장의 고정 비율, 슬롯별 `SOLD OUT`, 카드 구매 상한 없음, 새로고침 없음, 라이터·위스키 독립 1회와 무료 나가기가 동작하고 결과가 다음 전투에 반영된다.
- 서비스를 하나 이상 이용한 방문마다 다음 상점의 두 서비스 가격이 한 단계만 함께 오르며, 미이용 방문과 새 런 초기화가 정확히 처리된다.
- 두 일반 전투에는 상대 선택이 있고 보스에는 선택이 없다.
- 패배 시 골드·상점·다음 전투가 생성되지 않는다.
- 재시작 시 영혼·덱·골드·상대·상점 상태가 초기화된다.
- 확정된 체크포인트에서만 저장되고 중도 종료 후 같은 시작 악마·상점·사건 상태로 이어진다.
- 신규 RF 테스트와 기존 CoreLoop·StageProgression 전체 테스트가 통과한다.
- 실제 두 씬 왕복과 1280×720·1920×1080 상점 화면이 통과한다.
- 게임 관련 Unity Console Error·Exception이 없다.
