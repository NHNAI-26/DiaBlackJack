# 1. 게임 개요

플레이어는 악마에게 납치되어 지옥의 블랙잭 대회에 참가한다.

각 스테이지에서는 한 명의 적과 여러 라운드에 걸쳐 블랙잭 대결을 진행한다. 이곳에서는 단순히 21에 가까운 숫자를 만드는 것뿐 아니라 총기, 흉기, 독극물, 마법과 악마의 힘을 사용해 상대를 직접 버스트시키는 행위도 허용된다.

플레이어는 12개의 영혼을 가지고 게임을 시작한다. 플레이어의 영혼은 런 전체에서 유지되며, 일반적으로 적 한 명을 쓰러뜨려도 자동으로 회복되지 않는다.

각 적은 해당 스테이지에서만 사용하는 영혼을 가진다.

- 일반 적: 영혼 2~3
- 강한 일반 적: 영혼 3~4
- 엘리트: 영혼 4~5
- 보스: 영혼 6~8

플레이어 또는 적의 영혼이 0이 될 때까지 블랙잭 라운드를 반복한다.

# 2. 핵심 게임 경험

## 2.1 블랙잭을 이용한 전투

카드 숫자의 합을 21에 가깝게 만드는 기본적인 블랙잭 규칙을 사용한다.

그러나 각 숫자 카드에는 상대의 카드를 제거하거나, 상대를 강제로 히트시키거나, 비공개 카드를 추측하는 전투 효과가 존재한다.

따라서 플레이어는 다음 두 목적 사이에서 판단해야 한다.

- 좋은 숫자 합계를 만든다.
- 카드를 사용해 상대의 상태를 무너뜨린다.

강력한 효과를 가진 카드가 반드시 좋은 숫자를 가진 것은 아니며, 효과를 사용하기 위해 비공개 카드를 공개하는 것도 가능하다.

## 2.2 영혼을 체력과 자원으로 동시에 사용

영혼은 플레이어의 체력인 동시에 악마와 계약하거나 상점을 이용하는 자원이다.

영혼을 사용하면 즉시 강해질 수 있지만, 이후 전투에서 패배할 가능성이 높아진다.

플레이어는 다음과 같은 선택을 반복한다.

- 안전하게 영혼을 보존한다.
- 영혼을 소비해 전투를 빠르게 끝낸다.
- 낮은 영혼 상태를 활용하는 발악 빌드를 구성한다.
- 악마 계약을 반복해 강력한 효과를 얻는다.

## 2.3 악마 계약

플레이어는 자신의 차례에 영혼을 소비해 악마와 계약할 수 있다.

악마는 일반 카드보다 훨씬 강력한 효과를 제공하지만, 반드시 플레이어에게 불리한 대가를 요구한다.

악마 계약은 전투의 규칙을 일시적으로 변경하는 고위험·고효율 행동이다.

일반 카드 덱과 악마 카드 덱은 서로 분리한다. 계약은 악마 카드 덱에서 시작하며, 하나의 전투 스테이지에서는 원칙적으로 1회만 할 수 있다. 카드·유물·악마 효과가 추가 계약을 명시한 특별한 상황만 이 제한의 예외로 처리한다.

## 2.4 상대의 추론을 역이용하는 심리전

적 AI는 **아직 앞면 공개되지 않은** 플레이어 비공개 카드의 숫자나 덱의 다음 카드를 직접 알 수 없다. 카드 사용·효과·계약 등으로 비공개 카드가 앞면 공개되면 그 숫자는 양측이 아는 확정 정보가 된다. 다만 해당 카드는 최종 승부 전까지 비공개 카드 역할을 유지한다.

AI는 다음 정보만을 사용한다.

- 플레이어의 공개 카드
- 이미 사용되거나 버려진 카드
- 현재까지 공개된 카드 숫자
- 플레이어가 사용한 행동
- 활성화된 카드 효과와 악마 계약
- 거짓말 탐지기 등으로 얻은 정보
- 플레이어 덱의 공개된 구성 정보

플레이어는 AI가 현재 어떤 숫자를 의심하고 있는지 일부 확인할 수 있다.

예시:

- 숫자 7일 가능성: 30%
- 숫자 8일 가능성: 25%
- 숫자 5일 가능성: 15%
- 기타 숫자: 30%

AI의 정확한 다음 행동을 항상 공개하지는 않는다.

일부 적은 공격적인 성향, 추측 중심 성향, 안전한 스탠드 성향 등 고유한 사고방식을 가진다.

# 3. 전체 게임 구조

## 3.1 런 시작

플레이어는 다음 상태로 게임을 시작한다.

- 영혼 12
- 기본 일반 덱
- 시작 선택으로 확정된 악마 카드가 최소 1장인 악마 카드 덱
- 기본 유물 또는 캐릭터 특성
- 승점 및 전투 상태 없음

새 런을 시작하기 전에 **사탄·벨페고르·바알제붑·마몬**으로 고정된 시작 후보 풀에서 서로 다른 악마 카드 2장을 제시하고 반드시 1장을 선택한다. 선택한 악마는 시작 악마 카드 덱에 추가되어 모든 런이 악마를 최소 1장 보유하도록 보장한다. 이 선택은 계약이 아니므로 영혼과 전투 스테이지당 계약 횟수를 소비하지 않으며 건너뛸 수 없다.

시작 시 네 악마를 모두 보유하는 방식은 사용하지 않는다. 후보 선정 가중치는 동일하게 두며, 별도 해금·캐릭터 효과가 생기기 전까지 후보 풀을 확장하지 않는다.

## 3.2 스테이지 진행

플레이어는 지도 없이 `전투 → 골드 정산 → 상점/사건 → 전투 → 골드 정산 → 상점/사건 → 보스` 순서의 런을 진행한다. 첫 개발에서는 `상점/사건` 구간을 모두 상점으로 고정한다.

스테이지 종류는 다음과 같다.

- 상대 선택 전투
- 보스 전투
- 전투 후 이벤트: 상점 또는 무작위 사건

일반 전투에 진입하기 전 서로 다른 상대 후보 2명을 제시하고 플레이어가 한 명을 선택한다. 후보 조합은 일반 적 2명 또는 일반 적 1명과 엘리트 1명으로 구성하며, 엘리트 2명을 동시에 제시하지 않는다. 선택한 적과 데블랙잭 게임을 시작한다.

다음 전투가 남아 있는 전투를 승리하면 상대 프로필에 따른 골드를 받은 뒤 별도의 카드 보상 화면 없이 상점 또는 무작위 사건 중 하나로 이동한다. 카드 획득은 상점 상품으로 통합하고, 휴식은 독립 스테이지로 등장하지 않으며 상점에서 골드를 지불해 이용한다.

첫 개발에서는 무작위 사건을 제외하고 모든 전투 후 이벤트를 상점으로 고정한다. 이후 사건 콘텐츠가 준비되면 상점과 무작위 사건 중 하나가 등장하도록 확장한다.

## 3.3 저장과 이어하기

런 저장은 전투나 선택 처리 중간이 아닌 다음의 안정 체크포인트에서만 갱신한다.

- 시작 악마 2장 중 1장 선택을 완료한 뒤
- 전투 스테이지를 클리어하고 골드 정산까지 완료한 뒤
- 상점 거래를 마치고 `상점 나가기`를 선택한 뒤
- 무작위 사건의 선택과 결과 처리를 모두 완료한 뒤
- 보스 승리 또는 플레이어 패배로 런 결과가 확정된 뒤

전투 중, 계약·사건 선택 중, 상점 이용 중에는 새 체크포인트를 만들지 않는다. 이때 게임을 종료하면 마지막 완료 체크포인트에서 이어 한다. 재접속으로 시작 악마 후보, 상점 재고나 사건을 다시 뽑을 수 없도록 이미 생성된 후보·상품·사건 ID 또는 이를 재현하는 런 시드를 저장한다.

저장 상태에는 현재 진행 위치, 영혼·골드, 일반·악마 카드 덱의 구성과 물리 ID, 시작 악마 선택 결과, 완료한 상점·사건과 다음 콘텐츠를 재현할 정보가 포함된다. 전투 중 손패, 덱 순서, 보류 중인 선택과 연출 상태는 저장하지 않는다.

## 3.4 전투 종료

다음 중 하나가 발생하면 전투가 종료된다.

- 적의 영혼이 0이 된다.
- 플레이어의 영혼이 0이 된다.
- 특정 보스의 고유 패배 조건이 충족된다.

## 3.5 런 종료

플레이어의 영혼이 0이 되면 런이 종료된다.

최종 보스를 쓰러뜨리면 별도의 카드 보상과 상점 없이 즉시 런 승리로 확정한다. 보스 골드는 결과 기록에는 포함하지만 현재 프로토타입에는 이를 소비할 후속 구간이 없다.

# 4. 용어 구조

게임의 진행 단위는 다음과 같이 구분한다.

## 런

게임을 시작해 최종 보스를 쓰러뜨리거나 플레이어가 패배할 때까지의 전체 과정이다.

## 스테이지

상대 선택을 포함한 하나의 전투 또는 전투 뒤에 등장하는 상점·무작위 사건 중 하나의 이벤트를 의미한다.

## 라운드

각자 두 장의 카드를 받은 시점부터 한쪽이 버스트하거나 양쪽이 스탠드할 때까지의 과정이다.

한 스테이지에서는 여러 라운드가 진행될 수 있다.

## 차례

라운드 안에서 플레이어나 적이 행동 하나를 선택하는 단위다.

# 5. 영혼 시스템

## 5.1 플레이어 영혼

플레이어는 영혼 12개로 런을 시작한다.

플레이어 영혼은 스테이지가 끝나도 유지된다.

전투에서 승리하더라도 기본적으로 영혼은 회복되지 않는다.

영혼이 0이 되면 런에서 패배한다.

## 5.2 적 영혼

적 영혼은 현재 스테이지에서만 사용된다.

적을 쓰러뜨리면 남은 영혼과 관계없이 해당 적의 영혼은 소멸한다.

적 영혼의 권장 범위는 다음과 같다.

| 적 등급 | 권장 영혼 |
| --- | --- |
| 일반 적 | 2~3 |
| 강한 일반 적 | 3~4 |
| 엘리트 | 4~5 |
| 보스 | 6~8 |

## 5.3 라운드 피해량

현재 프로토타입의 임시 피해량은 다음과 같다.

| 결과 | 플레이어 피해 | 적 피해 |
| --- | --- | --- |
| 플레이어 스탠드 후 합계 비교 패배 | 영혼 1 | 없음 |
| 플레이어 숫자·카드 효과 버스트 | 영혼 2 | 없음 |
| 적 라운드 패배 | 없음 | 영혼 1 |
| 정확히 21로 적에게 승리 | 없음 | 영혼 2 |
| 카드 특수 효과 | 카드별 적용 | 카드별 적용 |

플레이어와 적의 피해량은 비대칭으로 설계한다.

플레이어의 영혼은 런 전체에서 유지되지만, 적의 영혼은 하나의 스테이지에서만 사용되기 때문이다.

피해량은 플레이 테스트 결과에 따라 변경할 수 있다.

# 6. 덱 구조

## 6.1 기본 덱 크기

프로토타입의 플레이어 시작 덱은 16~20장으로 구성한다.

초기 권장 구성은 다음과 같다.

- 숫자 1~10 카드 각 2장
- 총 20장

또는 플레이어 캐릭터에 따라 일부 숫자 카드의 수와 효과를 변경할 수 있다.

## 6.2 덱 빌딩 대상

플레이어는 두 종류의 덱 또는 카드 집합을 성장시킨다.

### 일반 덱

실제 블랙잭 라운드에서 뽑는 숫자 카드 덱이다.

일반 덱에서는 다음 행동이 가능하다.

- 새로운 카드 추가
- 기존 카드 제거
- 카드 강화
- 동일 숫자의 다른 효과 카드로 교체
- 특정 숫자 카드의 수량 조정

### 악마 카드 덱

일반 카드 덱과 별도로 계약 행동에서 등장할 악마를 관리한다.

다음과 같은 성장이 가능하다.

- 새로운 악마 추가
- 악마 제거
- 악마 강화
- 악마의 대가 완화
- 특정 악마의 등장 확률 증가
- 계약 비용 조절

계약 시 악마 카드 덱에서 현재 제시할 수 있는 카드 중 최대 2장을 중앙 선택 영역에 앞면으로 펼쳐 그중 1장을 선택한다. 카드가 1장뿐이면 그 1장만 제시하며, 카드가 없으면 계약할 수 없다. 각 후보를 호버하면 능력과 대가를 함께 표시하고 선택하지 않은 카드가 있으면 악마 버린 카드 더미로 보낸다.

## 6.3 전투 중 덱 순환

전투가 시작될 때 플레이어와 적은 자신의 덱을 섞는다.

각 라운드가 종료되어도 덱을 전부 초기화하지 않는다.

사용된 카드는 버린 카드 더미에 놓는다.

다음 라운드에는 남아 있는 덱에서 카드를 뽑는다.

덱이 모두 소진되면 버린 카드 더미를 섞어 새로운 덱으로 사용한다.

전투가 종료되면 덱과 버린 카드 더미를 초기 상태로 복구한다.

이 구조를 통해 다음 전략이 가능하다.

- 남은 높은 숫자 카드의 수를 계산한다.
- 리볼버가 남아 있을 확률을 추측한다.
- 에이스가 이미 사용되었는지 확인한다.
- 다음 라운드를 위해 특정 카드를 보존한다.
- 덱 순환 속도를 높여 원하는 카드에 다시 접근한다.

# 7. 라운드 규칙

## 7.1 라운드 시작

라운드가 시작되면 플레이어와 적은 각각 자신의 덱에서 카드 2장을 뽑는다.

각자는 두 장을 모두 확인한 뒤 다음과 같이 배치한다.

- 카드 1장: 공개 카드
- 카드 1장: 비공개 카드

적의 비공개 카드는 플레이어에게 보이지 않는다.

플레이어의 아직 앞면 공개되지 않은 비공개 카드는 적 AI가 직접 확인할 수 없다. 앞면 공개된 비공개 카드의 숫자는 적 AI도 확정 공개 정보로 사용한다.

## 7.2 차례 행동

자신의 차례에는 다음 행동 중 하나를 선택한다.

### 히트

덱 맨 위에서 카드 1장을 뽑아 자신의 공개 카드에 추가한다.

### 스탠드

현재 라운드에 더 이상 차례를 진행하지 않는다.

상대 카드 효과에 의해 스탠드가 취소될 수 있다.

### 카드 사용

사용 가능한 카드 한 장의 효과를 발동한다.

비공개 카드도 앞면으로 뒤집어 사용한다. 이때 **앞면·뒷면 표시 상태**와 **공개·비공개 역할**은 서로 다르게 취급한다.

- 사용한 비공개 카드는 숫자와 효과가 양측에 보이지만 최종 승부 전까지 비공개 카드 역할을 유지한다.
- 공개 카드 숫자 합, 중간 버스트, `공개 카드`를 대상으로 하는 효과·계약에는 포함하지 않는다.
- 체인지·비공개 교체·비공개 추측·최종 승부에서는 계속 비공개 카드 한 장으로 취급한다.
- 양측 손패 표시에서는 앞면이 되었더라도 비공개 카드 위치를 유지한다.

### 체인지

자신의 비공개 카드를 버리고 일반 덱 맨 위 카드 2장 자신만 확인한다.

그 중 1장을 새로운 비공개 카드로 받고, 나머지는 버린다.

체인지는 전투 중 자신의 차례라면 여러 번 사용할 수 있지만, 같은 전투에서 사용할수록 영혼 비용이 증가한다.

| 해당 전투의 체인지 횟수 | 영혼 비용 |
| ---: | ---: |
| 1회 | 0 |
| 2회 | 1 |
| 3회 | 2 |
| 4회 | 3 |

이후에도 `현재 전투에서 이미 완료한 체인지 횟수`만큼 영혼을 지불한다. 비용은 라운드가 바뀌어도 유지하고 다음 적과의 전투가 시작되면 0으로 초기화한다. 비용을 지불한 뒤에도 영혼이 최소 1 남아야 하므로, 현재 영혼이 비용보다 많지 않으면 체인지를 시작할 수 없다.

체인지를 승인하면 기존 비공개 카드는 공개된 상태로 버린다. 후보를 확인한 뒤에는 취소할 수 없으며, 후보 선택을 완료하면 체인지 1회가 끝난 것으로 보고 플레이어의 차례를 소비한다.

적도 자신의 비공개 역할 카드가 앞면 공개되었거나, 그 비공개 숫자를 포함한 자신의 예상 최종 합이 21을 초과하면 체인지를 시도한다. 공개 카드 합이 21을 초과한 뒤에는 기존 규칙상 즉시 버스트되어 행동 창이 없으므로, 여기서 `21 초과`는 적이 알고 있는 자기 비공개 카드까지 포함한 예상 최종 합을 뜻한다. 두 조건에 모두 해당하지 않으면 일반 AI는 체인지를 자발적으로 사용하지 않는다. 적은 플레이어의 비공개 정보가 아니라 자신의 손과 공개 정보만 사용하며, 현재 영혼이 비용보다 많고 후보 2장을 확보할 수 있을 때만 시작한다.

적은 후보 중 `최종 합 21 이하 → 21에 가까운 후보 → 같은 합이면 먼저 제시된 후보` 순으로 선택한다. 두 후보가 모두 21을 넘으면 최종 합이 더 낮은 후보를 고르고, 동률이면 먼저 제시된 후보를 고른다. 선택 카드는 새 비공개 역할 카드로 뒷면 배치하고 미선택 후보는 버린다. 모든 적은 공통 누적 비용을 사용하되 사기꾼만 사용 횟수와 무관하게 매회 영혼 1을 지불한다.

### 계약

테이블의 악마 카드 덱을 선택해 계약을 시작한다. 별도의 중앙 계약 오브젝트는 사용하지 않는다. 비용을 지불하기 전에는 확인과 취소가 가능하지만, 후보가 공개된 뒤에는 반드시 하나를 선택한다.

영혼 1개를 버린다. 내 악마 카드 덱에서 최대 2장을 하스스톤의 `발견`처럼 중앙에 제시한다. 카드가 2장이면 그중 하나와 계약하고 나머지 1장은 악마 버린 카드 더미로 보낸다. 카드가 1장이면 해당 카드만 제시하며, 악마 카드가 없으면 계약을 시작할 수 없다.

악마는 강력한 능력과 그에 상응하는 대가를 제공한다.

선택한 악마 카드는 일반 카드와 같은 크기의 앞면 카드로 플레이어 앞 계약 영역에 놓는다. 카드를 호버하면 능력과 대가를 함께 표시한다. 계약 효과는 해당 스테이지가 종료될 때까지 적용된다.

계약은 하나의 전투 스테이지에서 원칙적으로 1회만 할 수 있다. 카드·유물·악마 효과가 추가 계약을 명시한 경우에만 예외로 허용한다.

기본 계약 비용은 지불 후 영혼이 최소 1 남아야 하므로 현재 영혼이 비용보다 많을 때만 지불할 수 있다. 계약 이후 악마의 개별 대가는 보유 영혼을 0까지 감소시킬 수 있으며, 영혼이 0이 되는 순간 해당 전투에서 즉시 사망한다. 사망이 확정되면 남은 효과와 차례를 처리하지 않는다.

악마 카드 문구의 `할 수 있다`는 효과 소유자가 실행 여부를 선택한다는 뜻이다. 문구의 `버스트`는 숫자 초과뿐 아니라 카드·악마·계약 효과와 특수 패배 조건으로 발생하는 모든 버스트를 포함한다. 단, 영혼 0으로 인한 사망은 버스트가 아니라 전투 패배다.

추가 계약이 허용된 상황에서는 이미 활성화된 악마와 같은 악마를 다시 선택할 수 있다. 동일 악마 계약은 각각 별도의 계약 인스턴스로 유지하며, 구체적인 효과·대가의 중첩 순서와 수치는 악마별 문구를 따른다.

악마 계약이 숫자가 적힌 특수 카드를 공개 영역에 생성하면 그 숫자를 블랙잭 합계에 포함한다. 카드가 뒤집혀 숫자가 바뀌면 바뀐 숫자로 즉시 합계를 다시 계산한다.

계약이 생성·이동·추방한 카드는 현재 전투의 여러 라운드에 걸쳐 유지하지만 런 덱을 영구 변경하지 않는다. 라운드 종료 시에는 현재 소유자의 일반 카드와 같은 방식으로 버린 카드 더미에 들어가거나 명시된 추방 상태를 유지한다. 전투 종료 시에는 다음과 같이 원상복구한다.

- 바포메트의 오망성처럼 계약이 생성한 특수 카드는 모든 전투 위치에서 제거한다.
- 파이몬이 추방한 카드는 원래 소유권과 전투 시작 덱 구성을 복구한다. 플레이어 런 덱에는 제거를 반영하지 않는다.
- 벨리알이 가져온 카드는 전투 중 벨리알 계약 소유자의 카드로 취급하고 라운드 종료 시 그 소유자의 버린 카드 더미로 보낸다. 전투 종료 시에는 원래 소유권으로 복구한다.
- 활성 계약, 계약별 카운터와 임시 선택 상태는 전투 종료 시 제거한다.

적이 계약할 때도 비용, 선택, 효과, 대가, 중첩과 전투 종료 정리 규칙을 플레이어와 동일하게 적용한다.

## 7.3 자동 발동 카드

자동 발동 카드가 공개 카드에 추가되면 즉시 효과를 처리한다.

**라운드 시작 시 최초 카드 분배에서는 자동 발동이 적용되지 않는다.**

효과 처리 후 카드의 위치는 카드별 규칙을 따른다.

## 7.4 버스트

다음과 같은 상황에서 버스트될 수 있다.

- 히트·강제 히트·카드 효과 등 라운드 진행 중에는 공개 카드 숫자 합이 21을 초과한다.
- 양쪽 모두 스탠드한 최종 승부에서는 비공개 카드를 포함한 전체 카드 숫자 합이 21을 초과한다.
- 카드 효과가 대상을 버스트시킨다.

비공개 카드 숫자는 앞면 공개 여부와 관계없이 양쪽 모두 스탠드하기 전의 중간 버스트 판정에 포함하지 않는다. 최종 승부에서 비공개 카드 역할의 카드를 포함한 전체 합계와 최종 버스트를 계산한다.

본 게임에서 `[버스트]`는 단순한 숫자 초과만을 의미하지 않는다.

카드나 악마 효과로 해당 라운드에서 탈락하는 모든 결과를 통합해 버스트라고 부른다.

버스트한 대상은 즉시 해당 라운드에서 패배한다.

# 8. 라운드 종료

다음 중 하나가 발생하면 라운드가 종료된다.

- 플레이어가 버스트한다.
- 적이 버스트한다.
- 양쪽 모두 스탠드한다.

## 8.1 버스트

한쪽이 버스트하면 즉시 승패를 처리한다.

- 플레이어 버스트: 플레이어 영혼 2 감소
- 적 버스트: 적 영혼 1 감소
- 카드 효과에 별도의 영혼 피해가 있으면 추가 적용

## 8.2 양쪽 스탠드

양쪽 모두 비공개 카드를 공개한다.

각자의 카드 숫자 합을 계산한다.

에이스는 1 또는 11 중 합계가 21 이하에서 가장 커지는 값을 자동으로 선택한다.

다음 순서로 승자를 결정한다.

1. 21을 넘은 대상은 일반 승리 대상에서 제외한다.
2. 21 이하에서 21에 더 가까운 대상이 승리한다.
3. 양쪽 모두 21을 넘었다면 21에 더 가까운 대상이 승리한다.
4. 무승부일 경우 일반적으로 플레이어의 승리로 간주한다.

스탠드 후 합계 비교에서 플레이어가 패배하면 플레이어 영혼 1을 잃는다. 적이 패배하면 적 영혼 1을 잃는다.

## 8.3 정확히 21

플레이어가 정확히 21로 라운드에서 승리하면 적에게 영혼 피해 2를 준다.

# 9. 전투 종료와 회복

## 9.1 승리

적의 영혼이 0이 되면 해당 스테이지에서 승리한다.

전투에서 승리해도 플레이어 영혼은 자동으로 회복되지 않는다.

플레이어는 상점의 휴식, 특정 카드·유물 또는 무작위 사건을 통해 회복 수단을 확보해야 한다.

## 9.2 패배

플레이어의 영혼이 0이 되면 런이 종료된다.

## 9.3 선택적 회복 수단

자동 회복은 제공하지 않지만 다음과 같은 선택형 회복 수단을 제공한다.

- 상점에서 골드를 지불하고 휴식
- 특정 유물의 조건부 회복
- 특정 카드 또는 악마 효과를 통한 회복
- 사건을 통한 대가성 회복

회복은 항상 다른 성장 선택지를 포기하거나 자원을 소비하도록 설계한다.

# 10. 일반 카드

카드 문구는 현재 버전을 유지하며, 구현 및 테스트 과정에서 표현을 정리한다.

## 1: 에이스 카드

`(P) 패시브`라운드 종료 시 1과 11 중 카드 숫자의 합이 21 이하에서 가장 큰 값이 되도록 자동으로 선택된다.

## 2, 3, 4: 효과 없음

## 5: 수정 구슬

덱 맨 위 카드 2장을 자신만 확인한다.

그중 0~1장을 선택해 자신의 공개 카드에 추가한다.

나머지는 덱에 돌려놓는다.

## 6: 위협용 해머

상대의 공개 카드 1장을 선택해 버린다.

상대가 스탠드 상태였다면 다음 효과를 추가로 적용한다.

- 상대의 스탠드를 취소한다.
- 상대의 비공개 카드를 버린다.
- 상대가 덱 맨 위에서 새로운 비공개 카드를 뽑게 한다.

상대에게 공개 카드가 없다면 사용할 수 없다. 이 효과는 자신의 공개 카드를 비용으로 요구하지 않는다.

## 7, 8: 리볼버

숫자 하나를 선언한다.

선언한 숫자와 상대의 비공개 카드 숫자가 같다면 상대를 버스트시킨다.

## 9, 10: 보위 나이프

상대의 공개 카드 합이 16 이하라면 상대를 강제로 히트시킨다.

그 결과 상대의 공개 카드 합이 21을 넘지 않았다면 방금 추가된 카드를 즉시 버린다.

# 11. 악마 카드

## 11.0 프로토타입 등장 범위

프로토타입에서 실제로 획득·계약·적 보유·상점 판매될 수 있는 악마는 다음 7종으로 한정한다.

- 사탄
- 벨페고르
- 바알제붑
- 아스모데우스
- 마몬
- 바포메트
- 아자젤

루시퍼·레비아탄·메피스토펠레스·파이몬·벨리알을 포함해 위 목록에 없는 악마는 프로토타입에서 제외한다. 제외 악마의 기존 카드 규칙과 구현 기록은 향후 콘텐츠 후보 및 과거 검증 자료로만 보존하며, 플레이어·적·시작 선택·상점·무작위 생성 풀에는 넣지 않는다.

아래 개별 악마 설명 중 제외 악마 항목은 **비활성 보관 기획**이다. 현행 프로토타입의 출현 규칙보다 우선하지 않는다.

아래 악마의 능력과 대가는 별도 문구가 없는 한 현재 전투가 끝날 때까지 유지한다. 선택형 문구, 버스트 범위, 동일 악마 중첩과 임시 카드의 수명은 7.2의 계약 공통 규칙을 따른다.

## 사탄

`(P) 패시브`

스탠드할 수 없으며 어떠한 이유로도 버스트되지 않는다.

사탄 계약 상태는 윗면으로 시작하고, 계약 소유자의 차례가 끝날 때마다 `윗면 ↔ 아랫면`으로 전환된다. 이는 일반 카드의 앞면/뒷면 공개 상태나 물리 카드 뒤집기와 다른 규칙 상태다.

- 윗면: 자신의 차례에 숫자 두 개를 선언한다. 두 숫자 중 하나라도 상대의 비공개 카드 숫자와 같으면 상대를 버스트시킨다.
- 아랫면: 상대를 강제로 히트시킨다. 그 결과 상대의 공개 카드 합이 21을 넘지 않았다면 방금 추가된 카드를 즉시 버린다.

계약 직후 종말 카운트 4를 얻는다. 계약 소유자의 차례를 시작할 때마다 종말 카운트가 1 감소한다.

### 대가

종말 카운트가 0이 된 차례 시작 시 영혼 2개를 잃는다. 이 대가는 0 도달 시 한 번만 적용한다.

## 벨페고르

`(P) 패시브`

자신의 차례마다 히트하기 전 덱 맨 위 카드 1장을 확인한다. 다음 중 하나를 선택한다.

- 확인한 카드를 그대로 히트한다.
- 확인한 카드를 덱 맨 아래에 넣고 차례를 넘긴다.

### 대가

상대가 스탠드했다면 자신의 다음 차례 종료 시 스탠드한다.

## 바알제붑

`(P) 패시브`

버스트되어야 할 때 영혼 1개, 자신의 공개 카드 1장과 상대의 공개 카드 1장을 버리고 생존한다.

계약 소유자가 자신의 공개 카드 1장과 상대의 공개 카드 1장을 각각 선택해 버린다. 영혼 1을 먼저 지불하고, 이 대가로 소유자의 영혼이 0이 되면 즉시 사망한다. 이때는 카드 선택·버림과 남은 효과를 처리하지 않는다. 영혼이 남은 경우에만 두 장을 선택하며, 선택 도중 카드 상태가 달라진 오래된 입력은 아무 상태도 바꾸지 않고 거절한다.

### 대가

자신의 공개 카드가 3장 이하라면 스탠드할 수 없다.

## 아스모데우스

`(P) 패시브`

자신의 차례를 시작할 때마다 상대가 스탠드하지 않았다면 상대를 히트시킬 수 있다.

### 대가

7 이하의 카드는 카드 사용을 할 수 없다.

## 루시퍼

계약 즉시:

무작위 악마 카드 5개 중 하나를 선택해 계약할 수 있다.

### 대가

영혼 1개를 잃는다.

루시퍼로 선택한 악마의 능력과 대가도 모두 적용한다.

구현 기준에서는 현재 계약 소유자의 악마 덱에 남은 카드 중 최대 5장을 후보로 제시한다. 5장보다 적으면 남은 수만 제시하고, 남은 카드가 없으면 추가 계약 없이 효과를 끝낸다. `계약할 수 있다`는 선택 문구이므로 후보가 있어도 추가 계약을 건너뛸 수 있으며, 선택하지 않은 후보는 악마 버린 카드 더미로 이동한다.

루시퍼의 기본 계약 비용·전투당 사용 횟수는 최초 계약을 열 때 한 번만 적용한다. 추가로 고른 악마는 별도 물리 계약 인스턴스로 활성화하고 그 악마의 능력과 개별 대가만 적용한다. 같은 악마와 다른 루시퍼도 선택할 수 있으며, 각 루시퍼는 남은 악마 덱에서 독립적으로 후보를 만든다. 루시퍼의 영혼 1 대가나 선택 악마의 대가로 영혼이 0이 되면 즉시 사망하고 남은 선택 처리를 중단한다.

## 마몬

계약 즉시:

6면체 주사위를 굴린다.

`(P) 패시브`

자신의 차례에 일반 행동 대신 주사위를 다시 굴리고 차례를 끝낼 수 있다. 라운드 종료 직전 주사위 숫자를 자신의 카드 합에 더할지 결정한다.

### 대가

주사위가 6이 나오면 버스트된다.

## 레비아탄

`(P) 패시브`

자신이 사용하는 `리볼버`의 첫 예측이 실패하면 같은 카드로 한 번 더 예측할 수 있다. 두 번째 예측은 별도의 선언을 사용하며 일반 리볼버와 같은 성공·실패 판정을 따른다.

### 대가

첫 예측이 성공하면 두 번째 예측과 대가를 생략한다. 첫 예측과 두 번째 예측이 모두 실패하면 영혼 1개를 잃으며, 이로 인해 영혼이 0이 되면 즉시 사망한다.

## 메피스토펠레스

`(P) 패시브`

이제부터 자신이 사용하는 모든 `보위 나이프` 카드에 다음 효과를 추가한다.

- 보위 나이프 사용 결과 상대의 공개 카드 합이 21을 넘었다면 상대를 버스트시킨다.

### 대가

`보위 나이프`를 사용했을 때 상대가 버스트되지 않았다면 자신의 비공개 카드를 공개한다.

## 파이몬

`(P) 패시브`

상대가 버스트할 때마다 내 덱 또는 상대의 덱 맨 위 2장을 자신만 확인한다.

확인한 카드 중 원하는 카드를 현재 전투가 끝날 때까지 추방할 수 있다. 추방한 카드는 전투 중 덱·손·버린 카드 더미로 돌아오지 않으며 전투 종료 시 원래 소유권과 전투 시작 덱 구성을 복구한다. 플레이어 런 덱에는 제거를 반영하지 않는다.

### 대가

라운드 종료 시 카드 숫자의 합이 18 이하라면 버스트된다. 이 효과는 다른 모든 승패 조건보다 우선한다.

파이몬 능력의 카드 확인·추방 선택을 먼저 끝낸 뒤 기존 라운드 결과의 임시 승자를 정하고, 그 임시 승자가 파이몬 계약자일 때만 위 대가를 한 번 판정한다. 이 대가로 임시 승자가 버스트되면 승패를 반전하며, 새 승자의 파이몬 대가나 새로 발생한 상대 버스트 능력은 같은 라운드에서 다시 연쇄하지 않는다. 이 단일 판정 규칙은 양측 파이몬의 무한 반전을 막기 위한 프로토타입 결정이며 플레이 테스트 뒤 재검토한다.

## 벨리알

계약 즉시:

자신의 공개 카드를 모두 버린다.

`(P) 패시브`

자신의 차례를 시작할 때마다 상대의 공개 카드를 자신의 공개 카드로 옮길 수 있다.

가져온 카드는 이미 사용된 카드라도 즉시 사용한다.

가져온 카드는 현재 전투 동안 벨리알 계약 소유자의 카드로 취급한다. 라운드 종료 시 벨리알 계약 소유자의 다른 카드와 함께 그 소유자의 버린 카드 더미로 보내며, 전투 종료 시 원래 소유권으로 복구한다.

상대가 스탠드 상태였다면 스탠드를 취소한다.

### 대가

라운드 시작 시 영혼 1개를 잃는다.

## 바포메트

계약 즉시:

상대 덱에 오망성 5장을, 자신의 덱에 오망성 3장을 각각 섞는다.

오망성은 숫자를 합계에 포함하고 현재 전투의 여러 라운드에서 덱·손·버린 카드 더미를 순환한다. 전투 종료 시 양쪽의 모든 전투 위치에서 제거하므로 런 덱에는 남지 않는다.

`(P) 패시브`

상대 덱에 들어간 모든 오망성이 제거되면 상대를 버스트시킨다.

이후 상대 덱을 초기화시키고, 오망성 카드 5장을 상대 덱에 섞는다.

### 대가

자신의 덱에 들어간 모든 오망성이 제거되면 자신이 버스트된다.

이후 자신의 덱을 초기화시키고 오망성 카드 3장을 자신의 덱에 섞는다.

### 프로토타입 판정 (DC-D15)

- 상대 덱에는 숫자 1·2·3·4·5 오망성을 한 장씩, 계약 소유자 덱에는 숫자 1·2·3 오망성을 한 장씩 넣는다. 숫자 1 오망성은 기존 에이스 계산과 같이 안전하면 11로 계산한다.
- 한 계약이 특정 대상에게 넣은 오망성이 그 대상의 **드로우 더미에 한 장도 남지 않은 시점**을 해당 묶음의 소진으로 본다. 손·버린 카드 더미·파이몬 추방 상태로 빠진 오망성도 드로우 더미에서는 소진된 것으로 센다.
- 소진 시 해당 묶음의 오망성을 손·드로우·버린 더미·추방·탈취 위치에서 먼저 제거하고, 대상의 가용 드로우·버린 더미를 합쳐 다시 섞은 뒤 같은 숫자 묶음을 새 물리 카드로 삽입한다. 현재 손의 오망성이 아닌 카드는 해당 라운드가 끝날 때까지 유지한다.
- 같은 카드 진입에서 숫자·카드·다른 계약의 버스트가 이미 확정되면 그 판정을 먼저 처리한다. 그 버스트가 방지되어 행동이 계속될 때에는 이어서 오망성 소진을 판정한다. 오망성 버스트 자체도 사탄 방지와 바알제붑 대체를 같은 방식으로 적용한다.
- 위 판정은 첫 플레이 테스트를 위한 구현 기준이며, 소유자 오망성 숫자와 `드로우 더미 0장` 소진 정의는 밸런스 확인 뒤 이천서가 재조정할 수 있다.

## 아자젤

계약 즉시:

자신의 사용된 공개 카드를 모두 재사용한다.

`(P) 패시브`

자신의 차례에 히트할 때마다 사용 효과를 반복한다.

### 대가

지금부터 자신의 공개 카드에 동일한 숫자의 카드가 추가되면, 버스트된다.

# 12. 자동 발동 카드

## 1: 독극물

`(A) 자동 발동`

다음 중 하나를 선택한다.

- 지금 즉시 스탠드한다.
- 영혼 3개를 담보로 건다. 현재 영혼이 3개보다 적다면 현재 보유한 영혼을 모두 건다.

영혼을 지불하는 선택을 했고 해당 라운드에서 승리하면 영혼을 5개로 돌려받는다. 회복은 최대 영혼을 넘을 수 없다.

## 2: 부활초

`(A) 자동 발동`

양쪽은 각각 영혼 1개를 버릴 수 있다. 영혼을 버린 쪽은 자신의 모든 카드를 버린 뒤 비공개 카드 1장과 공개 카드 1장을 다시 받을 수 있다.

두 참가자의 선택은 서로 독립적이다. 한쪽만 영혼을 버렸다면 그쪽의 손패만 재배분하며, 어느 쪽도 영혼을 버리지 않았다면 손패를 바꾸지 않는다. 영혼을 버려 0이 되면 공통 규칙에 따라 즉시 사망하고 손패를 다시 받지 않는다.

사용 여부와 AI의 선택 기준은 추후 정한다.

## 3: 거짓말 탐지기

`(A) 자동 발동`

숫자 하나를 선언한다.

상대는 비공개 카드 숫자가 선언한 숫자 이상인지 아닌지를 알려준다.

## 4: 화염 방사기

`(A) 자동 발동`

스탠드하지 않은 모든 대상은 자신의 공개 카드 1장을 버릴 수 있다.

## 5: 회중시계

`(A) 자동 발동`

자신의 사용된 공개 카드 1장을 다시 사용 가능한 상태로 만든다.

효과 처리 후 이 카드를 즉시 버릴 수 있다.

# 13. 특수 카드

## 사탄 윗면/아랫면 계약 상태

사탄의 윗면·아랫면 효과는 별도의 일반 카드나 런 카드가 아니라 활성 계약 카드 자체의 규칙 상태에 기록한다. 기존 숫자 8·10 `사탄의 권능` 특수 카드 방식은 v0.7에서 폐기한다. 사탄의 `윗면 ↔ 아랫면` 전환 시점은 11장의 사탄 규칙을 따르며 일반 카드의 앞면/뒷면 공개와 혼용하지 않는다.

## 1, 2, 3, 4, 5: 오망성

바포메트 계약에 의해 덱에 삽입되는 특수 카드다.

# 14. 적 AI 설계

## 14.1 AI 공정성 원칙

적 AI는 게임 내부적으로 존재하는 **미공개 정보**를 직접 사용하지 않는다.

AI 판단 함수에는 아직 앞면 공개되지 않은 플레이어 비공개 카드의 실제 숫자와 덱의 실제 다음 카드가 전달되지 않아야 한다. 앞면 공개된 비공개 카드의 숫자는 공개 사실에서 얻은 확정 정보로 별도 전달할 수 있다.

AI는 공개 정보와 확률만으로 판단한다.

플레이어 비공개 카드의 숫자가 이미 공개되었고 적이 현재 사용할 수 있는 리볼버를 보유했다면, 적의 성향·확률 임계값과 다른 일반 행동보다 리볼버 사용을 우선하고 공개된 정확한 숫자를 선언한다. 아직 공개되지 않은 경우에만 기존 확률 추론과 적별 사용 임계값을 적용한다.

## 14.2 AI 추론 정보

AI는 다음과 같은 추론 데이터를 관리한다.

- 각 숫자 카드가 플레이어 비공개 카드일 확률
- 플레이어 덱에 남은 카드의 예상 분포
- 플레이어가 버스트할 확률
- 플레이어가 특정 카드 효과를 보유할 확률
- 플레이어가 계약을 선택할 가능성
- 플레이어의 반복 행동 성향

## 14.3 플레이어에게 제공되는 정보

플레이어에게 AI의 전체 내부 상태를 공개하지 않는다.

대신 일부 추론 결과를 UI로 표시한다.

예시:

- `상대는 높은 숫자를 의심하고 있습니다.`
- `상대가 가장 의심하는 숫자: 7, 8`
- `상대의 확신도: 낮음`
- `상대는 당신이 버스트에 가깝다고 판단합니다.`

상세 모드에서는 숫자별 추정 확률을 표시할 수 있다.

적의 다음 행동 자체는 항상 공개하지 않는다.

특정 적이나 보스만 행동을 사전에 예고하도록 설계할 수 있다.

- 고정 악마 처리 순서:
  1. 바포메트와 계약하고 마몬을 버림
  2. 아스모데우스와 계약. 함께 버릴 프로토타입 7종 내 악마는 재설계 대기
  3. 아자젤과 계약. 함께 버릴 프로토타입 7종 내 악마는 재설계 대기

  - 1 에이스 카드 x10
  - 5 수정 구슬 x5
  - 6 위협용 해머 x2
  - 7 리볼버 x4
  - 9 보위 나이프 x4
- 영혼 구간에 따라 행동 패턴이 변함
- 특정 카드 또는 악마 계약을 중심으로 고유 규칙 사용
- 일반 적보다 높은 판단 성능과 전용 연출 보유
- 필요에 따라 라운드 승리 횟수 등의 별도 승리 조건 사용

최대 영혼 8 기준 전환선은 `floor(8 × 0.66) = 5`, `floor(8 × 0.33) = 2`다. 전투 시작 시 1단계를 적용하고, 피해 처리 뒤 생존한 보스의 현재 영혼이 5 이하가 되면 2단계, 2 이하가 되면 3단계로 즉시 전환한다. 한 번의 피해로 두 전환선을 모두 넘으면 두 단계를 순서대로 처리해 3단계에 도달한다. 회복해도 이전 단계로 돌아가지 않는다.

보스의 고정 단계는 일반 계약 행동이 아니다. 영혼 비용과 후보 선택이 없고 전투당 기본 계약 횟수도 소비하지 않는다. 각 단계에서 기존 활성 계약과 버리기로 정한 짝 악마는 악마 버린 카드 더미로 이동하며 다음 활성 계약 하나만 남는다. 이미 지난 단계는 반복하지 않고, 피해로 영혼이 0이 되면 생존 조건을 만족하지 않으므로 새 단계를 활성화하지 않는다.

바포메트 계약이 끝나도 활성화 순간 생성된 오망성은 전투 한정 카드 수명 규칙을 따른다. 따라서 해당 전투에는 남아 덱 순환과 소진 판정을 계속하며, 전투 종료 시 모든 위치에서 제거한다. 현재 활성 계약과 효과 요약은 기존 계약 표시 모델에 노출한다.

# 16. 보상과 성장

## 16.1 카드 획득 경로

정식 런에서는 전투 승리 직후 별도의 무료 카드 보상 3장을 제시하지 않는다. 일반 카드와 악마 카드는 전투 뒤 상점에서 골드로 구매하며, 카드를 원하지 않는 플레이어는 골드를 위스키·라이터 또는 이후 상점 방문에 사용할 수 있다.

상점의 일반 카드 후보 풀에는 기본·수동 카드뿐 아니라 독극물, 부활초, 거짓말 탐지기, 화염 방사기, 회중시계의 자동 발동 카드 5종을 포함한다. 하나의 상점 제안 안에서는 같은 정의 키를 중복 제시하지 않는다. 정확한 희귀도와 가중치는 플레이 테스트 항목으로 두되, 일반전 승리 골드와 최저 카드 가격은 적어도 한 장을 살 수 있는 선택지가 발생하도록 함께 조정한다.

엘리트의 성장 보상은 별도 무료 보상 화면이 아니라 더 많은 골드와 높은 등급 상점 상품의 출현 확률로 표현한다. 보스 승리 뒤에는 다음 전투가 없으므로 카드 상품이나 카드 보상을 생성하지 않는다.

기존 `BattleRewardCatalog`, `RewardSelection`과 선택·건너뛰기 구현은 정식 런에서 호출하지 않는다. 향후 무료 보상 사건이나 특수 보상 콘텐츠에 재사용할 수 있으므로 별도 제거 작업이 승인되기 전까지 유산 기능으로 보존한다.

## 16.2 골드 보상

플레이어는 상대를 쓰러뜨릴 때마다 골드를 얻는다. 골드는 현재 런 동안 유지되며 상점에서만 사용한다.

- 겁쟁이 도박사 3, 총잡이 4, 광신도 6, 사기꾼 7, 집행자 9, 최종 보스 15골드를 지급한다.
- 더 높은 최대 영혼 구간의 적은 항상 낮은 구간보다 더 많은 골드를 지급한다. 같은 최대 영혼에서는 전용 카드·능력·등급의 위험도로 차등한다.
- 정확한 지급량은 프로필 키 기반 카탈로그로 관리하고 플레이 테스트에서 경제 흐름에 맞춰 조정한다.
- 런 재시작 시 골드는 초기값으로 돌아가며 다음 런으로 자동 계승하지 않는다.

골드는 전투 승리 정산에서 정확히 한 번 지급한다. 카드 선택 결과와 결합하지 않으며, 정산 실패·중복 호출·패배에는 지급하지 않는다.

## 16.3 상점과 휴식

다음 전투가 남아 있는 전투의 골드 정산이 끝나면 상점 또는 무작위 사건으로 이동한다. 첫 개발에서는 이 분기를 사용하지 않고 상점만 등장한다.

상점의 모든 서비스는 골드를 사용한다. 상점에는 최소한 다음 기능을 제공한다.

- 판매 카드 5장: 자동 발동 카드를 포함할 수 있는 일반 카드 3장과 악마 카드 2장으로 고정
- 위스키: 골드를 지불하고 영혼 회복, 상점당 1회
- 라이터: 덱에서 선택한 카드 1장 제거, 상점당 1회
- 향후 유물 구매

판매 카드 5장은 상점에 들어올 때 한 번 생성한다. 왼쪽 3칸에는 일반 카드, 오른쪽 2칸에는 악마 카드를 배치한다. 각 카드는 재고 1개이며 구매한 카드는 각각 일반 카드 덱 또는 악마 카드 덱에 추가한다. 구매한 자리에는 `SOLD OUT` 표지를 놓고 나머지 상품은 그대로 유지하며 새로고침·재입고 기능은 제공하지 않는다. 방문당 카드 구매 횟수에는 별도 상한을 두지 않으므로, 골드가 충분하면 아직 재고가 남은 카드 슬롯을 모두 구매할 수 있다.

플레이어 덱을 선택하면 보유 카드 목록을 열고, 라이터를 이용해 그중 한 장을 제거할 수 있다. 위스키는 별도 휴식 노드 대신 사용하는 영혼 회복 서비스다. 라이터와 위스키는 한 상점에서 각각 한 번만 이용할 수 있으며, 골드와 이용 조건을 충족하면 같은 상점에서 두 서비스를 모두 이용할 수 있다.

한 상점에서 라이터 또는 위스키를 하나 이상 이용했다면 다음 상점부터 두 서비스의 가격을 함께 한 단계 올린다. 같은 상점에서 하나만 이용한 경우와 둘 다 이용한 경우의 상승 단계는 모두 1단계이며, 둘을 이용해도 2단계 오르지 않는다. 어느 서비스도 이용하지 않은 상점은 가격 단계를 올리지 않는다. 가격 단계는 런 동안 누적되고 새 런에서 초기화한다. GameScene 프로토타입은 두 서비스의 기본 가격을 각각 2골드, 이용 상점당 공통 상승폭을 1골드로 두며, 판매 카드 가격·위스키 회복량과 함께 플레이 테스트로 조정할 수 있다.

상점 화면 좌측 상단에는 현재 골드와 영혼을 표시한다. 현재 골드로 살 수 없는 상품의 가격은 빨간색으로 표시한다. `나가기` 버튼은 무료이며 구매 여부와 관계없이 상점 방문을 끝낼 수 있다. 기획 이미지의 가격 숫자는 화면 예시일 뿐 최종 밸런스 값이 아니다.

## 16.4 카드 강화

카드 강화는 숫자를 바꾸기보다 효과를 강화하는 방향을 우선한다.

예시:

- 수정 구슬: 확인 카드 2장 → 3장
- 리볼버: 숫자 1개 선언 → 조건부로 2개 선언
- 보위 나이프: 강제 히트 후 카드를 버릴 수 없음

구체적인 강화안은 프로토타입 이후 확정한다.

## 16.5 유물

유물은 덱에 들어가지 않는 지속 효과다.

예시:

- 전투당 첫 계약 비용 감소
- 정확히 21로 승리하면 영혼 회복
- 리볼버 사용 시 추측 확률 표시 강화
- 덱을 다시 섞을 때 카드 1장 확인
- 상점 휴식 회복량 증가

# 17. UI 및 정보 표시

## 17.1 기본 전투 화면

전투 화면은 서부 시대 술집의 테이블을 바라보는 고정 카메라 기반 2.5D 화면으로 구성한다. 카드, 덱과 버린 카드 더미는 테이블 위 월드 오브젝트로 배치하고, 수치·설명·행동 안내는 화면 UI로 보완한다.

전투 화면에는 다음 정보가 표시된다.

- 플레이어 영혼
- 적 영혼
- 플레이어 공개 카드
- 플레이어 비공개 카드
- 적 공개 카드
- 적 비공개 카드
- 양쪽 공개 합계
- 플레이어 덱 잔여 카드 수
- 플레이어 버린 카드 수
- 적 덱 잔여 카드 수
- 활성화된 악마 계약
- 악마의 능력과 대가
- 사용 가능한 행동 버튼

테이블의 확정 배치는 다음을 따른다.

- 적 버린 카드 더미는 좌측 상단, 적 덱은 우측 상단에 둔다.
- 적 공개·비공개 카드는 상단 중앙에 둔다.
- 중앙은 카드 효과와 선택 연출을 위한 공용 공간으로 둔다.
- 플레이어의 일반 카드 덱과 악마 카드 덱은 좌측 하단에 서로 구분되는 별도 덱 오브젝트로 나란히 두고, 버린 카드 더미는 우측 하단에 둔다.
- 일반 카드 덱과 악마 카드 덱의 맨 위 카드는 각각 해당 덱 전용 뒷면이 보이도록 표현한다.
- 두 플레이어 덱을 호버하면 현재 덱에 포함된 카드 목록을 표시하되 실제 뽑기 순서는 노출하지 않는다. 악마 덱을 선택하면 계약을 시작한다.
- 계약 후보는 중앙 선택 영역에 앞면 카드 최대 2장으로 펼치며, 선택한 악마 카드는 플레이어 앞 계약 영역으로 이동한다. 루시퍼 효과만 후보 5장을 제시한다.
- 플레이어와 적의 비공개 카드는 모두 플레이어 화면 기준 손패 왼쪽에 둔다. 효과 사용 등으로 앞면 공개되어도 라운드가 끝날 때까지 이 위치를 유지한다.
- 아직 공개되지 않은 플레이어 비공개 카드는 카드 뒷면 위에 실제 앞면을 반투명하게 겹쳐 플레이어만 확인할 수 있게 한다.
- 사용 완료 카드는 현재 위치에 남기고 검게 처리해 숫자만 보이게 한다.
- 히트·스탠드는 화면 최하단, 체인지는 플레이어 비공개 카드 가까이에 둔다. 체인지에는 현재 영혼 비용과 사용 후 남을 영혼을 표시한다.
- 리볼버, 보위 나이프와 위협용 해머는 우측 가장자리에 항상 보이는 3D 장식으로 둔다.
- 플레이어 일반·악마 덱 호버 시 실제 남은 카드 목록을, 적 덱 확인 시 공개 정보로 추론 가능한 남은 후보 목록만 표시한다. 어느 목록도 실제 덱 순서를 노출하지 않는다.

## 17.2 AI 추론 패널

AI가 플레이어를 어떻게 추측하고 있는지 간략하게 표시한다.

표시 방식은 적의 특성과 게임 난도에 따라 조정한다.

- 쉬운 난도: 숫자별 확률 표시
- 보통 난도: 가장 의심하는 숫자 2~3개 표시
- 어려운 난도: 추론 방향과 확신도만 표시
- 특정 보스: 잘못된 추론 정보를 표시할 가능성 존재

잘못된 정보를 제공하는 보스가 존재할 경우, 해당 능력은 사전에 명확하게 설명한다.

## 17.3 사탄 계약 UI

사탄과 계약하면 화면에 남은 종말 카운트와 현재 계약 카드 면을 크게 표시한다.

예시:

`종말 카운트 4 · 윗면`

계약 소유자의 차례를 시작할 때 카운트가 감소하고, 계약 소유자의 차례가 끝날 때 계약 카드를 뒤집는다.

카운트가 1이면 다음 차례 시작의 영혼 2 손실을 화면과 사운드로 강하게 경고한다.

# 18. 시각 및 연출 방향

## 18.1 아트 방향

프로토타입은 다음 2.5D 방향을 사용한다.

- 배경과 테이블은 3D 서부 시대 술집으로 구성한다.
- 카메라는 플레이어가 테이블에 앉은 시점으로 고정한다.
- 카드 앞면·뒷면과 숫자·이름은 얇은 3D 월드 오브젝트로 표현한다.
- 덱과 버린 카드 더미는 높이가 있는 3D 오브젝트로 표현하며, 남은 카드 수에 따라 높이 단계를 바꾼다.
- 카드 상세 설명, 행동 버튼, 영혼·골드와 추론 정보는 화면 UI로 표시한다.
- 리볼버, 보위 나이프와 위협용 해머는 테이블 우측에 항상 보이는 3D 장식으로 배치하고, 효과 사용 시 해당 오브젝트가 움직인 뒤 제자리로 돌아오게 한다.
- 전투 종료 후 같은 테이블과 카메라를 유지하고, 적 자리에는 상인이 등장해 상품을 테이블에 펼친다.
- 전투·골드 정산·상점마다 별도 공간으로 이동하지 않고 조명, 음악, 인물과 테이블 오브젝트를 교체한다.
- 적 캐릭터의 표현 방식은 정지 일러스트, 파츠 애니메이션 또는 3D 캐릭터 중 추후 확정한다.
- 악마 계약 시 배경 조명, 테이블 문양과 UI 색상을 변경한다.
- 피격과 카드 효과는 오브젝트 애니메이션, 이펙트와 짧은 카메라 흔들림으로 강조한다.

## 18.2 테이블 상태 전환

- 상대 선택: 테이블 위에 상대 후보 2명의 정보 오브젝트를 제시한다.
- 전투: 양측 카드, 일반 카드 덱, 별도 악마 카드 덱과 버린 카드 더미를 지정 위치에 배치한다.
- 골드 정산: 전투 오브젝트를 정리하며 획득 골드를 짧게 제시하고 별도 선택 없이 상점 전환을 시작한다.
- 상점: 적을 퇴장시키고 같은 자리에 상인을 배치한다. 상인은 자동 발동 카드를 포함할 수 있는 일반 카드 3장과 악마 카드 2장, 라이터와 위스키를 테이블에 펼친다. 구매한 카드 자리에는 `SOLD OUT` 표지를 놓고, 골드가 부족한 가격은 빨간색으로 표시한다. 남은 카드 슬롯은 골드가 허용하는 만큼 구매할 수 있다. 라이터와 위스키는 각각 상점당 1회 이용할 수 있고 하나 이상 이용한 방문은 다음 상점의 두 서비스 가격을 함께 한 단계 올린다. `나가기` 버튼을 항상 제공하며 새로고침은 제공하지 않는다.
- 보스: 같은 공간을 사용하되 조명, 음악, 배경 인물과 테이블 장식을 보스 전용 상태로 전환한다.

AI 생성 도구를 이용해 다음 리소스를 제작할 수 있다.

- 적 초상화
- 악마 일러스트
- 카드 삽화
- 배경 콘셉트
- UI 장식
- 음성 샘플
- 효과음 초안

최종 리소스는 동일한 스타일로 보정한다.

## 18.3 첫 5분 연출 목표

첫 5분 안에 다음 요소를 모두 경험하게 한다.

1. 일반적인 히트와 스탠드
2. 카드 효과 사용
3. 상대의 비공개 카드 추측
4. 최초 악마 계약
5. 강력한 버스트 연출
6. 전투 종료와 카드 보상

튜토리얼 설명보다 실제 상황을 통해 규칙을 학습하도록 구성한다.

# 22. 현재 보류된 사항

다음 항목은 아직 확정하지 않는다.

## 시작 악마 후보 풀

새 런 시작 시 사탄·벨페고르·바알제붑·마몬 풀에서 서로 다른 악마 카드 2장 중 1장을 반드시 선택해 악마 카드 덱을 최소 1장으로 시작한다. 네 후보의 가중치는 동일하다. 일반 계약은 현재 악마 덱에서 최대 2장을 제시한다. 루시퍼의 5장 예외는 비활성 보관 기획이며 프로토타입에서는 사용하지 않는다.

## 자동 발동 카드 처리

효과 처리 후 카드를 버릴지, 공개 카드로 유지할지 카드별로 정해야 한다. 독극물의 즉시 스탠드와 스탠드 불가 계약이 동시에 적용될 때의 우선순위는 추후 확정한다.

## 악마별 연속 처리 세부 규칙

레비아탄은 첫 리볼버 예측이 성공하면 상대 버스트가 다른 계약으로 방지되더라도 두 번째 예측과 대가를 생략한다. 첫 예측이 실패하면 실패 연출을 끝낸 뒤 리볼버 준비 연출과 숫자 선택을 다시 시작한다. 두 선언은 서로 같아도 되며 두 번째 예측은 일반 리볼버와 같은 판정을 사용한다. 두 번째 예측이 성공하면 대가 없이 끝나고, 두 예측이 모두 실패했을 때만 영혼 1을 잃는다. 여러 레비아탄 계약 인스턴스의 추가 발동·대가 처리 순서는 추가 계약 콘텐츠 착수 전에 확정한다. 사탄 종말 카운트와 마몬 재굴림의 도메인 입력은 각각 DC-R02·DC-R03에서 고정했으며 실제 월드 계약 카드 입력과 연출은 DC-R05에서 연결한다.

## 적 행동 정보 공개 범위

AI가 추측하는 숫자 확률은 표시하지만, 정확한 다음 행동을 어느 정도까지 표시할지는 난도와 적 유형에 따라 조정한다.

## Notion v0.7 적 개정의 구현 결정

- 겁쟁이 도박사는 공개 합 15부터 스탠드하고, 기대 효용이 양수인 수동 카드를 정상 차례마다 15% 확률로 사용한다.
- 모든 적은 자신의 비공개 역할 카드가 공개되었거나 이를 포함한 예상 최종 합이 21을 넘으면 공통 체인지 평가를 수행한다. 사기꾼만 비용 1 고정을 사용한다.
- 광신도는 첫 정상 차례부터 계약을 우선하며, 성공할 때까지 이후 정상 차례마다 다시 시도한다.
- 광신도는 계약 강제 시도가 끝난 뒤 사용 가능한 수동 카드가 있으면 기본 히트·스탠드보다 우선 사용한다.
- 집행자는 각 라운드의 최초 배분 전에 전투 한정 독극물 1장을 플레이어의 가용 전투 덱에 넣어 섞는다.
- 보스는 전투 시작과 영혼 5·2 이하 진입 시 세 고정 계약 단계로 단방향 전환한다.
- 프로필별 골드는 겁쟁이 3·총잡이 4·광신도 6·사기꾼 7·집행자 9·보스 15다.
