## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | 데블랙잭 |
| 영문 가제 | DiaBlackJack |
| 장르 | 1인용 블랙잭 기반 덱 빌딩 로그라이트 |
| 플랫폼 | PC |
| 플레이 인원 | 1인 |
| 목표 플레이 시간 | 1런 15~20분 |
| 개발 규모 | 3인, 2주 프로토타입 |
| 핵심 대상 | 카드 게임 규칙을 빠르게 이해하고, 확률 추론과 고위험 선택을 즐기는 플레이어 |

### 1.1 한 문장 정의

> 영혼을 체력과 화폐로 사용하며, 카드 효과와 악마 계약으로 상대의 블랙잭을 붕괴시키는 1대1 덱 빌딩 로그라이트.

### 1.2 플레이어 판타지

플레이어는 악마에게 납치되어 지옥의 블랙잭 대회에 참가한다. 정직하게 21을 노릴 수도 있지만, 총기·흉기·마법·악마의 힘으로 상대의 패를 조작하고 강제로 버스트시킬 수도 있다. 승리를 위해 자신의 생명인 영혼까지 거래해야 한다.

### 1.3 핵심 재미

1. **숫자와 효과의 이중 선택**: 좋은 합계를 만들지, 불리한 숫자를 감수하고 강력한 효과를 사용할지 판단한다.
2. **제한된 정보의 심리전**: 공개 정보로 비공개 카드를 추론하고, 적 AI가 자신을 어떻게 추정하는지 역이용한다.
3. **영혼의 이중 용도**: 생존 자원인 영혼을 성장에 소비하는 긴장감을 만든다.
4. **규칙 파괴의 쾌감**: 악마 계약으로 평범한 블랙잭 규칙을 일시적으로 뒤집는다.

## 2. 제품 목표와 범위

### 2.1 프로토타입의 검증 목표

- 카드 숫자와 전투 효과를 함께 고려하는 선택이 실제로 재미있는가?
- 적의 비공개 카드 확률을 추론하는 과정이 이해 가능하고 유용한가?
- 영혼을 체력과 계약 비용으로 함께 쓰는 구조가 의미 있는 위험 선택을 만드는가?
- 한 전투가 일반 2~4분, 엘리트 4~6분, 보스 6~8분 안에 끝나는가?
- 첫 5분 안에 히트, 스탠드, 카드 사용, 추론, 계약, 버스트, 보상을 모두 경험할 수 있는가?

### 2.2 필수 구현 범위(MVP)

- 상대 선택 전투 2회, 전투 후 이벤트 2회, 최종 보스
- 일반 적 4종, 엘리트 1종, 보스 1종
- 히트, 스탠드, 카드 사용, 체인지, 계약
- 일반 카드 1~10 기본 세트 및 핵심 효과 카드
- 프로토타입 악마 7종 처리: 사탄, 벨페고르, 바알제붑, 아스모데우스, 마몬, 바포메트, 아자젤.
- 영혼 피해, 덱·버린 카드 더미 순환, 에이스 계산
- 공개 정보만 사용하는 적 AI와 추론 확률 UI
- 전투 승리 골드와 상점의 카드·회복·제거 선택

### 2.3 후순위 또는 제외 범위

- 메타 성장, 복수 캐릭터와 복수 지역
- 복잡한 카드 강화 트리와 메타 성장형 계약 확장
- 신규 악마와 추가 오망성·모략 카드 묶음
- 루시퍼, 레비아탄, 메피스토펠레스, 파이몬, 벨리알 및 그 밖의 악마
- 새 자동 발동 카드와 추가 보스 전용 규칙

일정 위험이 발생하면 후순위 항목부터 제외한다. 단, AI 추론 UI와 영혼 계약은 게임의 차별점이므로 축소하더라도 제거하지 않는다.

## 3. 게임 진행 구조

### 3.1 전체 흐름

1. 플레이어는 영혼 12와 기본 덱으로 런을 시작한다.
2. 지도 없이 `전투 → 전투 후 이벤트 → 전투 → 전투 후 이벤트 → 보스`의 고정된 순서를 진행한다.
3. 일반 전투 진입 전 서로 다른 상대 후보 2명 중 한 명을 선택한다. 후보 중 엘리트는 최대 1명만 등장한다.
4. 전투에서 적 영혼이 0이 될 때까지 여러 블랙잭 라운드를 반복한다.
5. 일반 전투에서 승리하면 상대 프로필에 따른 골드를 정확히 한 번 획득한다. 강한 적일수록 더 많은 골드를 주며 엘리트는 일반 적보다 더 많은 골드를 확정 지급한다.
6. 다음 전투가 남아 있다면 별도의 카드 보상 화면 없이 상점 또는 무작위 사건으로 이동한다. 첫 개발에서는 상점만 등장한다.
7. 상점에서 일반·수동·자동 발동 카드와 악마 카드 구매, 위스키 회복, 라이터 제거 중 원하는 항목에 골드를 사용하거나 아무것도 구매하지 않고 나간다. 플레이어 영혼은 자동 회복되지 않는다.
8. 최종 보스를 처치하면 카드 보상과 상점 없이 즉시 런 승리로 확정한다. 플레이어 영혼이 0이 되면 골드 정산 없이 런이 종료된다.

### 3.2 정식 런 경로

`상대 2명 중 선택 → 전투 → 골드 정산 → 상점/사건 → 상대 2명 중 선택 → 전투 → 골드 정산 → 상점/사건 → 보스 → 런 승리`

분기 지도는 구현하지 않는다. 경로 선택 대신 전투마다 제시되는 상대 2명 중 한 명을 고르는 방식으로 전투의 위험과 보상을 선택한다. 일반 전투 후보 조합은 `일반+일반` 또는 `일반+엘리트`만 허용하며, 엘리트 2명이 동시에 제시되지는 않는다. 엘리트의 등장 확률과 보상 차이는 플레이 테스트 후 조정한다.

전투 후 이벤트는 상점 또는 무작위 사건 중 하나를 결정한다. 휴식은 상점의 골드 소비 서비스로 통합한다. 첫 개발에서는 사건을 제외하고 두 이벤트 슬롯 모두 상점으로 고정하며, 이후 등장 가중치와 중복 규칙을 확정한다.

### 3.3 세션 목표

| 구간 | 목표 시간 | 학습/경험 |
| --- | ---: | --- |
| 첫 전투 | 3분 이내 | 히트, 스탠드, 카드 효과, 버스트 |
| 두 번째 전투 | 누적 5분 이내 | AI 추론과 첫 악마 계약 |
| 중반 | 6~12분 | 덱 변화, 영혼 보존과 소비의 갈등 |
| 보스 | 6~8분 | 빌드 검증과 고유 규칙 대응 |

## 4. 전투 규칙

### 4.1 전투 단위

- **런**: 시작부터 최종 보스 승리 또는 플레이어 패배까지.
- **스테이지**: 전투·보상·상점·무작위 사건 등 하나의 진행 단위.
- **라운드**: 양측이 두 장을 받은 뒤 한쪽이 버스트하거나 양측이 스탠드할 때까지.
- **차례**: 플레이어나 적이 행동 하나를 선택하는 단위.

### 4.2 라운드 시작

- 양측은 자신의 덱에서 카드 2장을 뽑는다.
- 각각 1장은 공개, 1장은 비공개로 놓는다.
- 아직 앞면 공개되지 않은 적의 비공개 카드는 플레이어가, 플레이어의 비공개 카드는 AI 의사결정 로직이 직접 열람할 수 없다. 앞면 공개된 비공개 카드 숫자는 양측의 확정 정보가 된다.
- 최초 배분에서는 자동 발동 효과가 발동하지 않는다.
- 플레이어가 먼저 행동한다. 보스의 선공 변경은 프로토타입에서 제외한다.

### 4.3 플레이어 행동

| 행동 | 규칙 |
| --- | --- |
| 히트 | 덱 맨 위 카드 1장을 공개 카드로 추가한다. |
| 스탠드 | 이번 라운드의 추가 행동을 종료한다. 카드 효과로 취소될 수 있다. |
| 카드 사용 | 사용 가능한 카드 1장의 효과를 발동한다. 비공개 카드는 앞면으로 뒤집어 사용하되 최종 승부 전까지 비공개 역할을 유지한다. |
| 체인지 | 기존 비공개 카드를 공개해 버리고 덱 위 2장을 혼자 확인해 1장을 새 비공개 카드로 선택한다. 같은 전투의 체인지 비용은 `0→1→2→3…` 영혼으로 증가하며 다음 전투에서 초기화한다. 비용 지불 후 영혼이 최소 1 남아야 한다. |
| 계약 | 일반 카드 덱과 분리된 악마 카드 덱을 선택하고 영혼 1을 지불해 가용 카드 중 최대 2장 가운데 1장과 계약한다. 카드가 1장이면 단일 후보를 제시하며, 전투 스테이지당 원칙적으로 1회만 사용할 수 있다. |

각 행동은 기본적으로 차례 하나를 소모한다. 카드 문구가 명시한 경우에만 추가 행동이나 즉시 처리를 허용한다.

### 4.4 카드 합계와 에이스

- 전투 모델은 공개 합계와 비공개 카드를 포함한 전체 합계를 각각 계산한다.
- 히트·강제 히트·카드 효과 도중의 중간 버스트는 공개 역할 카드 합계만 사용한다. 앞면 공개된 비공개 역할 카드는 제외한다.
- 양쪽 모두 스탠드한 최종 승부에서는 비공개 카드를 공개하고 전체 합계를 사용한다.
- 에이스는 1 또는 11 중 합계가 21 이하에서 가장 커지는 값을 자동 선택한다.
- 악마 계약이 생성한 특수 카드에 숫자가 명시되어 있으면 그 숫자를 합계에 포함한다. 숫자가 없는 계약 상태·카운터·표식은 합계에 포함하지 않는다.

### 4.5 버스트 정의

다음 중 하나라도 발생하면 해당 대상은 버스트한다.

- 라운드 진행 중 공개 합계가 21을 초과한다.
- 양쪽 스탠드 후 비공개 카드를 포함한 최종 합계가 21을 초과한다.
- 카드 또는 계약 효과가 대상을 버스트시킨다.
- 해당 라운드에 적용되는 특수 패배 조건을 충족한다.

버스트한 대상은 즉시 라운드에서 패배한다. 양측이 같은 효과 처리 중 동시에 버스트하면 효과를 발생시킨 쪽이 패배한 것으로 처리한다. 이 규칙은 무한 연쇄와 판정 모호성을 막기 위한 프로토타입 결정이다.

### 4.6 양측 스탠드 후 승패

1. 비공개 카드를 모두 공개한다.
2. 21을 초과한 대상은 비교에서 제외한다.
3. 21 이하에서 합계가 21에 가까운 쪽이 승리한다.
4. 양측 모두 21을 초과했다면 21과의 차이가 작은 쪽이 승리한다.
5. 합계가 같으면 플레이어 승리로 처리한다.

### 4.7 영혼 피해

| 결과 | 플레이어 피해 | 적 피해 |
| --- | ---: | ---: |
| 플레이어 스탠드 후 합계 비교 패배 | 1 | 0 |
| 플레이어 버스트 | 2 | 0 |
| 적 버스트 | 0 | 1 |
| 일반 합계 비교 승리 | 0 | 1 |
| 정확히 21로 플레이어 승리 | 0 | 2 |
| 카드·계약 효과 | 효과 명시값 | 효과 명시값 |

폴드 삭제 뒤 안전한 손실 선택은 스탠드가 담당한다. 플레이어가 스탠드 후 합계 비교에서 패배하면 영혼 1, 숫자 초과 또는 카드 효과로 버스트하면 영혼 2를 잃는다. 적은 버스트와 합계 비교 패배 모두 영혼 1을 잃는다.

### 4.8 라운드 종료와 덱 순환

- 버스트 또는 양측 스탠드 중 하나가 발생하면 라운드가 끝난다.
- 사용한 카드와 라운드 종료 시 보유 카드는 버린 카드 더미로 이동한다.
- 덱이 소진되면 버린 카드 더미를 섞어 새 덱으로 사용한다.
- 여러 장을 한 번에 뽑을 때 드로우 더미가 부족하면 버린 카드 더미를 섞어 기존 드로우 더미 아래에 보충한다. 기존 드로우 카드를 먼저 사용한다.
- 적을 처치하면 적 덱은 폐기되고, 플레이어의 덱과 버린 카드 더미는 다음 전투 시작 시 합쳐 섞는다.
- 자동 발동 카드는 효과 처리 후 버린다. 지속 카드만 공개 영역에 남는다.

## 5. 영혼과 성장

### 5.1 영혼 설계

- 시작 영혼: 12
- 최대 영혼: 기본 12. 유물이나 보상으로만 증가 가능.
- 적 영혼: 일반 2~3, 강한 일반 3~4, 엘리트 4~5, 보스 6~8.
- 전투 종료 시 자동 회복 없음.
- 영혼 0 도달 즉시 런 패배.

영혼을 1 소모하는 계약은 현재 생존 가능성을 직접 낮춘다. 계약 확인창에는 계약 후 남는 영혼과 예상 위험도를 항상 표시한다.

### 5.2 카드 성장 선택

정식 런의 카드 획득은 전투 보상 화면이 아니라 상점으로 통합한다. 전투 승리 직후에는 골드만 정산하고, 플레이어는 상점에서 카드를 구매할지 위스키·라이터에 투자할지, 골드를 보존할지를 결정한다.

일반 카드 3개 상품의 후보 풀에는 기본 숫자 카드, 수동 효과 카드와 자동 발동 카드 5종을 함께 넣는다. 같은 상점에서는 동일 정의 키를 중복 제시하지 않는다. 자동 발동 카드는 독극물·부활초·거짓말 탐지기·화염 방사기·회중시계다.

엘리트 선택의 이득은 더 많은 골드와 높은 등급 상품 출현 확률로 표현한다. 보스 뒤에는 사용할 구간이 없으므로 카드 보상을 생성하지 않고 즉시 `RunVictory`로 전환한다. 기존 보상 선택 코드는 특수 사건 재사용 후보로만 보존한다.

### 5.3 골드와 상점 휴식

전투 승리 시 겁쟁이 도박사 3, 총잡이 4, 광신도 6, 사기꾼 7, 집행자 9, 최종 보스 15골드를 지급한다. 더 높은 최대 영혼 구간의 적은 낮은 구간보다 항상 많이 지급하며, 같은 최대 영혼에서는 전용 능력·카드와 등급 위험도를 반영한다. 지급량은 프로필 데이터로 관리하고 플레이 테스트에서 조정한다.

상점에서는 골드를 사용해 상품과 서비스를 구매한다. 판매 카드는 왼쪽 일반 카드 3장과 오른쪽 악마 카드 2장으로 고정하며 각 카드의 재고는 1개다. 왼쪽 후보에는 자동 발동 카드를 포함할 수 있다. 일반·자동 발동 카드는 일반 카드 덱에, 악마 카드는 악마 카드 덱에 추가한다. 구매한 슬롯은 `SOLD OUT` 표지로 교체하고 나머지 상품은 유지한다. 방문당 카드 구매 횟수 제한은 없어 골드가 충분하면 재고가 남은 슬롯을 모두 구매할 수 있으며, 새로고침과 재입고는 제공하지 않는다.

휴식은 독립 노드가 아니라 위스키 오브젝트로 제공하는 상점 서비스이며, 한 상점에서 1회만 골드를 지불해 영혼을 회복한다. 라이터를 통한 일반 카드 제거도 방문당 1회 제공한다. 골드와 이용 조건이 허용하면 같은 방문에서 위스키와 라이터를 모두 이용할 수 있다. 둘 중 하나 이상 이용한 방문은 다음 상점부터 두 서비스 가격을 함께 한 단계 올리며, 하나만 이용한 경우와 둘 다 이용한 경우의 상승폭은 같다. 어느 쪽도 이용하지 않은 방문은 가격을 올리지 않는다. 카드 강화와 유물은 상점 콘텐츠 범위에 따라 추후 제공한다.

상점에는 무료 `나가기` 버튼을 항상 제공한다. GameScene 프로토타입은 위스키·라이터 기본 가격 2골드와 이용 방문당 공통 +1골드를 사용하며, 판매 카드 가격과 위스키 회복량을 포함한 최종 밸런스 값은 플레이 테스트 뒤 확정한다.

영혼 회복은 최대치를 넘을 수 없다. 판매 카드와 모든 서비스의 가격, 휴식 회복량은 아직 확정하지 않으며 골드 지급량 및 계약 비용과 비교해 조정한다. 상점 콘셉트 이미지의 가격과 영혼 수치는 화면 구성을 보여 주는 예시에 불과하고 밸런스 값으로 사용하지 않는다. 현재 골드로 구매할 수 없는 가격은 빨간색으로 표시한다.

### 5.4 카드 강화 원칙

강화는 숫자보다 효과를 개선한다. 숫자를 바꾸면 블랙잭 확률 구조와 카드 정체성이 동시에 변하므로 프로토타입에서는 금지한다.

예시:

- 수정 구슬: 확인 2장 → 3장
- 리볼버: 숫자 1개 선언 → 조건부 2개 선언
- 보위 나이프: 강제 히트 후 추가 카드 버림 제거

## 6. 덱과 카드 시스템

### 6.1 시작 덱

기본안은 숫자 1~10을 2장씩 포함한 20장이다. 에이스 역할의 숫자 1은 자동으로 1 또는 11로 계산한다.

프로토타입 첫 플레이 테스트에서 20장 덱을 우선 사용한다. 평균 전투 시간이 길거나 원하는 효과 카드 재등장 빈도가 낮으면 16장 구성으로 축소한다.

새 런 시작 시 사탄·벨페고르·바알제붑·마몬으로 고정된 기본 풀에서 서로 다른 악마 카드 2장을 동일 가중치로 무작위 추첨해 모두 시작 악마 카드 덱에 넣는다. 선택 화면은 열지 않는다. 이 지급은 계약 비용과 전투당 계약 횟수를 소비하지 않으며 첫 상대 선택 전에 체크포인트로 저장한다.

### 6.2 일반 카드 역할

| 숫자 | 대표 카드/역할 | 기획 의도 |
| ---: | --- | --- |
| 1 | 에이스 및 독극물 | 합계 안정성과 영혼 베팅 |
| 2 | 기본 카드 및 부활초 | 낮은 숫자와 선택적 자기 손패 재배분 |
| 3 | 기본 카드 및 거짓말 탐지기 | 낮은 숫자와 비공개 정보 추론 |
| 4 | 기본 카드 및 화염 방사기 | 낮은 숫자와 공개 카드 정리 |
| 5 | 수정 구슬 및 회중시계 | 다음 카드 탐색·덱 조작 또는 사용 완료 카드 재활성화 |
| 6 | 위협용 해머 | 상대 공개 카드 제거, 스탠드 해제와 비공개 카드 교체 |
| 7~8 | 리볼버 | 비공개 숫자 추측 공격 |
| 9~10 | 보위 나이프 | 낮은 공개 합계의 상대에게 강제 히트 |

### 6.3 카드 사용 공통 규칙

- 사용 가능한 카드는 테두리와 아이콘으로 강조한다.
- 카드를 사용해도 그 카드의 숫자는 효과가 명시하지 않는 한 합계에 남는다.
- `버린다`가 명시된 카드는 합계에서 제거되고 버린 카드 더미로 간다.
- 비공개 카드가 앞면 공개되면 숫자와 효과는 상대와 AI의 공개 정보가 되지만 카드 역할은 바뀌지 않는다.
- 앞면 공개된 비공개 역할 카드는 공개 합계·중간 버스트·공개 카드 대상 효과에서 제외하고, 체인지·비공개 교체·비공개 추측·최종 승부에서는 계속 비공개 카드로 취급한다.
- 양측 손패에서 앞면 공개 여부와 관계없이 비공개 역할 카드의 화면 왼쪽 위치를 유지한다.
- 한 카드의 효과는 한 번만 사용한다. 사용 여부를 카드 위 아이콘으로 표시한다.
- 대상이 없는 효과는 사용할 수 없다.

### 6.4 자동 발동 카드

자동 발동 카드 원본은 효과가 끝나도 공개 카드로 테이블에 남고 숫자 합계에 계속 포함된다. 효과 완료 자체로 덱이나 버린 더미로 돌아가지 않는다. 라운드 종료 또는 카드 문구가 명시한 손패 재배분·원본 폐기만 예외로 한다.

- 최초 2장 배분 중에는 발동하지 않는다.
- 히트, 강제 히트, 카드 효과로 공개 영역에 추가되었을 때 발동한다.
- 처리 순서는 `카드 공개 → 자동 효과 → 버스트 확인 → 다음 효과`이다.
- 효과 처리 후 기본적으로 버린다. 카드에 `지속`이 있으면 공개 영역에 남긴다.
- 여러 장이 동시에 추가되면 추가된 순서대로 처리한다.
- 최신 카드 숫자는 독극물 1, 부활초 2, 거짓말 탐지기 3, 화염 방사기 4, 회중시계 5다. 기존 코드의 독극물 2·화염 방사기 9·회중시계 9 정의 키는 후속 구현에서 새 물리 카드 정의로 이관한다.

폴드 삭제에 따라 독극물과 루시퍼는 다음 효과로 개정한다.

- **독극물:** 발동 즉시 `지금 즉시 스탠드한다` 또는 `영혼 3개를 담보로 건다` 중 하나를 선택한다. 현재 영혼이 3개보다 적다면 현재 보유한 영혼을 모두 건다. 담보 선택 뒤 해당 라운드에서 승리하면 영혼을 5개로 돌려받으며 최대 영혼을 넘을 수 없다.
- **부활초:** 양쪽은 각각 영혼 1개를 버릴 수 있다. 영혼을 버린 쪽만 자신의 모든 카드를 버린 뒤 비공개 카드 1장과 공개 카드 1장을 다시 받는다. 두 선택은 독립적이며, 영혼을 버려 0이 되면 즉시 사망한다. 적 AI의 선택 기준은 추후 확정한다.
- **루시퍼:** 계약 즉시 현재 소유자의 악마 덱에서 최대 5장을 제시하고, 그중 1장과 추가 계약하거나 건너뛴다. 루시퍼의 대가로 영혼 1개를 잃고, 선택했다면 그 악마 카드의 효과와 개별 대가도 모두 적용한다. 선택하지 않은 후보는 악마 버린 더미로 이동한다.

독극물의 즉시 스탠드와 `스탠드할 수 없음` 효과가 충돌할 때의 우선순위는 추후 확정한다. 루시퍼는 현재 소유자의 남은 악마 덱을 후보 풀로 사용하고, 같은 악마·루시퍼 중복을 별도 물리 계약 인스턴스로 허용한다. 추가 계약에는 최초 기본 비용과 사용 횟수를 다시 부과하지 않는다.

### 6.5 카드 문구 표준

모든 카드는 아래 순서로 작성한다.

`발동 조건 → 비용/대상 → 효과 → 처리 후 위치`

예: `상대의 공개 카드 1장을 선택해 버린다. 상대가 스탠드 상태라면 스탠드를 취소하고 비공개 카드 1장을 버리게 한 뒤 새 비공개 카드 1장을 뽑게 한다.`

`카드 소유자` 대신 `자신`, 반대편은 `상대`로 통일한다. 취소·교체·버림의 처리 시점을 카드 데이터에 명시한다.

## 7. 악마 계약

### 7.1 프로토타입 제공 방식 — 기획 확정

- 일반 카드 덱과 악마 카드 덱은 테이블 위에서 서로 구분되는 별도 덱 오브젝트로 둔다.
- 두 덱의 맨 위는 각각 해당 덱 전용 카드 뒷면으로 표시한다.
- 일반 카드 덱과 악마 카드 덱을 호버하면 현재 포함된 카드 목록을 표시하되 실제 덱 순서는 노출하지 않는다.
- 전투 시작 시 악마 덱을 섞는다.
- 플레이어가 악마 카드 덱을 선택해 `계약`을 시작하면 영혼 1을 먼저 지불한다.
- 악마 덱에서 제시 가능한 카드 중 최대 2장을 중앙 선택 영역에 앞면 카드로 펼쳐 `발견` 방식으로 제시한다. 카드가 1장이면 1장만 제시하고, 0장이면 계약할 수 없다. 각 후보의 호버 정보에는 능력과 대가를 함께 표시한다.
- 후보 1장을 선택하면 해당 카드를 플레이어 앞 계약 영역으로 옮기고, 미선택 카드가 있으면 악마 버린 더미로 보낸다.
- 활성 계약 카드는 일반 카드와 같은 크기의 앞면 카드로 유지하며, 호버하면 능력과 대가 및 공개 가능한 현재 상태를 표시한다.
- 선택한 악마의 계약 즉시 효과를 처리하고, 지속 효과는 해당 스테이지 종료까지 유지한다.
- 하나의 전투 스테이지에서 계약은 원칙적으로 1회만 허용한다.
- 카드·유물·악마 효과가 추가 계약을 명시한 특별한 상황만 횟수 제한의 예외로 처리한다.
- 비용 지불 후 남은 영혼이 0이면 계약할 수 없다.
- 악마의 개별 대가는 영혼을 0까지 감소시킬 수 있으며 0이 되는 순간 즉시 전투 패배로 처리한다.
- `할 수 있다`고 적힌 계약 효과는 소유자가 실행 여부를 선택한다.
- 추가 계약에서는 같은 악마를 다시 선택할 수 있고 각 계약을 별도 인스턴스로 유지한다.
- 적의 계약에도 플레이어와 같은 비용·선택·대가·중첩·정리 규칙을 적용한다.

이 방식은 무작위성과 선택권을 함께 제공하면서 별도의 악마 상점이나 사전 덱 편집 UI 없이 구현할 수 있다.

### 7.2 계약 카드 표시 정보

- 악마 이름과 일러스트
- 계약 즉시 효과
- 지속 능력
- 대가와 발동 시점
- 남은 차례 또는 카운터
- 계약 후 플레이어 영혼

### 7.3 악마별 역할과 최신 개정

| 악마 | 핵심 역할 | 위험 |
| --- | --- | --- |
| 사탄 | 허용된 일반 행동 또는 현재 면 능력 중 선택. 능력 성공 시에만 윗면 추측↔아랫면 강제 히트 전환, 절대 버스트 방지 | 스탠드 불가, 종말 카운트 4가 0이면 영혼 2 손실 |
| 벨페고르 | 히트 전 덱 위 카드 확인 | 상대 스탠드 시 자신도 행동 제약 |
| 바알제붑 | 버스트를 영혼과 양측 공개 카드로 대체 | 공개 카드가 3장 이하면 스탠드 불가 |
| 아스모데우스 | 차례 시작에 상대 강제 히트 선택 | 7 이하 카드 사용 불가 |
| 루시퍼 | 악마 5장 중 추가 계약 | 영혼 1과 선택 악마의 대가를 함께 부담 |
| 마몬 | 일반 행동 대신 주사위를 다시 굴리고 최종 합계를 조작 | 재굴림으로 차례 종료, 6이면 즉시 버스트 |
| 레비아탄 | 첫 리볼버 예측 실패 시 한 번 더 준비·예측 | 두 예측이 모두 실패하면 영혼 1 손실 |
| 메피스토펠레스 | 보위 나이프 결과가 21 초과면 직접 버스트 | 실패하면 자신의 비공개 카드 공개 |
| 파이몬 | 상대 버스트 때 덱 위 카드를 전투 동안 추방 | 라운드 종료 합계 18 이하면 최우선 버스트 |
| 벨리알 | 상대 공개 카드를 가져와 즉시 사용 | 라운드 시작 영혼 1 손실 |
| 바포메트 | 상대 오망성 소진 시 버스트·덱 초기화 | 자신의 오망성 소진 시 자기 버스트·덱 초기화 |
| 아자젤 | 계약 시와 정상 히트 뒤 공개 수동 카드 효과를 왼쪽부터 한 번씩 실행 | 같은 숫자 공개 카드가 추가되면 버스트 |

바알제붑의 버스트 대체는 계약 소유자가 자신의 공개 카드 1장과 상대 공개 카드 1장을 순서대로 직접 선택한다. 영혼 1 대가가 소유자를 0으로 만들면 즉시 전투 패배로 끝내고 선택·카드 이동·남은 효과를 생략한다. 적 소유자는 공개 정보만 사용해 자신의 높은 숫자 카드와 상대의 낮은 숫자 카드를 결정적으로 선택한다. 과거의 `가장 최근 공개 카드 자동 폐기`는 이천서의 명시적 기획 정정으로 폐기됐다.

악마 계약이 공개 영역에 생성한 특수 카드의 숫자는 **블랙잭 합계에 포함한다**. 숫자가 없는 계약 상태·카운터·표식은 합계에 포함하지 않는다. 사탄의 윗면·아랫면은 활성 계약 카드 상태이며 일반 카드 숫자를 추가하지 않는다.

### 7.4 계약 임시 카드와 소유권

- 계약이 생성·이동·추방한 카드는 현재 전투의 여러 라운드에 걸쳐 유지하지만 런 덱을 영구 변경하지 않는다.
- 바포메트의 오망성은 전투 종료 시 모든 위치에서 제거한다.
- 파이몬이 추방한 카드는 전투 종료 시 원래 소유권과 전투 시작 덱 구성을 복구한다. 플레이어 런 덱에는 제거를 반영하지 않는다.
- 벨리알이 가져온 카드는 전투 중 계약 소유자의 카드로 취급하고 라운드 종료 시 그 소유자의 버린 카드 더미로 보낸다. 전투 종료 시 원래 소유권으로 복구한다.
- 일반 라운드 정리는 위 임시 상태를 없애지 않으며, 전투 종료 정리만 런 원상복구를 수행한다.

파이몬의 카드 확인·추방이 끝난 뒤에는 그 시점의 라운드 결과에서 임시 승자 한 명만 정한다. 해당 승자가 파이몬 계약자이고 전체 손 합이 18 이하라면 한 번 버스트시켜 승패를 뒤집되, 새 승자의 파이몬이나 새로 발생한 상대 버스트 반응은 같은 라운드에 다시 연쇄하지 않는다. 이는 무한 승패 반전을 막기 위한 프로토타입 결정이며 플레이 테스트 후 재검토한다.

바포메트의 상대 묶음은 오망성 1~5, 소유자 묶음은 1~3으로 고정한다. 한 묶음이 대상의 드로우 더미에서 모두 빠지면 손·버린 더미·추방·탈취 위치의 해당 물리 카드까지 회수하고, 가용 덱을 다시 섞은 뒤 같은 묶음을 재삽입한다. 숫자 1은 기존 에이스 계산을 따르며, 이 `드로우 더미 0장` 소진 정의와 소유자 숫자는 DC-D15 프로토타입 결정으로 플레이 테스트 후 재검토한다.

### 7.5 사탄 윗면/아랫면 계약 상태와 카운터 확정안

- 계약 카드는 윗면으로 시작한다.
- 윗면은 숫자 두 개를 선언해 상대 비공개 카드와 하나라도 일치하면 버스트시킨다.
- 아랫면은 상대를 강제로 히트시키고 공개 합이 21 이하라면 새 카드를 즉시 버린다.
- 계약 소유자의 차례 종료마다 계약 카드를 뒤집는다.
- 계약 직후 종말 카운트 4로 시작하고 계약 소유자의 차례 시작마다 1 감소한다.
- 카운트가 0이 된 차례 시작 시 영혼 2를 한 번 잃는다.
- 기존 숫자 8·10 `사탄의 권능` 별도 카드 방식은 폐기하고 활성 계약이 윗면/아랫면 규칙 상태를 소유한다. 이 상태는 일반 카드의 앞면/뒷면 공개 상태와 무관하다.

현재 코드의 6카운트·양측 차례 감소·별도 권능 카드는 과거 구현 기준이다. 새 규칙은 후속 계약 개정 작업에서 테스트와 UI를 포함해 함께 이관한다.

## 8. 적 AI와 정보 설계

### 8.1 공정성 원칙

AI는 아직 앞면 공개되지 않은 플레이어 비공개 카드, 덱 순서, 난수 결과를 직접 열람하지 않는다. 앞면 공개된 비공개 카드의 숫자는 공개 사실에서 얻은 확정 정보로 사용한다. 그 밖에는 다음 공개 정보만 사용한다.

- 공개 카드와 버린 카드
- 공개된 카드 숫자와 플레이어 덱 구성
- 플레이어 행동 이력
- 활성 카드·계약 효과
- 정보 획득 카드의 결과

디버그 빌드에서는 AI가 사용한 입력 목록을 로그로 남겨 부정 정보 접근 여부를 검증한다.

### 8.2 추론 모델

1. 시작 시 플레이어 덱에 남아 있는 각 숫자의 개수를 사전 확률로 삼는다.
2. 공개·버린 카드를 제외해 확률을 갱신한다.
3. 체인지, 히트, 특정 카드 사용 등 관찰된 행동에 적 성향별 가중치를 적용한다.
4. 가능한 비공개 카드별 최종 합계, 버스트 확률, 플레이어 승리 확률을 계산한다.
5. 적은 기대 영혼 손익이 가장 높은 행동을 선택하되 난이도별 무작위성을 적용한다.

### 8.3 행동 평가

AI 행동 후보는 히트, 스탠드, 사용 가능한 카드 효과와 계약이다. 적은 폴드를 사용하지 않는다. 각 행동의 점수는 아래 요소로 계산한다.

`예상 적 피해 - 예상 자기 피해 + 생존 보정 + 성향 보정 + 소량의 무작위값`

일반 적은 계산 깊이 1, 엘리트와 보스는 카드 효과 이후까지 포함한 계산 깊이 2를 사용한다. 프로토타입에서 몬테카를로 탐색은 사용하지 않는다.

플레이어 비공개 카드의 숫자가 이미 공개되었고 적이 현재 사용할 수 있는 리볼버를 가지고 있으면, 적 유형별 점수·확률 임계값과 다른 일반 행동보다 리볼버 사용을 우선한다. 선언 값은 공개된 비공개 숫자와 정확히 같아야 한다. 비공개 숫자가 아직 공개되지 않았을 때만 확률 추론을 적용한다.

### 8.4 적 성향

| 유형 | 영혼 | 행동 특징 |
| --- | ---: | --- |
| 겁쟁이 도박사 | 3 | 18장 저수치 덱, 공개 합 15 스탠드, 기대 효용 양수인 수동 카드의 자발적 사용 확률 15% |
| 총잡이 | 3 | 리볼버 8장을 포함한 14장 덱으로 비공개 숫자를 추측하는 튜토리얼 적 |
| 광신도 | 5 | 첫 정상 차례부터 성공할 때까지 매 차례 계약을 우선하고, 상대 공개 카드가 2장 이상이면 바알제붑, 아니면 벨페고르 선택 |
| 사기꾼 | 5 | 공통 적 체인지 판단을 사용하되 비용 1 고정, 수정 구슬·거짓말 탐지기 중심의 18장 정보전 덱 |
| 집행자(엘리트) | 5 | 보유 악마 없음. 최초 배분 전에 매 라운드 플레이어 전투 덱에 독극물 1장을 섞고 자동 카드·강제 히트로 압박 |
| 최종 보스 | 8 | 전투 시작과 영혼 5·2 이하 진입 시 25장 덱의 세 고정 악마 계약 단계로 전환 |

상세 카드 수량과 처리 순서는 `rule.md` 15장을 단일 원본으로 사용한다. 모든 적은 자신의 비공개 역할 카드가 공개됐거나 이를 포함한 예상 최종 합이 21을 넘을 때 공통 체인지 평가를 수행한다. 후보는 21 이하에서 가장 높은 최종 합을 우선하고, 둘 다 넘으면 더 낮은 합을 고른다. 사기꾼만 비용을 매회 1로 고정한다.

### 8.5 플레이어에게 공개할 추론 정보 — 기획 확정

- 일반 난이도: 가능성이 높은 비공개 숫자 3개와 각각의 확률 표시
- 엘리트: 상위 2개 숫자와 `낮음/보통/높음` 신뢰도 표시
- 보스: 추론 방향과 신뢰도만 표시
- 적의 정확한 다음 행동은 표시하지 않으며, 강력한 고유 행동만 1차례 전에 예고한다.
- 거짓 추론을 보여 주는 보스는 능력 설명과 왜곡 상태 아이콘을 사전에 명시한다.

## 9. 콘텐츠 구성

### 9.1 적 제시

| 구간 | 제시 방식 | 목표 |
| --- | --- | --- |
| 첫 번째 전투 | 일반 적 2명 또는 일반 적 1명+엘리트 1명 | 추론 UI와 카드 사용 학습, 위험 선택 제공 |
| 두 번째 전투 | 일반 적 2명 또는 일반 적 1명+엘리트 1명 | 현재 덱·영혼에 맞는 상대 선택과 빌드 검증 |
| 최종 전투 | 보스 1명 | 전체 빌드와 영혼 관리 검증 |

두 후보는 적 이름, 등급, 최대 영혼, 핵심 성향 또는 특수 규칙과 예상 보상을 전투 전에 공개한다. 같은 후보 2명을 동시에 제시하지 않으며, 엘리트는 한 선택 화면에 최대 1명만 포함한다.

### 9.2 보스 계약 단계안

보스는 영혼 8과 25장 전용 덱을 사용하며 현재 계약을 종료하고 다음 계약으로 교체할 수 있다. 악마 처리는 다음 고정 쌍 순서를 따른다.

1. 바포메트 계약·마몬 버림
2. 아스모데우스 계약·레비아탄 버림
3. 아자젤 계약·루시퍼 버림

전투 시작 시 1단계를 적용한다. 최대 영혼 8의 `floor(66%)=5`, `floor(33%)=2`를 전환선으로 사용해 피해 처리 뒤 생존한 보스가 5 이하일 때 2단계, 2 이하일 때 3단계로 즉시 전환한다. 큰 피해로 두 선을 동시에 넘으면 두 단계를 순서대로 처리하며, 회복해도 이전 단계로 돌아가지 않는다. 기존 코드의 `7~5·4~3·2~1` 정책은 과거 구현값이다.

고정 단계는 영혼 비용·후보 선택·일반 계약 횟수를 사용하지 않는다. 단계 전환 시 이전 계약과 버리기로 정한 짝 악마를 악마 버린 더미로 옮기고 현재 계약 하나만 유지한다. 치명 피해에는 후속 단계를 열지 않는다. 바포메트가 만든 오망성은 계약 교체와 별개로 전투 한정 카드 수명을 유지해 전투 종료 때 제거한다. 이 흐름은 EP-R06에서 구현·검증되었으며 정식 골드·저장·런 화면은 포함하지 않는다.

### 9.3 유물 예시

- 첫 계약의 영혼 비용 1회 면제
- 정확히 21 승리 시 영혼 1 회복
- 리볼버 사용 시 추론 확률을 상세 표시
- 덱을 다시 섞을 때 맨 위 카드 1장 확인
- 상점 휴식 회복량 +1

## 10. UI/UX 설계

### 10.1 전투 화면 정보 우선순위

1. 양측 영혼과 현재 합계
2. 양측 공개 카드와 플레이어 비공개 카드
3. 적 비공개 카드 및 AI 추론 패널
4. 덱·버린 카드 수와 사용 완료 상태
5. 활성 계약, 대가, 남은 카운터
6. 사용 가능한 행동 버튼
7. 전투 로그와 효과 처리 순서

### 10.2 화면 배치

- 고정 카메라: 플레이어가 서부 시대 술집 테이블에 앉은 시점을 유지한다.
- 상단 월드 영역: 좌측 적 버림패, 중앙 적 공개·비공개 카드, 우측 적 덱
- 중앙 월드 영역: 카드 효과와 선택 연출을 위한 공용 처리 공간
- 하단 월드 영역: 좌측 플레이어 일반 카드 덱·별도 악마 카드 덱·체인지, 중앙 비공개·공개 카드, 우측 플레이어 버림패
- 플레이어 앞 계약 영역: 선택한 악마 카드를 일반 카드와 같은 크기의 앞면 카드로 배치
- 우측 가장자리: 평소 숨겨 두었다가 카드 효과 시작 시 준비·판정 연출로 등장하는 리볼버·보위 나이프·위협용 해머 전용 구역
- 우측: 계약·지속 효과 및 전투 로그
- 최하단: 히트와 스탠드 버튼. 체인지는 비공개 카드, 계약은 악마 카드 덱 오브젝트에서 진입

카드와 카드 더미는 테이블 위 월드 오브젝트로 표현한다. 상세 효과, 영혼·골드, 추론 정보와 행동 버튼은 화면 UI로 분리해 가독성을 확보한다.

### 10.3 정보 표현 규칙

- 실제 합계와 공개 합계를 구분해 플레이어에게는 둘 다, 적 영역에는 공개 합계만 표시한다.
- 버스트 가능성이 있는 히트 버튼에는 위험 아이콘을 표시하되 결과를 확정적으로 예고하지 않는다.
- 영혼을 쓰는 행동은 비용과 행동 후 잔여 영혼을 버튼에 함께 표시한다.
- 체인지에는 현재 비용을 `무료`, `영혼 1`, `영혼 2`처럼 표시하고 같은 전투의 성공 횟수에 따라 즉시 갱신한다.
- 플레이어 비공개 카드는 뒷면 위에 실제 앞면을 반투명하게 겹쳐 플레이어만 확인하게 한다.
- 사용 완료 카드는 현재 위치에 남기되 검게 처리해 숫자만 표시한다.
- 플레이어 일반·악마 덱 호버 시 실제 잔여 카드 목록을 표시하되 순서는 숨기고, 적 덱 확인 시에는 공개 정보로 추론 가능한 후보 목록만 표시한다.
- 계약 후보 카드는 호버 시 능력과 대가를 함께 표시하며, 선택된 활성 계약 카드와 상점의 악마 카드 상품에도 같은 악마 상세 패널 표현을 사용한다.
- 연쇄 효과는 번호가 붙은 처리 대기열로 0.3~0.5초 간격 표시한다.
- 마지막 계약 차례에는 화면 테두리와 경고음으로 위험을 강조한다.

### 10.4 카드 효과 상호작용

카드 효과 입력은 하단 카드 제시, 선택지, 테이블 카드 직접 선택, 숫자 예측의 네 형식으로 통일한다. 어떤 카드가 발동하더라도 플레이어가 한 순간에 답해야 하는 질문은 하나만 유지한다.

- 하단 카드 제시는 계약 후보와 수정 구슬이 공유한다. 수정 구슬에는 `추가하지 않기`를 제공한다.
- 테이블 직접 선택은 위협용 해머를 기준으로 한다. 자신의 카드는 화염 방사기·회중시계·바알제붑, 상대 카드는 위협용 해머·바알제붑이 같은 호버와 클릭 규칙을 사용한다.
- 자동 발동 카드와 차례 시작 악마 능력은 카드 이름, 선택 결과와 영혼 비용을 한 화면에 표시한다.
- 바알제붑은 공개 카드가 존재하는 쪽만 선택 대상으로 만든다. 양쪽 모두 있으면 2단계, 한쪽만 있으면 단일 선택으로 처리하고, 양쪽 모두 없을 때만 발동하지 않는다.
- 화염 방사기와 부활초는 플레이어가 상대 결과를 보기 전에 자기 선택을 확정한다. 플레이어 확정 뒤 상대 결정을 공개하고 양쪽 결과를 동시에 적용한다.
- 회중시계는 재활성화 대상이 없어도 원본을 버릴지 유지할지 묻는다.
- 리볼버와 사탄 윗면은 숫자 예측 입력 기반을 공유할 수 있다. 다만 실제 배치, 확인 버튼과 3D 무기 연출은 미정이다.
- 여러 자동 카드와 계약 훅은 효과 처리 대기열에서 순서대로 열고, 현재 선택 중 다른 전투 입력을 잠근다. 같은 시점이면 자동 발동 카드를 기본 우선한다. 버스트 방지·대체나 즉시 전투 종료처럼 판정 자체를 바꾸는 악마 훅만 필요한 선행 예외로 둔다.

### 10.5 튜토리얼

팝업 설명보다 첫 적의 상황 설계를 통해 학습시킨다.

1. 첫 차례에 히트와 스탠드 설명
2. 사용 가능한 카드 강조
3. 적 비공개 카드 추론 패널 개방
4. 적이 낮은 확률 선택으로 실패하는 모습을 보여 공정성 전달
5. 첫 전투 종료 전 계약 1회 무료 제공
6. 승리 골드 확인과 상점의 카드·위스키·라이터 선택

튜토리얼 안내는 이미 이해한 플레이어가 즉시 건너뛸 수 있어야 한다.

## 11. 연출 및 아트 방향

- 3D 서부 시대 술집과 테이블을 사용하는 고정 카메라 기반 2.5D 화면
- 카드 앞면·뒷면은 얇은 3D 오브젝트, 덱과 버린 카드 더미는 높이가 있는 3D 오브젝트로 표현
- 남은 카드 수는 덱 높이 단계와 숫자 표시를 함께 사용
- 리볼버, 보위 나이프와 위협용 해머는 효과 발동 시 등장하는 3D 연출 오브젝트로 표현
- 리볼버는 사용 승인 직후 준비 상태로 등장하고 숫자 예측 뒤 성공·실패 사격으로 이어진 다음 다시 숨김
- 카드 상세 설명과 전투 정보는 화면 UI로 표시하는 월드 오브젝트·UI 혼합 방식
- 전투, 보상과 상점은 같은 술집 테이블을 공유하며 인물·조명·음악·테이블 오브젝트를 교체해 전환
- 상점에서는 적 대신 상인이 테이블 맞은편에 등장해 카드와 서비스 상품을 펼침
- 계약 시 배경 조명, 테이블 문양, UI 테두리를 악마별 색으로 일시 변경
- 적 캐릭터의 정지 일러스트·파츠 애니메이션·3D 여부는 추후 확정
- 생성형 리소스는 콘셉트 초안으로만 사용하고 최종 빌드에서는 색감·선 굵기·광원 방향을 통일

### 11.1 필수 피드백

- 카드 획득: 짧은 뒤집기와 숫자 강조
- 카드 사용: 카드가 중앙으로 이동한 뒤 대상 방향으로 효과 전달
- 영혼 피해: 영혼 아이콘 파괴 및 잔여량 강조
- 정확히 21: 전용 금색 플래시와 2배 피해 표시
- 버스트: 합계 숫자 붉은 파열, 원인 카드 강조
- 계약: 서명/낙인 연출과 대가 재확인

- 운 패배가 잦으면 체인지 비용 곡선과 정보 제공량을 먼저 조정한다.

## 14. 테스트 및 완료 조건

### 14.1 규칙 테스트

- 에이스 여러 장이 있을 때 가장 큰 21 이하 합계를 선택한다.
- 양측 모두 21 초과 시 21에 더 가까운 쪽이 승리한다.
- 동점은 플레이어 승리로 처리한다.
- 최초 배분 자동 발동이 발생하지 않는다.
- 카드 효과 처리 중 버스트가 즉시 라운드를 종료한다.
- 버스트·정확히 21의 피해량과 체인지 누적 비용이 표와 일치한다.
- 덱 소진 시 버린 더미가 정확히 한 번 섞인다.
- 영혼 0에서 계약할 수 없고, 영혼 0 도달 시 런이 끝난다.

### 14.2 AI 공정성 테스트

- AI 관측 상태에 플레이어 비공개 카드 값과 덱 순서가 포함되지 않는다.
- 같은 공개 상태와 같은 난수 시드에서 같은 행동을 선택한다.
- 공개·버린 카드 변화에 따라 추론 확률 총합이 100%로 갱신된다.
- 거짓 정보를 표시하는 보스 외에는 UI 확률과 AI 내부 확률이 일치한다.

### 14.3 프로토타입 완료 정의

- 시작부터 보스 승리 또는 패배까지 중단 없이 1런 진행 가능
- 핵심 행동 5종과 프로토타입 악마 7종의 규칙 처리가 정상 작동
- 일반 4종, 엘리트 1종, 보스 1종의 행동 차이가 체감됨
- 시작 악마 2장 지급, 스테이지 골드 정산, 상점 나가기, 사건 해결과 런 종료 체크포인트가 명확히 구분됨
- 전투나 보류 선택 도중 종료하면 마지막 완료 체크포인트에서 같은 후보·상품·사건으로 이어 하기 가능
- 5회 이상 완주 테스트에서 진행 불가 버그 0건
- 목표 전투 시간과 핵심 지표를 기록할 수 있는 로그 확보

### 15.2 원문에 반영을 권장하는 변경

1. **일반 합계 승리의 피해를 명시한다.** 현재 피해 표에는 적 버스트와 정확히 21만 있어, 일반 비교 승리 시 전투가 진행되는지 모호하다.
2. **개정된 악마 효과와 자동 카드 숫자를 구현에 이관한다.** 사탄·마몬·레비아탄·메피스토펠레스의 기존 처리기와 독극물·화염 방사기·회중시계 정의 키를 새 규칙으로 교체한다.
3. **카드 사용 후 숫자가 합계에 남는지 명시한다.** 본 기획서는 `버린다` 문구가 없으면 남는 것으로 정했다.
4. **자동 발동 카드의 처리 후 위치와 동시 발동 순서를 공통 규칙으로 올린다.** 카드별 예외만 개별 문구에 둔다.
5. **사탄의 4카운트와 윗면/아랫면 표시를 같은 값으로 유지한다.** 카운트 감소·상태 전환·영혼 대가를 코드와 두 전투 화면에서 함께 갱신한다.
6. **동시 버스트와 효과 연쇄 중 전투 종료 우선순위를 추가한다.** 구현과 QA에서 가장 큰 충돌 가능성이 있다.
7. **적 행동 정보의 공개 범위를 적 등급별로 확정한다.** 확률 UI가 핵심 차별점이므로 후순위로 남기지 않는 편이 좋다.
8. **Notion 적 프로필을 현행 코드로 다시 이관한다.** 광신도의 악마 풀을 벨페고르·바알제붑으로 제한하고 상대 공개 카드 2장 경계를 검증한다. 집행자의 악마 덱은 비워 둔다.

### 15.3 플레이 테스트 후 결정할 항목

- 시작 덱을 16장으로 축소할지 여부
- 다중 레비아탄 계약의 추가 발동 횟수와 대가 중첩 처리
- 모든 악마의 대가 수치와 동일 악마 중첩 시 효과·대가의 카드별 계산 방식
- 자동 발동 카드가 일부 상황에서 공개 영역에 남아야 하는지
- 보스의 거짓 추론 정보가 재미보다 불공정함을 크게 만드는지
- 상점·무작위 사건 등장 가중치와 연속 등장 제한 여부
- 첫 번째·두 번째 전투의 엘리트 등장 확률
- 높은 등급 카드의 기준과 카드 등급별 보상 등장 확률
- 적별 골드 `3·4·6·7·9·15`와 상점 상품·휴식 가격의 실제 경제 밸런스
- 겁쟁이 도박사의 합 15 스탠드·수동 카드 15%가 초반 난도에 적절한지
- 공통 적 체인지와 광신도 계약 재시도·집행자 독극물 누적·보스 영혼 5·2 전환의 전투 시간 영향

## 17. 후속 문서

프로토타입 제작 전 아래 문서를 별도로 준비한다.

- 카드 데이터 시트: ID, 숫자, 발동 조건, 대상, 효과, 처리 후 위치, 강화안
- 악마 계약 데이터 시트: 즉시 효과, 지속 효과, 대가, 카운터, 중첩 규칙
- 적 AI 정책표: 성향 가중치, 행동 임계값, 계약 사용 조건
- 전투 상태 전이표: 입력, 처리 순서, 종료 조건, 예외
- 플레이 테스트 기록지: 전투 시간, 계약 횟수, 피해 원인, 승패, 혼동 지점

이 문서는 `rule.md`의 규칙을 대체하지 않는다. 구현 중 충돌이 생기면 본 문서의 임시 결정안을 우선 적용하고, 플레이 테스트 결과를 근거로 두 문서를 함께 갱신한다.
