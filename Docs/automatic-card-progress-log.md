> **원본 수명 정정 기록(2026-08-01)**
> 독극물·거짓말 탐지기·화염 방사기와 비재배분 부활초는 효과 완료 뒤 원본을 버리지 않고 공개 손패에 유지하도록 수정했다. 유지된 숫자는 공개 합과 버스트·최종 승부에 계속 반영한다. 부활초 소유자가 전체 손패 재배분을 선택한 경우와 회중시계의 선택 폐기는 명시적 예외로 유지한다. 관련 회귀 43/43은 통과했다. 전체 EditMode는 867/869가 통과했으며, 이번 변경과 무관한 `DX02_U02` 프리팹 위치값과 `MOO01_U04` 색상 비교 2건이 단독 재실행에서도 실패했다.

> **동시 선택·우선순위 기획 변경 기록(2026-08-02)**
> 화염 방사기와 부활초는 플레이어 선확정·상대 후공개·양쪽 결과 동시 적용으로 변경했다. 회중시계는 재활성화 대상이 없어도 원본 유지·폐기만 결정한다. 자동 카드와 일반 악마 효과가 같은 시점이면 자동 카드를 기본 우선하고 판정 자체를 바꾸는 악마 훅만 선행 예외로 둔다. 이번 항목은 문서 결정이며 기존 소유자→상대 순차 코드는 아직 이관하지 않았다.

> **정식 획득 경로 변경 기록(2026-07-30)**
> 자동 카드 5종은 정식 런에서 상점 일반 상품으로 획득하도록 기획이 바뀌었다. 현재 `ShopController`는 기본 숫자 카드만 후보로 만들므로 아직 구현되지 않았으며, 기존 전투 보상 풀 등록과 AC 완료 증거는 그대로 보존한다.

> **현행 효과 변경 기록(2026-07-30)**
> 독극물은 영혼 담보·승리 시 5 회복 문구를 유지한다. 부활초는 양쪽이 각각 영혼 1개를 버릴 수 있고, 실제 지불한 참가자만 자기 손패를 모두 버린 뒤 비공개 1장과 공개 1장을 다시 받는다. 한쪽의 거절은 다른 쪽 선택에 영향을 주지 않는다. AC-RV03에서 기존 양측 강제 손실·전체 라운드 재시작 코드를 제거했다.

> **Notion v0.7 영향 기록**
> 새 사기꾼·집행자 덱 수량과 집행자의 매 라운드 플레이어 덱 독극물 1장 추가를 EP-R04~R05에서 코드에 이관했다. 주입은 최초 배분 전 가용 전투 덱 혼합·같은 라운드 드로우·전투 중 누적·종료 제거로 구현했다. 기존 AC-00~AC-RV01의 검증은 과거 완료 증거로 유지한다.

> **AC-RV02 구현 결과 (2026-07-29)**
> 집행자 프로필만 매 라운드 새 독극물 물리 카드를 플레이어 가용 덱에 추가한다. 주입 카드는 일반 카드처럼 드로우·버림·재순환하고 라운드가 거듭될수록 누적되지만 런 덱에는 반영하지 않으며 전투 종료 시 모두 제거한다. 정책 12/12·CoreLoop 466/466·StageProgression 189/189·전체 655/655가 통과했다.

## 1. 기록 원칙

- 계획과 실제 구현을 분리한다.
- 코드가 없는 문서 단계는 구현 완료로 기록하지 않는다.
- 단계마다 작업자, 변경 파일, 결정한 문제, 대상·전체 테스트와 실제 화면 결과를 남긴다.
- AI 대화 원문은 복사하지 않고 목적, 지시, 결과와 사람의 결정을 기술적으로 정리한다.
- 기획·코드·검증의 최종 승인 책임자는 이천서로 기록한다.
- 팀원의 예정 업무는 실제 변경과 검증이 확인되기 전까지 완료 기여로 기록하지 않는다.
- 사용자의 명시적 요청 전에는 스테이징·커밋·푸시하지 않는다.
