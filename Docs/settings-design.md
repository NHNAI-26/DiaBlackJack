# 설정·일시정지 메뉴 기획서

> 프로젝트: DiaBlackJack
> 작업 범위: SET-00~SET-06
> 버전: v1.1
> 최종 갱신: 2026-08-09

## 1. 목표

게임 중과 메인 메뉴에서 같은 설정 화면을 제공한다.

- ESC 일시정지 메뉴: `계속하기 / 설정 / 게임 종료`
- 게임 플레이: 공용 카드 호버 툴팁 크기
- 사운드: Master, BGM, SFX
- 설정은 즉시 미리보기하고 설정 화면을 닫을 때 저장한다.
- 기존 볼륨 이벤트 채널과 `SoundManager` 연결은 유지한다.

## 2. 화면 흐름

```text
게임
└─ ESC → 일시정지
   ├─ 계속하기 → 게임
   ├─ 설정
   │  └─ ESC/뒤로 → 저장 → 일시정지
   └─ 게임 종료
      ├─ 취소/ESC → 일시정지
      └─ 확인 → 게임 종료
```

메인 메뉴는 같은 설정 프리팹을 설정 전용 모드로 연다. 덱 미리보기처럼 임시
오버레이가 열려 있으면 첫 ESC는 오버레이만 닫는다.

## 3. 설정 규칙

- 호버 툴팁 크기는 `작게 / 보통 / 크게` 순서로 제공하고 양 끝에서 순환한다.
- 기본값은 `보통`이다.
- 실제 배율은 작게 `(1,1,1)`, 보통 `(1.3,1.3,1)`, 크게 `(1.5,1.5,1)`이다.
- 크기 설정은 공용 `CardHoverTooltip`에만 적용한다.
- 전투 행동 툴팁, 악마 상세, 말풍선은 크기 설정 대상이 아니다.
- 해상도와 창 모드는 설정 항목과 런타임 기능에서 제공하지 않는다.
- 기본 볼륨은 Master 100%, BGM 80%, SFX 100%다.

## 4. 일시정지 규칙

- 메뉴가 열리면 `Time.timeScale = 0`으로 설정한다.
- 닫을 때 직전 `timeScale`을 복원한다.
- 일시정지 동안 전투 입력과 월드 클릭을 차단한다.
- UI와 오디오는 unscaled 입력·오디오 경로를 사용해 계속 동작한다.

## 5. 범위 제외

- 언어, 카메라 흔들림, 음소거
- 키 바인딩
- 해상도·창 모드 선택과 내부 렌더 해상도
- 전투 행동 툴팁·악마 상세·말풍선 크기 변경
