# 설정·일시정지 메뉴 기획서

> 프로젝트: DiaBlackJack
> 작업 범위: SET-00~SET-05
> 버전: v1.0
> 최종 갱신: 2026-07-30

## 1. 목표

Windows Standalone 기준으로 게임 중 즉시 열 수 있는 설정·일시정지 메뉴를 제공한다.

- ESC 일시정지 메뉴: `계속하기 / 설정 / 게임 종료`
- 게임 플레이: 해상도와 화면 모드
- 사운드: Master, BGM, SFX
- 설정은 즉시 미리보기하고 설정 화면을 닫을 때 저장한다.
- 기존 볼륨 이벤트 채널과 `SoundManager` 연결은 유지한다.

## 2. 화면 흐름

```text
게임
└─ ESC → 일시정지
   ├─ 계속하기 → 게임
   ├─ 설정
   │  └─ ESC/뒤로 → 저장 → 일시정지
   └─ 게임 종료
      ├─ 취소/ESC → 일시정지
      └─ 확인 → 게임 종료
```

덱 미리보기처럼 임시 오버레이가 열려 있으면 첫 ESC는 오버레이만 닫는다.

## 3. 설정 규칙

- 기본 화면 모드는 테두리없는 전체화면이다.
- 기본 볼륨은 Master 100%, BGM 80%, SFX 100%다.
- 해상도는 인덱스가 아닌 너비·높이를 저장한다.
- 지원 해상도는 크기별로 중복 제거하고 오름차순 정렬한다.
- 같은 크기의 여러 주사율 중 가장 높은 값을 적용한다.
- 화살표는 목록 양 끝에서 순환한다.
- 테두리없는 전체화면은 모니터 기본 해상도를 사용하고 해상도 화살표를 잠근다.
- 미지원 저장 해상도는 현재 모니터의 기본 해상도로 복구한다.

## 4. 일시정지 규칙

- 메뉴가 열리면 `Time.timeScale = 0`으로 설정한다.
- 닫을 때 직전 `timeScale`을 복원한다.
- 일시정지 동안 전투 입력과 월드 클릭을 차단한다.
- UI와 오디오는 unscaled 입력·오디오 경로를 사용해 계속 동작한다.

## 5. 범위 제외

- 언어, 카메라 흔들림, 음소거
- 키 바인딩
- 내부 렌더 해상도
- macOS/Linux 전용 화면 모드 대응
- 기존 데모 드롭다운 설정 UI의 운영 연결
