> **현행 획득 경로 변경(2026-07-30)**
> 정식 런의 무료 전투 카드 보상은 사용하지 않는다. 독극물·부활초·거짓말 탐지기·화염 방사기·회중시계는 상점의 일반 카드 3개 후보 풀에 포함하며, 구매하면 일반 카드 덱에 추가한다. 기존 일반 보상 풀 등록은 RW 유산 경로와 테스트 호환을 위해 보존한다.

> **현행 효과 문구 변경(2026-07-30)**
> 독극물의 영혼 선택은 `영혼 3개를 담보로 건다`로 표현하고, 승리 시 `영혼을 5개로 돌려받는다`로 표기한다. 부활초는 양쪽이 각각 영혼 1개를 버릴 수 있고, 실제로 버린 쪽만 자기 손패를 모두 버린 뒤 비공개 카드 1장과 공개 카드 1장을 다시 받는 효과다. 두 선택은 독립적이다. AC-RV03에서 기존 `양측 영혼 2 이상` 제한·양측 강제 손실·전체 라운드 재시작을 제거했다.

> **현행 숫자 변경 안내**
> 자동 발동 카드 숫자는 독극물 1, 부활초 2, 거짓말 탐지기 3, 화염 방사기 4, 회중시계 5다. AC-RV01에서 정의 키와 숫자, 보상·런/전투 변환 참조를 같은 기준으로 이관했다. 과거 키를 가진 `prototype-v1` 저장은 추측 변환하지 않고 거절하며 새 런을 안내한다.

> **현행 비공개 역할 안내 (2026-07-29)**
> 비공개 역할과 앞뒷면은 별개다. 비공개 카드가 사용·효과로 앞면 공개되면 숫자는 양측의 공개 정보가 되지만, 최종 승부 전까지 공개 합·중간 버스트·공개 카드 대상에서는 제외된다. 아래 “실제 비공개 숫자 비노출”은 아직 뒤집히지 않은 숫자와 거짓말 탐지기가 내부 비교한 값을 새로 유출하지 않는다는 뜻이다.

> **Notion v0.7 적 덱·능력 개정 (2026-07-29)**
> 사기꾼은 거짓말 탐지기 3장을, 집행자는 독극물 3장·거짓말 탐지기 2장·화염 방사기 2장·회중시계 2장을 전투 덱에 사용한다. 집행자는 첫 라운드를 포함해 매 라운드 최초 배분 전에 플레이어의 가용 전투 덱에 새 독극물 1장을 넣어 섞는다. AC-RV02에서 새 덱 수량과 주입·전투 중 누적·종료 제거를 구현했다.

## 1. 문서 목적

수동 카드 사용과 악마 계약에 이어, 공개 영역에 들어온 카드가 별도 행동을 소비하지 않고 즉시 효과를 일으키는 **자동 발동 카드 시스템**을 독립 작업으로 정의한다.

이 문서는 다음을 확정한다.

- 자동 발동을 검사하는 카드 유입 시점
- 여러 효과와 버스트 사이의 처리 순서
- 효과 선택 중 전투를 멈추고 재개하는 방식
- 효과 처리 후 원본 카드의 위치
- 플레이어와 적에게 동일하게 적용되는 카드별 규칙
- 숨은 정보와 적 AI의 공정성 경계
- 구현 전에 기획자가 임시로 결정해야 하는 충돌 사항

구현하지 않은 기능은 완료로 기록하지 않는다. 이천서는 기획·개발·검증의 최종 책임자이며 AI는 규칙 대조, 구조 초안과 검증 보조로만 기록한다.

## 2. 현재 기준선

2026-07-23 AC-00 작성 시점의 실제 상태는 다음과 같다.

- `CardActivationKind.Automatic` 분류는 존재하지만 자동 발동 카드 정의와 실행기는 없다.
- 수동 카드 4종은 `CardEffectResolver` 및 타입별 처리기로 실행된다.
- 플레이어와 적의 수동 카드 선택, 진행 세션 전달, 전투 UI가 구현돼 있다.
- 최초 배분, 일반 히트, 강제 히트, 수정 구슬 획득은 서로 다른 코드 경로로 카드를 손에 넣는다.
- 중간 버스트는 공개 합, 양쪽 스탠드 뒤 최종 승부는 비공개 카드를 포함한 전체 합으로 판정한다.
- 적 AI는 공개 관측만 사용하며, 카드 효과가 합법적으로 제공한 정보만 별도 결과로 받을 수 있다.
- 직전 자동 검증 기준은 DC-08 전체 EditMode 397/397이지만 AC-00에서는 Unity를 다시 실행하지 않는다.

## 3. 목표와 제외 범위

### 3.1 이번 시스템의 목표

- 공개 영역 카드 유입을 한 경계에서 감지한다.
- 자동 카드 효과가 끝나기 전에는 버스트·다음 행동·외부 효과를 진행하지 않는다.
- 플레이어 선택이 필요한 효과는 입력을 기다리고, 적 선택은 결정적인 정책으로 해결한다.
- 자동 효과가 끝난 뒤 원래 히트·카드 효과·적 행동을 정확히 한 번 재개한다.
- 독극물, 부활초, 거짓말 탐지기, 화염 방사기, 회중시계 5종을 양측 대칭으로 구현한다.
- 자동 카드가 보상과 런 덱을 거쳐 실제 전투에 등장하게 한다.

### 3.2 이번 시스템에서 제외하는 항목

- 나머지 악마 카드와 바포메트 오망성
- 카드 강화안과 유물
- 상점, 골드와 정식 런 순서
- 신규 애니메이션·사운드·외부 에셋
- 최초 배분 카드의 자동 발동
- 자동 카드가 비공개 상태로 손에 들어왔을 때의 발동

상점과 정식 런 진행은 HONG의 계획 영역을 유지한다. 이천서는 전투·카드·적 AI·현재 전투 UI 경계만 담당한다.

## 4. 공통 발동 규칙

### 4.1 발동 조건

자동 카드는 다음 조건을 모두 만족할 때 발동한다.

1. 카드 정의의 발동 종류가 `Automatic`이다.
2. 최초 라운드 배분이 끝난 뒤 카드가 새로 공개 영역에 추가된다.
3. 같은 공개 영역 진입에 대해 아직 자동 효과를 처리하지 않았다.

다음 유입은 발동 대상이다.

- 플레이어 또는 적의 일반 히트
- 보위 나이프·사탄 계약 아랫면 등 강제 공개 드로우
- 수정 구슬 등 카드 효과로 가져온 공개 카드
- 향후 효과가 공개 영역에 직접 생성하거나 이동하는 카드

다음 유입은 발동 대상이 아니다.

- 라운드 시작의 최초 공개·비공개 카드 배분
- 체인지로 선택한 새로운 비공개 카드
- 위협용 해머가 교체한 비공개 카드
- 이미 공개 영역에 남은 카드의 상태 변경
- 회중시계가 사용 완료 카드를 다시 사용 가능하게 만드는 동작

### 4.2 처리 순서

공개 카드 한 장의 유입은 아래 순서를 지킨다.

```text
카드 공개 영역 진입
  → 자동 카드 여부 확인
  → 자동 효과와 모든 선택 완료
  → 원본 카드 위치 처리
  → 현재 공개 합 버스트 확인
  → 중단했던 히트·카드 효과·적 행동 재개
```

- 자동 효과 처리 중에는 일반 행동, 수동 카드 사용, 체인지와 계약을 모두 잠근다.
- 효과가 영혼 0, 버스트 또는 라운드 초기화를 확정하면 남은 자동 발동과 원래 행동의 후속 처리를 취소한다.
- 여러 카드가 한 명령으로 공개 영역에 추가되면 실제 추가 순서대로 한 장씩 처리한다.
- 한 카드의 자동 효과와 버스트 검사를 마치기 전에는 다음 카드의 효과를 시작하지 않는다.
- 자동 효과는 별도 차례 행동으로 세지 않는다. 자동 카드를 뽑게 한 원래 행동만 차례를 소비한다.
- 자동 카드와 일반 악마 효과가 같은 판정 시점에 대기하면 자동 카드를 기본적으로 먼저 처리한다. 버스트 방지·대체, 자동 발동 여부 변경 또는 즉시 전투 종료처럼 판정 자체를 바꾸는 악마 효과만 필요한 선행 예외로 둔다.

### 4.3 최초 배분 예외

최초 배분으로 받은 자동 카드는 발동하지 않는다.

- 최초 공개 카드는 공개 영역에 남아 숫자를 합계에 포함한다.
- 최초 비공개 카드는 비공개 상태로 남아 최종 승부에만 숫자를 포함한다.
- 같은 카드가 이후 버린 더미를 거쳐 다시 공개 영역으로 들어오면 정상 발동한다.

이 예외는 시작하자마자 선택 창이 연쇄적으로 열리는 문제와 비공개 카드 수 불변식 훼손을 방지한다.

## 5. 카드 위치와 수명

### 5.1 기본 위치 규칙

- 자동 카드 원본은 효과 해결이 끝난 뒤에도 소유자의 공개 손패에 남는다.
- 유지된 원본의 숫자는 이후 공개 합과 버스트 판정에 계속 포함한다.
- 효과가 라운드나 전투를 즉시 끝내더라도 카드 총수와 물리 ID가 중복되거나 유실되지 않아야 한다.
- 자동 효과가 보류된 동안 원본은 공개 손패에 남지만 다른 효과의 선택 대상이나 수동 사용 대상이 될 수 없다.
- 라운드 종료 정리 또는 카드 문구가 명시한 이동만 원본을 버린 더미로 보낸다.

### 5.2 회중시계 예외

회중시계는 효과 처리 뒤 소유자가 `즉시 버림` 또는 `공개 영역에 유지`를 선택한다.

- 유지한 회중시계는 숫자 5로 공개 합에 남는다.
- 같은 공개 영역에 머무는 동안 다시 발동하지 않는다.
- 이후 버린 뒤 다시 공개 영역에 들어오면 새로운 발동으로 처리한다.
- 회중시계 자신과 다른 자동 카드는 재사용 가능 대상으로 선택할 수 없다.

## 6. 카드별 프로토타입 규칙

### 6.1 독극물 — 숫자 1

발동 소유자는 다음 중 하나를 선택한다.

1. 지금 즉시 스탠드한다.
2. 영혼 3개를 담보로 건다. 현재 영혼이 3보다 적으면 가진 영혼을 전부 건다.

프로토타입 결정은 다음과 같다.

- 활성 계약이 스탠드를 금지하면 계약 제한이 우선하며 `즉시 스탠드` 선택지는 제공하지 않는다.
- 영혼 지불은 계약 시작 비용과 달리 최소 1을 보존하지 않는다. 영혼 0이면 즉시 전투 패배다.
- 영혼을 담보로 걸고 현재 라운드에서 승리하면 영혼을 5개로 돌려받는다. 회복은 최대 영혼을 넘지 않는다.
- 부활초로 손패를 재배분하는 것 자체는 라운드 승리가 아니므로 독극물 회복은 발생하지 않는다.
- 같은 라운드에서 여러 독극물 비용을 지불하면 물리 카드별 회복 예약을 각각 보존한다.
- 원본 독극물은 효과 해결 후 공개 손패에 남고 숫자 1을 유지한다.

### 6.2 부활초 — 숫자 2

양쪽 참가자가 각각 다음 중 하나를 선택한다.

- 영혼을 버리지 않는다.
- 영혼 1개를 버리고 자기 손패를 재배분한다.

영혼을 버린 참가자에게만 다음을 적용한다.

1. 영혼 1개를 버린다.
2. 영혼이 0이면 즉시 사망하며 이후 재배분을 중단한다.
3. 생존했다면 자신의 모든 카드를 자기 버린 더미로 옮긴다.
4. 비공개 카드 1장과 공개 카드 1장을 다시 받는다.

한쪽의 거절은 다른 쪽의 선택을 막지 않는다. 둘 다 지불하면 각자 손패를 재배분하고, 둘 다 거절하면 어느 손패도 바꾸지 않는다. 플레이어는 상대 결정을 볼 수 없는 상태에서 먼저 자기 선택을 확정한다. 이후 상대 결정을 공개하고 양쪽 결과를 함께 적용한다. 적 AI는 자신의 공개 합이 21 초과이거나 상대 공개 합보다 3 이상 낮고 지불 뒤 생존할 때만 재배분을 선택한다.

- 손패 재배분은 라운드 승패가 아니므로 일반 피해, 정확히 21 보너스와 독극물 회복을 발생시키지 않는다.
- 지불하지 않은 참가자의 영혼·손패·스탠드 상태는 바꾸지 않는다.
- 부활초가 다른 카드 효과의 강제 드로우로 발동했다면 실제 손패 재배분이 발생한 경우 바깥 효과와 남은 차례 처리를 취소한다.
- 소유자가 영혼을 지불해 자기 손패를 재배분하면 원본 부활초도 `자신의 모든 카드`에 포함해 버린다. 소유자가 거절했으면 상대의 선택과 관계없이 공개 손패에 남는다.

### 6.3 거짓말 탐지기 — 숫자 3

발동 소유자는 1부터 10까지 숫자 하나를 선언한다.

- 상대의 비공개 카드 숫자가 선언 값 이상이면 `이상`, 작으면 `미만`으로 응답한다.
- 선언 숫자는 공개 정보다.
- `이상/미만` 응답은 효과 소유자만 확인한다.
- 결과와 공용 전투 로그에는 실제 비공개 숫자를 저장하지 않는다.
- 적이 사용한 경우 적의 합법적인 전투 지식에는 비교 결과만 저장하고 실제 숫자는 전달하지 않는다.
- 상대 비공개 카드가 정확히 한 장이 아니면 `판정 불가`로 안전하게 종료하고 숨은 값을 읽지 않는다.
- 체인지, 해머 교체 또는 새 라운드로 상대 비공개 카드가 바뀌면 이전 비교 지식을 폐기한다.
- 원본 거짓말 탐지기는 효과 해결 후 공개 손패에 남는다.

### 6.4 화염 방사기 — 숫자 4

발동 시점에 스탠드하지 않은 각 참가자는 자신의 공개 카드 한 장을 버리거나 건너뛸 수 있다.

- 양쪽 선택은 발동 시점 상태를 기준으로 서로 독립적으로 결정한다.
- 스탠드한 참가자는 선택 단계 자체를 건너뛴다.
- 화염 방사기 원본은 효과 처리 중인 카드이므로 소유자의 버릴 카드 후보에서 제외한다.
- 자신의 다른 공개 카드가 없으면 그 참가자만 자동으로 건너뛴다.
- 플레이어는 상대 선택을 보지 못한 상태에서 먼저 자기 선택을 확정한다. 이후 상대 선택을 공개하고 양쪽 카드 이동을 동시에 반영한다.
- 양측 선택을 모두 끝낸 뒤 원본을 공개 손패에 유지하고 공개 합 버스트를 검사한다.
- 원본 화염 방사기는 효과 해결 후 공개 손패에 남는다.

적은 자신의 공개 합이 17 이상이거나 이미 버스트 위험이면 숫자가 가장 큰 유효 카드를 버리고, 그 외에는 기본적으로 건너뛴다. 이 수치는 최초 프로토타입 정책이며 플레이 테스트로 조정한다.

### 6.5 회중시계 — 숫자 5

발동 소유자는 자신의 공개 영역에 있는 사용 완료 수동 카드 한 장을 다시 사용 가능한 상태로 만들 수 있다.

- 대상은 `Manual`이면서 `Used`인 자신의 공개 카드다.
- 회중시계 자신, 다른 자동 카드와 이미 사용 가능한 카드는 대상이 아니다.
- 유효 대상이 없으면 재사용 단계는 자동으로 건너뛴다.
- 재사용 가능 상태로 바꾸는 것은 효과 실행이 아니므로 자동 연쇄를 만들지 않는다.
- 대상 처리 뒤 회중시계를 즉시 버릴지 공개 영역에 유지할지 선택한다.
- 유지한 회중시계는 해당 손패를 떠나기 전까지 다시 발동하지 않는다.

### 6.6 AC-04 기존 구현과 이관 대상

- 기존 구현은 화염 방사기를 소유자→상대 순차 상호작용으로 처리한다. 현행 기획은 플레이어 선확정·상대 후공개·동시 적용으로 변경됐으므로 코드 이관이 필요하다.
- 양쪽 후보와 선택은 발동 시점 스냅샷을 기준으로 고정하며 한쪽 결과를 먼저 손패에 반영하지 않는다.
- 화염 방사기 원본은 소유자 후보에서 제외하며 두 단계 완료 뒤 공개 손패에 유지한다.
- 회중시계의 재활성화는 카드 효과 실행이 아니라 `Used → Available` 상태 변경만 수행한다.
- 회중시계 원본의 유지·폐기는 재활성화 대상과 분리된 두 번째 선택이며, 유지 시 자동 카드의 `Unavailable` 상태를 보존한다.
- AC-04에서는 사람·적 선택 규칙만 대칭으로 만들고 적의 자동 우선순위와 화면 입력은 AC-06에 남긴다.

### 6.7 AC-05 과거 구현 이력

아래 내용은 AC-RV03 이전 구현과 검증 기록이다. 현행 부활초 규칙이 아니며, 양쪽 독립 선택과 지불 참가자별 손패 재배분으로 교체해야 한다.

- 부활초의 `라운드 재시작`은 양측 현재 영혼이 모두 2 이상일 때만 선택할 수 있다.
- 재시작하면 부활초 원본을 버리고 양측 영혼을 각각 1 감소시킨 뒤, 승자·일반 피해·정확히 21 보너스·독극물 회복 없이 다음 라운드를 시작한다.
- 일반 `RoundResolution`을 위조하지 않고 `RoundTransition`에 원인, 이전·새 라운드 번호, 원본 물리 카드 ID와 소유자를 기록한다.
- 재시작은 독극물 승리 회복 예약, 거짓말 탐지기 지식, 현재 자동 상호작용과 계약의 라운드 상태를 정리한다.
- 수정 구슬·보위 나이프 등 부모 카드 효과에서 들어온 경우 부모 효과와 남은 차례 재개를 취소한다.
- 양측 손패를 각자의 버린 더미로 옮기고 스탠드를 해제한 뒤 기존 `StartRound`를 정확히 한 번 호출한다.
- 새 라운드 최초 공개·비공개 배분은 기존 예외대로 자동 발동하지 않는다.
- 거절은 부활초 원본만 버리고 영혼·라운드 번호·다른 손패를 바꾸지 않는다.
- 플레이어 화면 입력, 진행 세션, 보상 등록과 적 자동 선택 정책은 AC-06에 남긴다.

### 6.8 AC-06 구현 확정

- 독립 전투와 런 전투 세션이 동일한 상호작용 ID·옵션 ID로 플레이어 자동 카드 선택을 전달한다.
- 현재 자동 선택과 최근 해결 결과는 공개 정보와 소유자 전용 정보가 분리된 표시 모델로 화면에 전달한다.
- 적 자동 선택 정책은 공개 합·현재 영혼·공개 후보·합법적인 거짓말 탐지기 비교 지식과 이미 앞면 공개된 비공개 숫자만 관측한다. 아직 뒤집히지 않은 비공개 숫자는 전달하지 않는다.
- 적 정책이 잘못된 옵션을 반환하거나 예외를 일으키면 현재 유효 옵션의 첫 항목으로 안전하게 해결해 전투 교착을 막는다.
- 독극물·부활초·거짓말 탐지기·화염 방사기·회중시계를 정식 상점 일반 카드 풀에 추가한다. 기존 일반 보상 풀 등록은 유산 RW 경로에만 유지한다.
- 사기꾼의 일반 카드 한 장을 거짓말 탐지기로 교체하되 시작 덱과 다른 적 프로필은 바꾸지 않는다.
- `GameScene.unity`를 직렬화하지 않고 기존 View·Controller와 `GameManager`의 코드 기반 패널로 선택·결과를 표시한다.
- 정식 런의 골드·상점·진행 순서, 아트 자산, Packages와 외부 에셋은 변경하지 않는다.

## 7. 플레이어 입력과 적 AI

### 7.1 플레이어 입력

- 자동 효과 보류 중에는 전용 안내와 현재 선택지만 표시한다.
- 입력에는 증가형 상호작용 ID와 옵션 ID를 함께 사용해 오래된 클릭과 중복 제출을 거절한다.
- 적 차례 중 플레이어가 화염 방사기 대상으로 선택해야 하는 경우에도 전투를 일시 중단하고 플레이어 입력을 기다린다.
- 표시 모델은 규칙을 다시 계산하지 않고 현재 보류 상호작용의 안전한 읽기 모델만 사용한다.

### 7.2 적 AI

- 적이 자동 카드 소유자 또는 선택 대상이면 정상 행동 정책과 분리된 자동 효과 선택 정책을 사용한다.
- 적 자동 선택은 플레이어 입력 UI를 열지 않는다. 적 선택이 동기 처리되기 직전의 `ResolvingAutomaticCardEffect` 중간 프레임도 HUD·IMGUI에서 숨기고, 해결 결과만 공개 범위에 맞게 표시한다.
- 동일한 공개 상태와 시드는 동일한 선택을 만들어야 한다.
- 독극물은 생존 가능성과 스탠드 가능 여부를 비교한다.
- 부활초는 자기 공개 상태가 불리하고 영혼 1 지불 뒤 생존할 수 있을 때 자기 손패 재배분을 우선한다. 상대 선택은 상대 관점의 같은 기준으로 별도 판단한다.
- 거짓말 탐지기는 공개 추론 분포를 가장 비슷하게 둘로 나누는 선언 값을 우선한다.
- 화염 방사기와 회중시계는 공개 카드와 사용 상태만으로 선택한다.
- 앞면 공개된 비공개 숫자는 확정 공개 정보로 전달한다. 아직 뒤집히지 않은 숫자는 거짓말 탐지기의 이상·미만 비교 지식 외에는 직접 전달하지 않는다.

## 8. 런·보상 연결

- 자동 카드 5종은 안정적인 정의 키와 물리 카드 ID를 사용한다.
- 시작 덱에는 자동 카드를 추가하지 않는다.
- AC-06에서 개별 카드 효과와 통합 테스트를 기준으로 5종을 기본 일반 보상 풀에 등록했다.
- 카드 등급이 확정되지 않았으므로 높은 등급 보상 풀에는 자동으로 추가하지 않는다.
- 사기꾼 프로필의 거짓말 탐지기 등 적 덱 변경도 해당 카드의 양측 효과와 정보 은닉 검증 뒤에만 적용한다.
- 집행자가 넣는 독극물은 현재 전투에만 존재하는 새 물리 카드다. 이전 손을 정리한 뒤 플레이어의 드로우·버린 더미를 가용 덱으로 모으고, 최초 배분 전에 독극물 1장을 추가해 결정적으로 섞는다. 따라서 같은 라운드의 최초 배분부터 뽑힐 수 있다. 주입 카드는 라운드마다 누적·순환하지만 런 덱은 바꾸지 않고 전투 종료 시 모두 제거한다.
- 런 재시작 시 획득한 자동 카드와 전투 중 비교 지식·회복 예약·보류 상호작용은 초기화한다.

## 10. 완료 조건

다음을 모두 만족하면 자동 발동 카드 시스템 1차 범위를 완료한다.

- 최초 배분 예외와 모든 공개 유입 경로가 자동 테스트로 고정된다.
- 플레이어·적 양측에서 5종 효과와 선택이 동일한 규칙으로 실행된다.
- 자동 효과 뒤 버스트와 원래 행동 재개가 정확히 한 번 발생한다.
- 부활초가 지불한 참가자의 손패만 재배분하고 피해·독극물 회복·외부 효과를 중복 처리하지 않는다.
- 거짓말 탐지기가 아직 뒤집히지 않은 실제 비공개 값을 공용 결과·UI·AI 관측에 새로 노출하지 않는다. 이미 앞면 공개된 숫자는 기존 공개 정보로 유지한다.
- 카드 총수, 물리 ID, 버린 더미와 사용 상태가 반복 전투에서 보존된다.
- 독립 전투와 런 전투 UI에서 선택·결과·재시작을 확인한다.
- 대상 테스트, 전체 EditMode, 두 씬, 두 해상도와 Console 검증 결과를 기록한다.
- 외부 에셋·오픈소스 추가가 없음을 기록한다.

AC-06 코드·세션·표시·보상·적 정책 통합을 완료했고, AC-RV01에서 새 숫자와 정의 키를 원자적으로 이관했다. AC-RV01 전용 11/11과 전체 EditMode 522/522, `GameScene`·`CoreLoopTest` 스모크 및 Console Error/Warning 0건을 확인했다. 화면 해상도별 정밀 레이아웃 검수는 숫자 이관에서 UI 구조를 바꾸지 않았으므로 별도 후속 범위로 유지한다.
