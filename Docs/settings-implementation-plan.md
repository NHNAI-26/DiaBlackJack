## SET-06 순서

1. `HoverTooltipSize`와 배율 매핑을 추가하고 스냅샷·기본값을 교체한다.
2. PlayerPrefs 버전 1 오디오를 보존하며 버전 2 크기 설정으로 이관한다.
3. 화면 모드·해상도 타입, 서비스 API, 레거시 그래픽 설정 경로를 제거한다.
4. 공유 설정 프리팹을 툴팁 크기 화살표 선택기로 교체한다.
5. `GameHudView`가 공용 카드 호버 툴팁에 초기값과 변경값을 적용한다.
6. 대상 테스트부터 전체 EditMode까지 순서대로 검증하고 실제 결과를 기록한다.

## SET-06 완료 게이트

- `작게 / 보통 / 크게`가 양방향 순환하고 닫기 뒤 저장된다.
- 공용 카드 호버 툴팁 배율이 `1 / 1.3 / 1.5`로 바뀐다.
- 해상도·창 모드 UI, 타입, 저장·적용 코드, 레거시 컴포넌트가 남지 않는다.
- `GameScene`·`MainMenuScene`에서 Missing Script·broken prefab·Console Error가 없다.
- 대상·영향 assembly·전체 EditMode와 720p/1080p 수동 검증 결과가 기록된다.
