> **현행 기획 이관 상태 (2026-07-30)**
> 일반전 뒤 카드 보상 화면을 제거하고 골드 정산 뒤 상점으로 바로 이동하며, 보스는 골드 결과 기록 뒤 즉시 승리한다. 자동 발동 카드 5종은 상점 일반 상품 풀에 포함한다. RF-01A의 골드 상태·저장 왕복과 RF-01B의 프로필별 승리 정산은 구현됐지만 현재 `StageProgressionSession`의 `RewardSelection` 우회와 정식 상점 도메인은 아직 이관되지 않았다.

> **현행 상점 규칙 변경 안내 (2026-07-29)**
> 카드 슬롯은 각각 재고 1개지만 방문 전체 구매 횟수에는 상한이 없다. 라이터와 위스키는 방문당 각각 1회 이용할 수 있고 같은 방문에서 둘 다 가능하다. 둘 중 하나 이상 이용한 방문은 다음 상점의 두 서비스 가격을 함께 한 단계만 올린다. GameScene MVP의 기본 2골드·상승 +1은 임시값이다.

> **Notion v0.7 골드 영향 (2026-07-29)**
> 적이 6종으로 재구성되어 RF-00의 3·3·4·6·10은 과거 임시값이 되었다. 현행 지급량 3·4·6·7·9·15는 RF-01B 카탈로그와 승리 정산에 반영됐다.

## 1. 기록 원칙

- 계획과 실제 구현을 분리한다.
- 실제 작업자가 구현·검증하기 전에는 계획 역할을 완료 기여로 기록하지 않는다.
- 각 단계마다 작업자, 변경 파일, 직접 결정한 문제, 대상·전체 테스트와 실제 화면 결과를 남긴다.
- AI 초안과 사람의 검토·결정을 구분한다.
- 전투·보상·상대 선택 내부 변경은 이유와 이천서 검토 여부를 기록한다.

## 5. RFM01 GameScene 상점 규칙 선반영

### 5.1 수행 내용

- 카드 구매는 구매한 슬롯만 `SOLD OUT`으로 막고 방문 전체 구매 플래그를 두지 않아, 골드가 충분하면 남은 슬롯을 모두 살 수 있게 했다.
- 라이터와 위스키에 서로 독립된 방문당 1회 플래그를 두어 같은 상점에서 둘 다 이용할 수 있게 했다.
- 둘 중 하나 이상 이용한 방문을 닫을 때 가격 단계를 정확히 1 올리고 다음 방문의 두 서비스 가격에 함께 적용했다. 둘 다 이용해도 한 단계만 오르며, 미이용 방문은 유지한다.
- 새 런 재시작은 골드·상점 제안 순번·가격 단계·방문 플래그를 모두 초기화한다.
- 일반 상점과 라이터 카드 선택 화면에 `나가기` 버튼을 연결했다.
- GameScene MVP의 두 서비스 기본 가격 2골드와 이용 방문당 +1골드는 Inspector에서 조정 가능한 임시값으로 두었다.

## 7. 인수인계 핵심 계약

1. `StageProgressionSession`은 상대 선택·전투·전투 스테이지를 계속 소유하고 기존 카드 보상 코드는 유산 기능으로 보존한다.
2. 정식 런 UI는 기존 카드 보상 API를 표시하거나 호출하지 않고 바깥 세션의 승리 정산을 사용한다.
3. 카드 선택과 건너뛰기 모두 승리 골드를 한 번 지급한다.
4. 일반전 승리·골드 정산 뒤에는 별도 카드 보상 없이 상점을 연다.
5. 상점에서 나간 뒤에만 `TryAdvanceToNextStage()`를 호출한다.
6. 첫 상점 뒤에는 상대 선택, 둘째 상점 뒤에는 고정 보스다.
7. 보스 골드는 기록하지만 상점을 열지 않는다.
8. 상점 변경 영혼·덱은 다음 전투 생성 전에 반영한다.
9. 카드 강화·유물·무작위 사건은 RF에서 선점하지 않는다.
10. 카드 구매는 슬롯별 재고만 제한하고 방문 전체 구매 상한을 두지 않는다.
11. 라이터·위스키는 방문당 각각 1회이며 둘 중 하나 이상 이용한 방문은 다음 상점의 두 가격을 한 단계만 올린다.
12. `나가기`는 무료이고 라이터 선택 상태에서도 사용할 수 있다.

| 비용만 빠지고 효과 실패 | 모든 조건 사전 검증 뒤 비용·효과·플래그 일괄 적용 |
| 화면 재진입으로 상품 재추첨 | `ShopVisit`과 불변 Offer 보존 |
| 제거한 카드 ID 재사용 | 기존 단조 증가 ID를 줄이지 않음 |
| 담당 파일 충돌 | 새 RunFlow·Shop 폴더 우선, 기존 UI 최소 변경, 이천서 검토 |
| 서비스 둘 사용 시 가격 2단계 상승 | 방문별 공통 불리언 하나로 다음 가격 단계를 1회만 증가 |
| 카드 첫 구매 뒤 나머지 슬롯 차단 | 구매한 `OptionId`만 판매 완료로 기록하고 방문 전체 플래그 금지 |
