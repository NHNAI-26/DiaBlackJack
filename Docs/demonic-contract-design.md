> **중앙 계약서 UI 확정 (2026-08-01):** 전투 테이블 중앙에 플레이어와 상대의 기본 계약 기회를 합산한 계약서 2장을 표시한다. 플레이어는 계약서를 눌러 기존 계약 후보 UI를 연다. 후보를 실제로 선택해 계약이 확정되면 1장을 제거하고, 상대가 계약을 확정해도 1장을 자동 제거한다. 후보 선택 중에는 계약서가 유지되며 전투 외 화면에서는 두 장 모두 숨긴다. 기존 HUD `CONTRACT` 버튼은 사용하지 않는다.

> **현행 콘텐츠 범위 (2026-07-30)**
> 프로토타입 등장 악마는 사탄·벨페고르·바알제붑·아스모데우스·마몬·바포메트·아자젤 7종뿐이다. 새 런은 사탄·벨페고르·바알제붑·마몬 기본 풀에서 서로 다른 2장을 무작위로 뽑아 모두 시작 악마 덱에 지급한다. 루시퍼·레비아탄·메피스토펠레스·파이몬·벨리알과 그 밖의 악마는 기존 구현 여부와 관계없이 프로토타입의 시작 지급·상점·플레이어 덱·적 덱·계약 후보에서 제외한다.

> **시작 악마 지급 변경 (2026-07-31):** 두 후보 중 하나를 고르는 시작 선택 화면을 제거한다. 네 기본 악마는 동일 가중치로 추첨하며 중복 없이 2장을 모두 지급한다. 지급 결과는 첫 상대 선택 전에 저장하고 재접속 시 다시 추첨하지 않는다. 기존 선택 구현과 검증 기록은 과거 이력이며 코드 이관이 필요하다.

> **광신도 최신 규칙 (2026-07-31):** 광신도 전용 악마 풀은 벨페고르·바알제붑 2종이다. 상대 공개 카드가 2장 이상이면 바알제붑, 아니면 벨페고르를 선택한다. 영혼 수와 카드 사용 가능 여부는 선택에 사용하지 않는다. EPR07에서 코드·회귀 이관을 완료했다.

## 1. 문서 목적

이 문서는 `rule.md`의 악마 계약을 현재 전투·카드·런 구조에서 단계별로 구현할 수 있도록 구체화한다. 계약은 영혼을 직접 지불해 전투 규칙을 바꾸는 고위험·고효율 행동이며, 일반 카드 사용과 구분되는 DiaBlackJack의 핵심 차별점이다.

문서에 없는 세부 처리는 다음 세 종류로 구분한다.

- **현행 확정:** 원본 규칙과 전체 기획이 일치하거나 이천서가 이미 명시한 사항
- **프로토타입 결정:** 첫 구현과 테스트를 위해 이 문서에서 임시로 고정한 사항
- **기획 확인 게이트:** 구현 전에 이천서가 최종 승인하거나 플레이 테스트로 조정해야 하는 사항

AI는 규칙·코드 구조 대조와 문서 초안을 보조했다. 기획 승인과 변경 결정 책임자는 이천서다.

> **과거 Notion v0.7 적 계약 이관 (2026-07-29)**
> 플레이어의 악마 계약 규칙과 CU-M07 레비아탄 조건부 재예측은 그대로 유지한다. 당시에는 광신도 3종과 집행자 파이몬을 EP-R05에서, 보스의 바포메트→아스모데우스→아자젤 단계를 EP-R06에서 구현했다. 광신도·집행자 부분은 위 2026-07-30 현행 콘텐츠 범위 및 광신도 최신 규칙보다 우선하지 않는다.

| 미선택 카드 | 미선택 카드가 있으면 해당 전투의 악마 버린 더미로 보낸다. |
| 덱 표현 | 일반·악마 덱은 나란히 두고 맨 위에 각각 전용 카드 뒷면을 표시한다. |
| 덱 정보 | 두 덱을 호버하면 포함 카드 목록을 표시하되 실제 순서는 숨긴다. |
| 후보 연출 | 화면 하단에 앞면 월드 카드 최대 2장을 절반만 보이도록 작은 호로 펼치고, 호버 시 카드를 전진·상승·확대한 뒤 큰 UI 상세 패널에 이름·앞면·능력·대가를 표시한다. |
| 활성 계약 | 선택 카드를 플레이어 앞에 일반 카드 크기의 앞면 카드로 놓고 호버 시 능력·대가를 표시한다. |
| 지속 범위 | 선택한 상대와의 전투 전체, 즉 여러 라운드에 걸쳐 유지하고 전투 종료 시 해제한다. |
| 행동 소비 | 계약 선택과 즉시 효과 처리는 플레이어의 정상 행동 1회를 소비한다. |
| 취소 | `CONTRACT` 입력은 확인창 없이 즉시 비용 지불과 후보 공개를 시도한다. 시작 실패는 원자적으로 무변경이며, 공개 뒤 취소·환불할 수 없다. |
| 개별 대가 | 영혼을 0까지 감소시킬 수 있고, 0이 되는 순간 즉시 전투 패배한다. |
| 선택형 문구 | `할 수 있다`는 계약 소유자가 실행 여부를 선택한다. |
| 버스트 범위 | 숫자·카드·악마·계약 효과와 특수 패배 조건의 버스트를 모두 포함한다. |
| 생성 카드 합계 | 숫자가 적힌 계약 생성 특수 카드는 합계에 포함한다. |
| 동일 악마 중첩 | 추가 계약에서 같은 악마를 다시 선택할 수 있으며 각 계약은 별도 인스턴스다. |
| 임시 카드 수명 | 생성·이동·추방 상태는 현재 전투의 여러 라운드에 유지하고 전투 종료 시 원상복구한다. |
| 적 계약 | 플레이어와 같은 비용·선택·대가·중첩·정리 규칙을 사용한다. |
| 1차 구현 악마 | 사탄, 벨페고르, 마몬, 레비아탄 |

`현재 영혼 > 비용`은 체인지와 동일한 엄격 조건이다. 계약 시작 비용 자체가 영혼을 0으로 만들 수는 없지만 이후 악마의 개별 대가는 영혼을 0까지 감소시킬 수 있다. 영혼이 0이 되면 버스트 판정과 구분되는 즉시 전투 패배로 처리하고 남은 효과와 차례를 중단한다.

## 4. 계약 플레이 흐름

1. 플레이어가 자신의 차례에 악마 덱 또는 `CONTRACT` 버튼을 선택한다.
2. 계약 가능 조건을 검사한다. 실패하면 영혼·횟수·덱·차례와 화면 상태를 바꾸지 않는다.
3. 성공하면 영혼 1을 지불한다.
4. 악마 덱에서 제시 가능한 카드 중 최대 2장을 화면 하단에 반쯤 보이는 월드 카드 손패로 펼친다.
5. 후보에 호버하면 해당 카드가 앞으로 나오고 위로 들리며 조금 커진다. 큰 UI 상세 패널에는 SO 표시 데이터의 이름·앞면·`ACTIVE`·`COST`를 표시한다.
6. 후보 선택 중 카드 호버·클릭과 카메라 `W`·`S`, 일시정지를 제외한 입력을 잠근다.
7. 플레이어가 하나를 클릭해 선택한다.
8. 선택한 악마 카드를 플레이어 앞 활성 계약 영역으로 옮기고 미선택 카드가 있으면 악마 버린 더미로 보낸다.
9. 선택한 악마의 즉시 효과를 처리한다.
10. 버스트·영혼 고갈·전투 종료를 확인한다.
11. 전투가 계속되면 지속 효과와 대가를 등록하고 적 차례로 넘긴다.
12. 이후 명시된 발동 시점마다 능력과 대가를 처리한다.
13. 전투가 끝나면 활성 계약과 전투용 악마 덱·버린 더미를 제거한다.

## 5. 계약 가능 조건

다음 조건을 모두 만족해야 계약을 시작할 수 있다.

1. 전투가 진행 중이고 플레이어가 정상 행동을 할 수 있다.
2. 카드 효과, 체인지, 다른 계약 선택을 처리 중이지 않다.
3. 이번 전투의 기본 계약 횟수를 아직 사용하지 않았다.
4. 플레이어의 현재 영혼이 계약 비용보다 많다.
5. 악마 덱에서 제시할 물리 카드가 최소 1장 있다.
6. 전투·런 상태가 계약 입력을 받을 수 있는 유효한 인스턴스다.

검사 실패는 영혼, 덱 순서, 사용 횟수, 차례와 UI 상태를 변경하지 않는다. 추가 계약을 허용하는 효과는 횟수 조건만 예외 처리하며 영혼 조건과 최소 후보 1장 조건은 그대로 적용한다.

## 6. 악마 덱과 수명

### 6.1 시작 덱 프로토타입 결정

새 런을 시작할 때 사탄·벨페고르·바알제붑·마몬의 고정 풀에서 서로 다른 악마 카드 2장을 동일 가중치로 무작위 추첨해 모두 시작 악마 카드 덱에 넣는다. 플레이어 선택은 없으며, 두 장을 동시에 공개한 뒤 확인 버튼으로 진행한다. 이 지급은 계약이 아니므로 영혼과 전투당 계약 횟수를 소비하지 않는다. 지급 직후 결과를 저장한다.

기본 풀 네 악마의 가중치는 동일하다. 별도 해금·캐릭터 효과가 확정되기 전에는 풀과 가중치를 바꾸지 않는다. 지급한 2장은 각각 안정된 물리 ID와 함께 최초·현재 런 악마 덱에 넣고, 지급 결과는 재시작과 첫 체크포인트 캡처·복원에서 유지한다.

현행 코드는 두 장 자동 지급·즉시 저장과 GameScene 동시 공개를 연결한다. 공개 카드는 선택 대상이 아니며 확인 버튼을 누른 뒤에만 상대 선택으로 이동한다. 과거 DC-R05의 선택 화면·악마 덱 1장·저장 재진입 검증은 당시 구현 증거로만 보존한다.

과거 4장 구성은 완료된 구현 이력으로만 보존한다. 중복 카드와 등장 가중치는 상점에서 악마 카드를 획득하는 흐름이 구현된 뒤 다시 조정한다.

### 6.2 런 덱과 전투 덱

- 런 상태는 보유한 악마 카드의 안정된 정의 키와 물리 ID를 보존한다.
- 전투 시작 시 런 악마 덱 전체를 복사해 전투용 드로우 더미를 만들고 섞는다.
- 선택한 카드는 활성 영역, 선택하지 않은 카드는 전투용 악마 버린 더미로 이동한다.
- 추가 계약 시 드로우 더미가 부족하면 활성 계약을 제외한 버린 더미를 섞어 보충한다.
- 제시 가능한 물리 카드가 1장 이상이면 계약을 시작할 수 있고 최대 2장을 뽑는다.
- 전투 종료 시 전투용 위치만 폐기하고 런 악마 덱의 소유권은 유지한다.

이 구조에서는 첫 전투에서 버린 악마도 다음 전투에 다시 등장할 수 있다. 전투 중 카드 이동을 런 영구 제거로 해석하지 않는다.

### 6.3 계약 임시 카드와 소유권

- 바포메트의 오망성은 숫자를 합계에 포함하고 현재 전투의 덱·손·버린 더미를 순환한다. 전투 종료 시 모든 위치에서 제거한다.
- 파이몬이 추방한 카드는 현재 전투 동안 덱·손·버린 더미에서 제외하고 전투 종료 시 원래 소유권과 전투 시작 덱 구성을 복구한다. 플레이어 런 덱에는 제거를 반영하지 않는다.
- 벨리알이 가져온 카드는 현재 전투 동안 벨리알 계약 소유자의 카드다. 라운드 종료 시 그 소유자의 버린 더미로 보내고 전투 종료 시 원래 소유권으로 복구한다.
- 라운드 종료는 위 임시 상태를 제거하지 않는다. 하나의 상대와 벌이는 전투가 끝났을 때만 원상복구한다.
- 적이 같은 효과를 사용해도 방향만 반대로 적용하고 동일한 수명·복구 규칙을 따른다.

## 7. 공통 처리 우선순위

계약 효과와 카드 효과가 연쇄될 때 다음 순서를 사용한다.

1. 현재 실행 중인 단일 카드 이동·수치 변경을 끝낸다.
2. 명시적인 계약 대가와 직접 버스트를 처리한다.
3. 대가로 영혼이 0이 되면 즉시 전투 패배로 확정하고 남은 처리를 중단한다.
4. 행동 도중 숫자 버스트는 공개 카드 합으로 판정한다.
5. 라운드·전투가 끝났으면 남은 후속 효과를 중단한다.
6. 전투가 계속될 때만 다음 계약 훅이나 카드 효과를 처리한다.
7. 모든 효과와 선택이 끝났을 때만 차례를 넘긴다.

양측이 같은 효과 명령으로 동시에 버스트하면 전체 기획의 임시안대로 효과를 발생시킨 쪽이 패배한다. 계약 효과가 기존 카드 판정을 바꿀 때는 카드 이동을 복제하지 않고 카드 처리 결과 전후의 명시된 계약 훅만 사용한다.

## 8. 악마별 최신 규칙과 구현 이관

### 8.1 벨페고르 — 첫 수직 구현 대상

#### 능력

플레이어가 자신의 정상 차례에 히트를 선택하면 드로우 전에 덱 위 카드 한 장을 자신만 확인한다. 다음 중 하나를 고른다.

- 확인한 카드를 공개 상태로 히트한다.
- 확인한 카드를 덱 맨 아래로 보내고 이번 차례를 넘긴다.

#### 대가

상대가 스탠드한 상태로 플레이어의 다음 정상 차례가 시작되면 `차례 종료 시 자동 스탠드`를 예약한다. 플레이어는 그 차례에 허용된 행동 하나를 수행할 수 있지만 행동 완료 뒤 자동으로 스탠드한다. 덱 아래로 보내고 넘기기를 골라도 자동 스탠드한다.

#### 프로토타입 결정

- 덱 위 카드 정보는 플레이어에게만 표시한다.
- 히트 외 카드 사용·체인지는 미리보기를 발동시키지 않는다.
- 덱이 비어 정상 히트를 할 수 없으면 기존 히트 불가 규칙을 따른다.

벨페고르는 계약 공통 기반, 전용 선택, 덱 이동, 지속 대가와 정보 은닉을 한 번에 검증할 수 있어 첫 수직 구현 대상으로 정한다.

#### DC-03 구현 상태

- 히트 입력은 실제 드로우 전에 `BelphegorTopCard` 선택으로 보류되며, 공개 옵션에는 카드 ID·숫자를 담지 않는다.
- 실제 카드 ID·정의·숫자는 소유자 전용 `PlayerDemonContractPreview`에만 제공한다.
- 그대로 히트와 덱 아래 이동 모두 미리 본 물리 ID를 다시 확인한 뒤 처리한다.
- 상대 스탠드 뒤 시작된 다음 정상 차례에는 행동 완료 시 자동 스탠드를 한 번 예약하고 라운드 종료 시 초기화한다.
- 카드 사용·체인지는 미리보기를 만들지 않으며, 공개 합 중간 버스트와 전체 합 최종 승부 규칙은 기존 경계를 유지한다.

### 8.2 마몬

#### 능력과 대가

- 계약 즉시 6면체 주사위를 한 번 굴리고 결과를 공개한다.
- 라운드마다 한 번, 자신의 차례에 일반 행동 대신 다시 굴리고 차례를 끝낼 수 있다.
- 결과가 6이면 즉시 계약 효과 버스트로 처리한다.
- 양측 스탠드 후 최종 합계 비교 직전에 1~5 값을 자신의 최종 합계에 더할지 선택한다.
- 더한 결과가 21을 넘으면 플레이어가 숫자 버스트한다.

#### 프로토타입 결정

- 주사위 값은 중간 공개 카드 합에 포함하지 않는다.
- 매 소유자 차례 시작마다 현재 값을 유지할지 재굴림할지 묻는다. 유지는 정상 행동으로 이어지고 재굴림은 해당 차례의 일반 행동을 소비하며 결과를 되돌릴 수 없다. 같은 라운드라도 다음 차례가 오면 다시 선택한다.
- 값 적용 여부는 라운드마다 선택하고, 현재 주사위 값은 계약이 끝날 때까지 유지한다.
- 난수는 테스트 가능한 주입식 난수원을 사용한다.

#### DC-R03 구현 상태

- `MammonRuntimeState`는 현재 주사위 값과 현재 차례의 유지·재굴림 선택 가능 여부를 계약 인스턴스별로 보존한다.
- 매 차례 시작에 물리 마몬 계약 ID가 연결된 유지·재굴림 보류 상호작용을 연다. 유지 선택은 보류만 닫고 정상 행동을 허용한다.
- 재굴림은 결과와 관계없이 해당 차례의 일반 행동을 소비한다. 6이면 계약 효과 버스트를 먼저 해결하고, 생존한 경우에도 즉시 상대 차례로 넘긴다.
- 최종 합계의 적용·미적용 선택과 주입식 주사위는 그대로 유지하며, 재굴림 값을 공개 정보로 적 AI에 제공해 광신도가 1~2에서만 선택하도록 했다.

### 8.3 레비아탄

#### 능력과 대가

- 플레이어가 리볼버를 사용해 첫 예측에 실패하면 해당 리볼버 효과를 한 번 더 발동한다.
- 두 예측이 모두 실패했다면 플레이어 영혼 1을 잃는다.

#### 프로토타입 결정

- 각 리볼버 발동은 기존 단일 비공개 카드 추측과 정보 은닉 규칙을 그대로 사용한다.
- UI는 실제 비공개 숫자를 노출하지 않고 첫 판정의 성공/실패, 실패 뒤 재준비, 두 번째 선언과 최종 성공/실패만 표시한다.
- 대가로 영혼이 0이 되면 즉시 전투 패배다.
- 리볼버 사용 자체가 승인되지 않았다면 능력과 대가 모두 발동하지 않는다.

#### CU-M07 현행 구현 상태

- 기존 DC-04의 실패 뒤 공개 합 22 이상 후처리를 제거했다.
- 같은 리볼버 물리 카드와 활성 레비아탄 계약을 묶은 연속 처리에서 첫 실패에만 새로운 선언 입력을 요청한다. 두 선언은 서로 같아도 된다.
- 첫 발동이 성공하면 상대 버스트가 다른 계약으로 방지되어도 두 번째 발동과 대가를 생략한다.
- 첫 실패는 실패 연출을 먼저 표시한 뒤 리볼버 준비와 숫자 선택을 다시 연다.
- 두 번째 발동은 일반 리볼버와 같은 판정을 사용한다. 성공하면 대가가 없고, 두 번 모두 실패하면 소유자 영혼 1을 잃는다. 영혼 0은 즉시 전투 패배다.
- 안전한 최근 결과에는 두 발동의 성공 여부, 버스트 대상과 지불 영혼만 남기며 실제 비공개 숫자는 포함하지 않는다.
- 여러 레비아탄 계약 인스턴스의 추가 발동 중첩 순서는 아직 확정하지 않았으며, 기본 전투당 계약 1회 범위에서는 활성 계약 하나만 적용한다.

### 8.4 사탄 — 노션 v0.6 개정 규칙

#### 원문 공통 부분

- 계약 중 플레이어는 스탠드할 수 없다.
- 계약 중 플레이어는 숫자·카드·계약 효과로 버스트되지 않는다.
- 사탄 계약 카드 자체가 윗면·아랫면 상태를 가진다.
- 계약 카드는 윗면으로 시작한다. 소유자는 정상 차례에 허용된 일반 행동 또는 현재 면 능력 중 하나를 선택한다.
- 윗면에서는 숫자 두 개를 선언하고 하나라도 상대 비공개 카드와 같으면 상대를 버스트시킨다.
- 아랫면에서는 상대를 강제로 히트시키고 공개 합이 21 이하라면 새 카드를 즉시 버린다.
- 카운터 종료 시 영혼 2를 잃는 위험이 있다.

#### 현행 결정

- 종말 카운트는 계약 직후 4로 시작한다.
- 계약 소유자의 차례 시작마다 1 감소한다.
- 0이 된 차례 시작 시 영혼 2를 한 번 잃는다.
- 기존 DC-06의 카운트 6·양측 차례 감소·계약 종료·별도 숫자 8/10 권능 카드는 과거 구현으로만 보존한다.
- 계약을 발동한 차례에는 윗면을 유지한다. 다음 소유자 정상 차례부터 일반 행동을 선택하면 면을 유지하고, 현재 면 능력이 성공적으로 해결되면 그 행동이 차례를 소비한 뒤 반대 면으로 전환된다. 실패·취소·오래된 입력은 행동과 면을 모두 보존한다.
- 윗면 선언은 서로 다른 숫자 두 개만 허용하며 상대 비공개 카드 숫자는 결과 판정에만 사용하고 화면·AI 관측에는 노출하지 않는다.
- 아랫면 강제 히트는 상대의 자동 발동 카드 선택이 끝난 뒤 재개한다. 새 공개 합이 21 이하면 해당 드로우 카드만 버리고, 21 초과면 사탄의 버스트 방지 규칙을 포함한 정상 판정을 적용한다.

#### DC-R02 구현 상태

- `SatanRuntimeState`가 종말 카운트 4, 현재 면과 대가 적용 여부를 활성 계약 인스턴스별로 보존한다.
- 소유자 차례 시작·종료 훅, 영혼 2의 1회 대가, 전투 종료까지 유지되는 스탠드·버스트 제한을 플레이어와 적에게 같은 방향성 규칙으로 적용한다.
- 별도 숫자 8/10 권능 정의와 처리기를 현행 카드 카탈로그에서 제거했다. 활성 사탄 계약의 윗면/아랫면 행동만 전투·세션 API로 제공한다.
- 적도 일반 행동과 현재 면 능력 중 하나를 공개 정보만으로 선택한다. 능력을 고른 경우 광신도·보스는 공개 추론만으로 윗면 숫자를 선언하고, 아랫면도 플레이어와 같은 강제 히트·자동 카드 재개 경계를 사용한다. 안전한 일반 히트가 있으면 이를 우선하고, 일반 히트가 위험하면 현재 면 능력을 선택한다.
- 표시 모델은 `종말 카운트 N · 윗면/아랫면`과 대가 적용 여부를 제공한다. DC-R05에서 활성 계약 물리 ID 입력을 사탄의 현재 상태 행동으로 연결했다. 사탄은 일반 카드의 앞면/뒷면을 바꾸지 않으며, 월드 카드가 추가되면 공개 상태를 유지한 채 윗면/아랫면 규칙 상태만 표시한다.

- 바알제붑의 대가로 영혼이 0이 되면 라운드 피해를 적용하지 않고 즉시 전투 패배로 끝내며 카드 이동도 하지 않는다.
- 바알제붑의 공개 카드 3장 이하 스탠드 금지는 기존 소유자 방향 스탠드 제한 훅을 재사용한다.
- 메피스토펠레스는 기존 보위 나이프의 공개 합 버스트 판정을 복제하지 않는다. 기존 효과가 라운드를 끝내지 못한 결과만 받아 소유자의 단일 비공개 카드를 공개한다.
- 아스모데우스는 소유자 정상 차례 시작에 상대가 스탠드하지 않았고 드로우할 수 있을 때만 `강제 히트/사용 안 함` 선택을 연다. 이 선택은 정상 행동을 소비하지 않으며, 숫자 7 이하 수동 카드는 계약 소유자 방향으로 사용할 수 없다. EP-R04에서 7 제한·8 허용 경계를 코드와 회귀 테스트로 고정했다.
- 아자젤은 계약 즉시와 소유자의 정상 히트 완료 뒤 현재 공개 수동 카드의 사용 효과를 테이블 왼쪽부터 오른쪽으로 각각 한 번씩 실행한다. 시작 시 카드 ID·순서를 고정하고 선택형 효과 완료 뒤 다음 카드로 이어가며, 새로 들어온 카드는 다음 발동부터 포함한다. 계약 이후 동일 숫자의 공개 카드가 추가되면 자동 카드 발동과 숫자 버스트보다 먼저 계약 효과 버스트를 처리한다.
- 파이몬은 상대가 숫자·카드·계약 효과로 버스트한 뒤 소유자가 양쪽 중 드로우 가능한 덱 하나의 위 2장을 비공개로 확인하게 한다. `추방하지 않음` 또는 확인한 카드 한 장을 고르고, 남은 카드는 원래 다음 드로우 순서로 돌려놓는다. 추방 카드는 현재 전투 동안 제외하고 전투 종료 시 원소유자 덱 구성으로 복구한다.
- 파이몬 대가는 카드 선택 뒤 임시 승자 한 명에게 한 번만 판정한다. 그 승자의 전체 카드 합이 18 이하면 계약 효과 버스트로 승패를 뒤집고, 새 승자 쪽 파이몬은 같은 라운드에 다시 판정하지 않는다. 이는 양측 무한 반전을 막는 프로토타입 결정이다.
- 벨리알은 계약 즉시 소유자의 공개 카드를 모두 버린다. 소유자 정상 차례 시작마다 상대 공개 카드 한 장을 가져오거나 건너뛸 수 있고, 가져온 카드는 이전 사용 여부와 관계없이 즉시 사용한 뒤 정상 행동을 보존한다. 상대 스탠드는 취소한다.
- 벨리알 탈취는 원본 카드와 전투용 대리 카드를 연결해 양측 덱의 같은 물리 ID 충돌을 피한다. 대리 카드는 현재 소유자의 손·버린 더미를 따르고 전투 종료 시 제거하며 원본은 원소유자 덱으로 복구한다. 다음 라운드 드로우 전 영혼 1을 잃어 0이면 카드를 나누기 전에 즉시 사망한다.
- 구현된 악마 처리기는 플레이어와 적에게 같은 소유자 방향 규칙을 사용한다. 단, 프로토타입 런타임 콘텐츠에는 확정된 7종만 공급한다. 제외 악마 처리기는 과거 구현·검증 보존용이며 출현 풀에 등록하지 않는다.
- 바포메트는 계약별 오망성 묶음의 드로우 더미 소진·회수·재삽입을 처리한다. 루시퍼는 현재 소유자 악마 덱에서 최대 5장을 제시하고 건너뛰기 또는 별도 계약 인스턴스를 만든다.
- DC-R05에서 시작 악마 선택 런타임과 사탄·마몬 활성 계약 행동 입력, 일반/루시퍼 후보 레이아웃을 코드로 연결했다. 실제 앞면 월드 계약 카드 오브젝트와 전용 연출은 씬·아트 후속 범위다.

## 9. 화면과 피드백

### 9.0 덱 오브젝트

- 일반 카드 덱 옆에 별도의 악마 카드 덱을 나란히 배치한다.
- 두 덱의 맨 위 카드는 각각 일반 카드와 악마 카드의 전용 뒷면이 보이게 한다.
- 일반 카드 덱과 악마 카드 덱을 호버하면 현재 포함된 카드 목록을 펼쳐 표시한다.
- 목록은 카드 구성과 수량을 확인하기 위한 정보이며 실제 뽑기 순서는 표시하지 않는다.
- 악마 덱 선택은 계약 시작 입력으로 사용하고, 호버 정보 확인만으로는 비용이나 상태를 변경하지 않는다.

### 9.1 계약 시작

- `CONTRACT` 입력은 별도 확인·취소 화면을 열지 않고 전투의 `TryBeginPlayerDemonContract` 경계로 바로 전달한다.
- 비용, 남은 횟수와 후보 존재 여부는 전투가 원자적으로 재검증한다.
- 실패하면 비용·횟수·덱·차례가 바뀌지 않으며 후보 화면도 열지 않는다.

### 9.2 후보 선택

- 화면 하단에서 아래쪽 절반이 화면 밖에 걸치고 작은 호를 이루는 앞면 월드 카드 최대 2장
- 악마 이름과 일러스트
- 카드 호버 시 해당 카드의 전진·상승·확대와 최상위 정렬
- 카드 뒤의 큰 UI 패널에 제목과 카드 앞면 표시
- 오른쪽의 분리된 `ACTIVE`·`COST` 패널에 SO 기반 능력·대가 표시
- 카드 자체를 선택하는 입력

후보가 공개된 뒤에는 취소 버튼을 제공하지 않는다. 후보 카드의 호버·클릭과 카메라 `W`·`S`, 일시정지만 허용하고 다른 전투 행동, 덱 선택, 카드 사용, 체인지, 상점과 재중복 입력은 잠근다. 일시정지 중에는 후보와 상세를 보존하되 상세 패널은 숨기고, 복귀 후 같은 후보 선택을 이어간다.

루시퍼가 제공하는 추가 계약은 같은 연출을 사용하되 현재 악마 덱에서 최대 5장을 제시하고 `추가 계약하지 않음`을 함께 제공한다. 5장보다 적으면 남은 수만 표시하며, 남은 카드가 없으면 선택 화면을 열지 않는다.

### 9.3 활성 계약

- 선택한 악마 카드를 일반 카드와 같은 크기의 앞면 월드 카드로 플레이어 앞 계약 영역에 둔다.
- 활성 계약 카드를 호버하면 악마 이름, 능력과 대가를 함께 표시한다.
- 계약 확정 뒤 화면 구석에 `DEMON CONTRACT` 제목과 활성 계약·최근 결과를 담은 텍스트 상태 상자를 상시 노출하지 않는다.
- 사탄 카운터 또는 마몬 주사위처럼 변하는 값
- 최근 발동 결과
- 전투당 계약 사용 완료 표시

UI는 규칙을 다시 계산하지 않고 전투가 제공한 안전한 표시 스냅샷만 사용한다. 상대 비공개 카드와 덱 순서는 계약 UI에 포함하지 않는다.

#### DC-05~DC-R03 구현 상태

- 비용 지불 전 화면은 현재 영혼·비용·계약 후 영혼과 확인·취소를 제공하고 전투 상태를 바꾸지 않는다.
- 현재 구현은 비용 지불 뒤 가용 카드 수에 따라 후보 1~2장을 만들고 이름·능력·대가를 표시한다. 한 장이면 버리는 카드 없이 활성화하고, 0장이면 비용·횟수·난수·차례를 바꾸지 않고 거절한다.
- 사탄은 카운트 4·소유자 차례 시작 감소·영혼 2의 1회 대가와 활성 계약의 윗면/아랫면 상태를 표시 모델에 투영한다.
- 별도 사탄 권능 카드는 제거했다. DC-R05에서 활성 계약 ID 입력은 연결했으며, 앞면 월드 카드 오브젝트와 양면 연출은 씬·아트 후속으로 분리한다.
- 표시 모델은 벨페고르 예약 상태, 마몬 현재 주사위, 레비아탄 발동 조건과 안전한 최근 결과를 보존하지만, 계약 완료 뒤 이를 별도 상시 패널로 그리지 않는다.
- 벨페고르 덱 위 숫자는 `PLAYER ONLY`로 구분하고 상대 비공개 숫자·전체 합은 표시 모델에 포함하지 않는다.
- `GameScene`과 `CoreLoopTest`의 스크립트 UI에서 사탄 활성 행동과 루시퍼 5장+건너뛰기를 1280×720·1920×1080으로 검증했다. CoreLoopTest는 후보가 4개 이상이면 상단 전투 정보를 영혼 한 줄로 축약하며, 씬 직렬화는 변경하지 않았다.
- 적 활성 계약은 표시 모델에 `상대` 소유자로 보존하되 상시 패널에는 노출하지 않고, 적 벨페고르 미리보기는 공용·플레이어 화면 모델에 노출하지 않는다.

DC-M01에서 `GameScene`과 `CoreLoopTest`의 계약 완료 후 상시 텍스트 패널을 제거했다. 비용 확인창, 후보 선택창과 계약 규칙·활성 상태 데이터는 유지하며, 향후 월드 카드와 호버 상세가 해당 정보를 맡는다.

DC-R05에서 시작 악마 2장 중 1장 선택·저장 재진입, 후보 1~2장과 루시퍼 최대 5장+건너뛰기, 활성 마몬·사탄 행동 버튼을 실제 두 전투 화면에 연결하고 두 해상도로 검증했다. 덱별 뒷면·덱 호버 목록과 플레이어 앞의 물리 앞면 월드 계약 카드·사탄 면 전환은 규칙·입력 완료와 분리한 씬·아트 후속 작업이다.

#### DC-V01 현행 GameScene 구현

- `CONTRACT` 버튼은 확인창을 거치지 않고 계약 시작 `Try*` 경계를 호출한다.
- 일반 `ChooseContract` 후보 1~2장은 `DemonContractSelectionView`가 기존 `DemonCard` 프리팹을 사용해 화면 하단 월드 카드 손패로 렌더링한다.
- 호버 카드의 위치·크기·정렬을 올리고, 기존 HUD 후보 패널을 제목·앞면·`ACTIVE`·`COST` 상세 패널로 재사용한다.
- 제목·능력·대가와 스프라이트는 도메인 표시 모델과 `CardContentCatalogSO` 경계에서 읽으며 UI가 규칙을 재계산하지 않는다.
- 루시퍼처럼 후보가 2장을 넘거나 건너뛰기가 포함된 상호작용은 기존 다중 옵션 UI를 유지한다.

## 10. 1차 범위와 제외 범위

### 10.1 포함

- 별도 런 악마 덱과 전투용 악마 덱·버린 더미
- 엄격한 영혼 비용 조건과 전투당 1회 제한
- 후보 최대 2장과 필수 1장 선택, 단일 후보 허용
- 활성 계약 수명과 전투 종료 초기화
- 동일 악마의 별도 계약 인스턴스와 전투 종료 원상복구 기반
- 사탄, 벨페고르, 바알제붑, 아스모데우스, 마몬, 바포메트, 아자젤
- 카드 효과·버스트·영혼·차례와의 명시적 연동
- 독립 전투와 런 전투의 입력·표시·영혼 동기화
- 정보 은닉, 반복 재시작과 카드 소유권 테스트
- 광신도의 우선 악마 4종 계약 선택과 플레이어·적 대칭 효과 처리

### 10.2 제외

- 루시퍼, 레비아탄, 메피스토펠레스, 파이몬, 벨리알과 그 밖의 악마
- 제외 악마를 참조하는 적 전용 덱·고정 계약 구성의 프로토타입 출현. 대체 구성 확정 전에는 해당 참조를 콘텐츠 풀에서 차단한다.
- 유물·강화에 의한 계약 횟수·비용 변경
- 상점 악마 카드 구매의 실제 구현
- 저장 파일과 덱 편집 UI
- 최종 일러스트·애니메이션·사운드·현지화
- 유물이 만드는 추가 계약과 계약 횟수·비용 변경

DC-07의 광신도 자율 계약은 과거 구현 기준이다. 현행 목표는 광신도에게 벨페고르·바알제붑 중 하나를 공개 카드 수에 따라 지정하고, 보스가 전투 시작과 영혼 5·2 이하 진입 시 고정된 세 계약 단계로 전환하도록 확장하는 것이다. 집행자는 악마를 보유하지 않는다.

### 10.1 광신도 계약 선택 기준

- 첫 정상 차례에는 일반 행동·공통 체인지보다 계약 시작을 우선한다.
- 플레이어 공격·효과 또는 입력 중단으로 계약이 완료되지 않았다면 다음 정상 차례에도 다시 시도한다.
- 한 번 계약에 성공하면 이 전투의 강제 계약 재시도 상태를 종료한다.
- 상대 공개 카드가 2장 이상이면 바알제붑, 아니면 벨페고르를 선택한다. 영혼 수와 카드 사용 가능 여부는 선택 조건에 포함하지 않는다.
- 전투 종료·사망처럼 정상 차례 자체가 열리지 않는 경우에는 별도 재시도를 만들지 않는다.

### 10.3 보스 계약 단계

- 전투 생성 직후 바포메트를 활성화하고 마몬을 버려 1단계를 시작한다.
- 피해 처리 뒤 보스가 살아 있고 현재 영혼이 5 이하가 되면 기존 계약을 종료하고 아스모데우스를 활성화한다. 함께 버릴 프로토타입 7종 내 악마는 재설계 대기다.
- 피해 처리 뒤 현재 영혼이 2 이하가 되면 기존 계약을 종료하고 아자젤을 활성화한다. 함께 버릴 프로토타입 7종 내 악마는 재설계 대기다.
- 한 번의 피해로 두 경계를 넘으면 2단계와 3단계를 순서대로 처리하며, 회복해도 단계를 되돌리지 않는다.

## 11. 플레이 테스트 지표

| 지표 | 1차 목표 |
| --- | ---: |
| 계약 사용 런 비율 | 70% 이상 |
| 평균 계약 횟수 | 전투당 0.5~1.0회 |
| 계약 선택 시간 | 20초 이하 |
| 계약 대가로 인한 패배 | 원인 이해 가능 여부를 우선 기록 |
| 우선 악마 선택률 | 한 악마가 60%를 넘으면 후보 가치 재검토 |
| 광신도 자동 전투 종료 | 200회 플레이어 행동 안에 100% 종료 |

계약 사용률이 낮으면 효과 수치부터 올리지 않고 비용, 계약 후 남은 영혼, 기대 이득과 대가 발동 시점을 먼저 더 명확히 표시한다.

### 11.1 DC-R04 4/5 바포메트 프로토타입 결정

- 상대 묶음은 오망성 1~5 한 장씩, 소유자 묶음은 1~3 한 장씩이다. 오망성 1은 기존 에이스 계산을 그대로 사용한다.
- 계약 인스턴스마다 양측 묶음을 별도로 추적한다. 한 묶음의 물리 카드가 대상 드로우 더미에 하나도 남지 않으면 소진으로 확정한다.
- 소진 묶음은 손·드로우·버린 더미뿐 아니라 파이몬 추방과 벨리알 탈취 대리까지 회수한다. 대상의 가용 드로우·버린 더미를 다시 섞고 같은 숫자 묶음을 새 물리 ID로 넣은 뒤 계약 효과 버스트를 처리한다.
- 기존 숫자·카드·다른 계약 버스트가 같은 카드 진입에서 먼저 확정되면 해당 판정이 우선한다. 방지 뒤 행동이 계속될 때 바포메트 소진을 이어서 처리하며, 바포메트 버스트에도 사탄·바알제붑 경계를 재사용한다.
- 이 수치와 소진 기준은 **프로토타입 결정**이다. 실제 전투에서 소유자 위험이 너무 낮거나 묶음 회전이 지나치게 늦으면 이천서가 숫자 구성 또는 소진 기준을 다시 확정한다.

### 11.2 DC-R04 5/5 루시퍼 프로토타입 결정

- 후보 풀은 전역 카탈로그가 아니라 현재 계약 소유자의 악마 덱에 남은 물리 카드다. 최대 5장을 꺼내며 부족하면 남은 수만 사용한다.
- `계약할 수 있다`를 선택으로 해석해 후보와 별도로 건너뛰기를 제공한다. 선택하지 않은 후보는 악마 버린 더미로 이동하고, 남은 카드가 없으면 루시퍼의 영혼 1 대가까지만 적용한 뒤 행동을 끝낸다.
- 최초 루시퍼를 연 기본 비용 1과 전투당 사용 횟수는 다시 부과하지 않는다. 선택 악마는 별도 물리 ID·런타임 상태로 활성화하고 그 악마의 능력·개별 대가만 적용한다.
- 같은 악마와 다른 루시퍼도 선택할 수 있다. 추가 루시퍼는 더 줄어든 현재 악마 덱에서 다시 최대 5장을 제시하므로 물리 카드 수명 안에서 유한하게 연쇄된다.
- 루시퍼 또는 선택 악마의 개별 대가로 영혼이 0이 되면 기존 공통 규칙대로 즉시 전투를 끝내고 후속 후보를 열지 않는다. 이 후보 수명·건너뛰기·연쇄 기준은 플레이 테스트 뒤 이천서가 재검토한다.

## 13. 완료 조건

- 계약 비용과 전투당 제한을 우회할 수 없다.
- 후보 최대 2장과 선택·버림·활성 영역에서 물리 카드가 복제되거나 유실되지 않는다.
- 일반·악마 덱의 전용 뒷면과 순서를 숨긴 호버 목록이 구분된다.
- 가용 카드 수에 따라 후보 1장 또는 2장이 화면 하단에 반노출 월드 카드 손패로 펼쳐지고 선택 카드가 플레이어 앞 계약 영역으로 이동한다.
- 후보와 활성 계약 카드의 호버 정보에 능력과 대가가 함께 표시된다.
- 네 우선 악마의 능력과 대가가 표시 문구와 같은 순서로 처리된다.
- 일반 중간 버스트는 공개 합, 최종 승부는 전체 합이라는 현행 규칙이 유지된다.
- 상대 비공개 정보와 실제 덱 순서가 화면·로그·적 AI에 새로 노출되지 않는다.
- 전투 종료·다음 전투·런 재시작에서 계약 상태가 남지 않는다.
- 오망성·파이몬 추방·벨리알 탈취가 라운드를 넘어 유지되면서 런 덱에는 남지 않는다.
- 루시퍼 추가 계약이 최초 기본 비용·사용 횟수를 이중 적용하지 않고 물리 카드·런타임 상태를 독립 보존한다.
- 같은 악마 계약이 서로 다른 물리 ID와 런타임 상태를 가진다.
- 자동·수동 검증 결과와 실제 담당 파일을 진행 기록·AI 활용·팀 역할 문서에 남긴다.
